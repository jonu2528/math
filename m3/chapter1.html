บทที่ 1: จำนวนจริง

จำนวนจริงเป็นพื้นฐานสำคัญของคณิตศาสตร์ ประกอบด้วยจำนวนตรรกยะและจำนวนอตรรกยะ ในบทนี้เราจะศึกษาเกี่ยวกับจำนวนจริง การดำเนินการ รากที่ n และการประมาณค่า ซึ่งจะเป็นพื้นฐานสำคัญในการเรียนคณิตศาสตร์ในระดับที่สูงขึ้น

1.1 ความหมายของจำนวนจริง

ความหมาย

จำนวนจริง (Real Numbers) คือจำนวนทั้งหมดที่สามารถเขียนแทนตำแหน่งบนเส้นจำนวนได้ ประกอบด้วย 2 กลุ่มหลัก:

  • จำนวนตรรกยะ (Rational Numbers) คือจำนวนที่เขียนในรูป $$\frac{a}{b}$$ ได้ โดยที่ $a$ และ $b$ เป็นจำนวนเต็ม และ $b \neq 0$ เช่น $\frac{1}{2}, -3, 0.25, 0.\overline{3}$
  • จำนวนอตรรกยะ (Irrational Numbers) คือจำนวนที่เขียนในรูปเศษส่วนไม่ได้ ทศนิยมไม่รู้จบและไม่มีรูปแบบซ้ำ เช่น $\sqrt{2}, \pi, e$

โครงสร้างจำนวนจริง

$$\text{จำนวนจริง} = \{\text{จำนวนตรรกยะ}\} \cup \{\text{จำนวนอตรรกยะ}\}$$

จำนวนตรรกยะ ประกอบด้วย:

  • จำนวนนับ: $1, 2, 3, 4, ...$
  • จำนวนเต็ม: $..., -2, -1, 0, 1, 2, ...$
  • เศษส่วน: $\frac{1}{2}, \frac{3}{4}, -\frac{2}{5}$
  • ทศนิยมรู้จบหรือทศนิยมซ้ำ: $0.5, 0.\overline{3}$

ตัวอย่างที่ 1

โจทย์: จงบอกว่าจำนวนต่อไปนี้เป็นจำนวนตรรกยะหรืออตรรกยะ

ก) $0.75$    ข) $\sqrt{9}$    ค) $\sqrt{5}$    ง) $\frac{22}{7}$    จ) $\pi$

วิธีทำ:

ก) $0.75 = \frac{75}{100} = \frac{3}{4}$ เป็นจำนวนตรรกยะ

ข) $\sqrt{9} = 3$ เป็นจำนวนตรรกยะ (เป็นจำนวนเต็ม)

ค) $\sqrt{5} = 2.236...$ (ทศนิยมไม่รู้จบไม่ซ้ำ) เป็นจำนวนอตรรกยะ

ง) $\frac{22}{7}$ อยู่ในรูปเศษส่วนอยู่แล้ว เป็นจำนวนตรรกยะ

จ) $\pi = 3.141592...$ (ทศนิยมไม่รู้จบไม่ซ้ำ) เป็นจำนวนอตรรกยะ

ตัวอย่างที่ 2

โจทย์: จงเขียนจำนวนต่อไปนี้ในรูปเศษส่วนอย่างต่ำ

ก) $0.6$    ข) $0.\overline{2}$    ค) $2.5$

วิธีทำ:

ก) $0.6 = \frac{6}{10} = \frac{3}{5}$

ข) ให้ $x = 0.\overline{2} = 0.2222...$

    $10x = 2.2222...$

    $10x - x = 2.2222... - 0.2222...$

    $9x = 2$

    $x = \frac{2}{9}$

ค) $2.5 = \frac{25}{10} = \frac{5}{2}$

ตัวอย่างที่ 3

โจทย์: จงหาจำนวนตรรกยะที่อยู่ระหว่าง $\frac{1}{3}$ และ $\frac{1}{2}$

วิธีทำ:

วิธีที่ 1: หาค่าเฉลี่ย

$$\text{จำนวนตรรกยะ} = \frac{\frac{1}{3} + \frac{1}{2}}{2} = \frac{\frac{2+3}{6}}{2} = \frac{\frac{5}{6}}{2} = \frac{5}{12}$$

ตรวจสอบ: $\frac{1}{3} = \frac{4}{12} < \frac{5}{12} < \frac{6}{12} = \frac{1}{2}$ ✓

วิธีที่ 2: เขียนในรูปทศนิยม

$\frac{1}{3} = 0.333...$ และ $\frac{1}{2} = 0.5$

ดังนั้น $0.4$ อยู่ระหว่างสองจำนวนนี้

$0.4 = \frac{4}{10} = \frac{2}{5}$

ตอบ: $\frac{5}{12}$ หรือ $\frac{2}{5}$ หรือจำนวนตรรกยะอื่นๆ ที่อยู่ระหว่างสองจำนวนนี้

ตัวอย่างที่ 4

โจทย์: จงเขียน $1.\overline{45}$ ในรูปเศษส่วนอย่างต่ำ

วิธีทำ:

ให้ $x = 1.\overline{45} = 1.454545...$

เนื่องจากมีเลข 2 ตัวซ้ำ จึงคูณด้วย $10^2 = 100$

    $100x = 145.454545...$

    $100x - x = 145.454545... - 1.454545...$

    $99x = 144$

    $x = \frac{144}{99} = \frac{16}{11}$

ตอบ: $\frac{16}{11}$

1.2 จำนวนอตรรกยะ

ความหมาย

จำนวนอตรรกยะ (Irrational Numbers) คือจำนวนที่ไม่สามารถเขียนในรูปเศษส่วน $\frac{a}{b}$ ได้ (โดยที่ $a, b$ เป็นจำนวนเต็ม และ $b \neq 0$) มีลักษณะเป็นทศนิยมไม่รู้จบและไม่มีรูปแบบซ้ำ

จำนวนอตรรกยะที่พบบ่อย

  • รากที่สองของจำนวนที่ไม่ใช่กำลังสองสมบูรณ์: $\sqrt{2}, \sqrt{3}, \sqrt{5}, \sqrt{7}, \sqrt{8}, ...$
  • รากที่สามของจำนวนที่ไม่ใช่กำลังสามสมบูรณ์: $\sqrt[3]{2}, \sqrt[3]{5}, \sqrt[3]{10}, ...$
  • ค่าคงตัวทางคณิตศาสตร์: $\pi = 3.141592..., e = 2.71828...$
  • ผลบวกหรือผลคูณของจำนวนตรรกยะกับอตรรกยะ: $2 + \sqrt{3}, 5\sqrt{2}$

สมบัติสำคัญ

  • จำนวนตรรกยะ + จำนวนอตรรกยะ = จำนวนอตรรกยะ
  • จำนวนตรรกยะ (ไม่เท่ากับ 0) × จำนวนอตรรกยะ = จำนวนอตรรกยะ
  • จำนวนอตรรกยะ + จำนวนอตรรกยะ = อาจเป็นตรรกยะหรืออตรรกยะก็ได้
  • จำนวนอตรรกยะ × จำนวนอตรรกยะ = อาจเป็นตรรกยะหรืออตรรกยะก็ได้

ตัวอย่างที่ 1

โจทย์: จงระบุว่าจำนวนต่อไปนี้เป็นจำนวนตรรกยะหรืออตรรกยะ พร้อมอธิบาย

ก) $\sqrt{16}$    ข) $\sqrt{20}$    ค) $2\sqrt{3}$    ง) $\sqrt{2} + \sqrt{8}$

วิธีทำ:

ก) $\sqrt{16} = 4$ เป็นจำนวนเต็ม ดังนั้นเป็นจำนวนตรรกยะ

ข) $\sqrt{20} = \sqrt{4 \times 5} = 2\sqrt{5}$ เนื่องจาก $\sqrt{5}$ เป็นอตรรกยะ จึงเป็นจำนวนอตรรกยะ

ค) $2\sqrt{3}$ = จำนวนตรรกยะ × จำนวนอตรรกยะ เป็นจำนวนอตรรกยะ

ง) $\sqrt{2} + \sqrt{8} = \sqrt{2} + 2\sqrt{2} = 3\sqrt{2}$ เป็นจำนวนอตรรกยะ

ตัวอย่างที่ 2

โจทย์: พิสูจน์ว่า $\sqrt{2}$ เป็นจำนวนอตรรกยะ

วิธีทำ: (พิสูจน์โดยวิธีตรงข้าม)

สมมติว่า $\sqrt{2}$ เป็นจำนวนตรรกยะ

กำหนดให้ $\sqrt{2} = \frac{a}{b}$ โดยที่ $\frac{a}{b}$ เป็นเศษส่วนอย่างต่ำ (ห.ร.ม. ของ $a$ และ $b$ เท่ากับ 1)

ยกกำลังสองทั้งสองข้าง: $2 = \frac{a^2}{b^2}$

$a^2 = 2b^2$ แสดงว่า $a^2$ เป็นเลขคู่ ดังนั้น $a$ ต้องเป็นเลขคู่

ให้ $a = 2k$ (โดยที่ $k$ เป็นจำนวนเต็ม)

แทนค่า: $(2k)^2 = 2b^2$

$4k^2 = 2b^2$

$2k^2 = b^2$ แสดงว่า $b^2$ เป็นเลขคู่ ดังนั้น $b$ ต้องเป็นเลขคู่

แต่ถ้า $a$ และ $b$ เป็นเลขคู่ทั้งคู่ แสดงว่าทั้งคู่มีตัวประกอบร่วมคือ 2

ขัดแย้งกับที่สมมติไว้ว่า $\frac{a}{b}$ เป็นเศษส่วนอย่างต่ำ

สรุป: $\sqrt{2}$ ไม่สามารถเขียนในรูปเศษส่วนได้ จึงเป็นจำนวนอตรรกยะ

ตัวอย่างที่ 3

โจทย์: จงหาค่าของ ก) $\sqrt{3} \times \sqrt{12}$    ข) $\sqrt{50} - \sqrt{8}$    ค) $(\sqrt{5})^2$

วิธีทำ:

ก) $\sqrt{3} \times \sqrt{12} = \sqrt{3 \times 12} = \sqrt{36} = 6$ (เป็นจำนวนตรรกยะ)

ข) $\sqrt{50} - \sqrt{8} = \sqrt{25 \times 2} - \sqrt{4 \times 2} = 5\sqrt{2} - 2\sqrt{2} = 3\sqrt{2}$ (เป็นจำนวนอตรรกยะ)

ค) $(\sqrt{5})^2 = 5$ (เป็นจำนวนตรรกยะ)

ตัวอย่างที่ 4

โจทย์: จงเรียงจำนวนต่อไปนี้จากน้อยไปมาก: $\sqrt{7}, 2.5, \frac{8}{3}, \sqrt{10}$

วิธีทำ: เขียนทุกจำนวนในรูปทศนิยมประมาณ

$\sqrt{7} \approx 2.646$

$2.5 = 2.5$

$\frac{8}{3} \approx 2.667$

$\sqrt{10} \approx 3.162$

ตอบ: $2.5 < \sqrt{7} < \frac{8}{3} < \sqrt{10}$

1.3 การดำเนินการจำนวนจริง

สมบัติของการดำเนินการจำนวนจริง

จำนวนจริงมีสมบัติพื้นฐานในการดำเนินการดังนี้:

สมบัติการบวกและการคูณ

1. สมบัติการสลับที่ (Commutative Property)

  • $a + b = b + a$
  • $a \times b = b \times a$

2. สมบัติการเปลี่ยนหมู่ (Associative Property)

  • $(a + b) + c = a + (b + c)$
  • $(a \times b) \times c = a \times (b \times c)$

3. สมบัติการแจกแจง (Distributive Property)

  • $a(b + c) = ab + ac$
  • $a(b - c) = ab - ac$

4. เอกลักษณ์ (Identity Property)

  • $a + 0 = a$ (0 เป็นเอกลักษณ์ของการบวก)
  • $a \times 1 = a$ (1 เป็นเอกลักษณ์ของการคูณ)

5. สมบัติตรงข้าม (Inverse Property)

  • $a + (-a) = 0$ (ตรงข้ามของการบวก)
  • $a \times \frac{1}{a} = 1, a \neq 0$ (ตรงข้ามของการคูณ)

การดำเนินการกับรากที่สอง

  • $\sqrt{a} \times \sqrt{b} = \sqrt{ab}$ (เมื่อ $a, b \geq 0$)
  • $\frac{\sqrt{a}}{\sqrt{b}} = \sqrt{\frac{a}{b}}$ (เมื่อ $a \geq 0, b > 0$)
  • $\sqrt{a^2} = |a|$
  • $(\sqrt{a})^2 = a$ (เมื่อ $a \geq 0$)

ตัวอย่างที่ 1

โจทย์: จงใช้สมบัติของจำนวนจริงในการคำนวณ $5 \times 23 \times 2$

วิธีทำ:

$5 \times 23 \times 2$

$= 5 \times 2 \times 23$ (ใช้สมบัติการสลับที่)

$= (5 \times 2) \times 23$ (ใช้สมบัติการเปลี่ยนหมู่)

$= 10 \times 23$

$= 230$

ตัวอย่างที่ 2

โจทย์: จงใช้สมบัติการแจกแจงคำนวณ $7(100 - 3)$

วิธีทำ:

$7(100 - 3)$

$= 7 \times 100 - 7 \times 3$ (สมบัติการแจกแจง)

$= 700 - 21$

$= 679$

ตัวอย่างที่ 3

โจทย์: จงทำให้เป็นรูปง่าย

ก) $\sqrt{18} + \sqrt{50} - \sqrt{8}$

ข) $\sqrt{12} \times \sqrt{27}$

ค) $\frac{\sqrt{72}}{\sqrt{2}}$

วิธีทำ:

ก) $\sqrt{18} + \sqrt{50} - \sqrt{8}$

    $= \sqrt{9 \times 2} + \sqrt{25 \times 2} - \sqrt{4 \times 2}$

    $= 3\sqrt{2} + 5\sqrt{2} - 2\sqrt{2}$

    $= 6\sqrt{2}$

ข) $\sqrt{12} \times \sqrt{27}$

    $= \sqrt{12 \times 27}$

    $= \sqrt{324}$

    $= 18$

ค) $\frac{\sqrt{72}}{\sqrt{2}}$

    $= \sqrt{\frac{72}{2}}$

    $= \sqrt{36}$

    $= 6$

ตัวอย่างที่ 4

โจทย์: จงทำให้ตัวส่วนเป็นจำนวนตรรกยะ

ก) $\frac{3}{\sqrt{5}}$    ข) $\frac{2}{\sqrt{3} + 1}$    ค) $\frac{6}{\sqrt{7} - \sqrt{2}}$

วิธีทำ:

ก) $\frac{3}{\sqrt{5}} = \frac{3}{\sqrt{5}} \times \frac{\sqrt{5}}{\sqrt{5}} = \frac{3\sqrt{5}}{5}$

ข) $\frac{2}{\sqrt{3} + 1} = \frac{2}{\sqrt{3} + 1} \times \frac{\sqrt{3} - 1}{\sqrt{3} - 1}$

    $= \frac{2(\sqrt{3} - 1)}{(\sqrt{3})^2 - 1^2}$

    $= \frac{2\sqrt{3} - 2}{3 - 1}$

    $= \frac{2\sqrt{3} - 2}{2}$

    $= \sqrt{3} - 1$

ค) $\frac{6}{\sqrt{7} - \sqrt{2}} = \frac{6}{\sqrt{7} - \sqrt{2}} \times \frac{\sqrt{7} + \sqrt{2}}{\sqrt{7} + \sqrt{2}}$

    $= \frac{6(\sqrt{7} + \sqrt{2})}{7 - 2}$

    $= \frac{6(\sqrt{7} + \sqrt{2})}{5}$

    $= \frac{6\sqrt{7} + 6\sqrt{2}}{5}$

1.4 รากที่สามและรากที่ n

ความหมาย

รากที่ $n$ (n-th root) ของจำนวน $a$ คือจำนวน $b$ ที่เมื่อยกกำลัง $n$ แล้วได้ $a$

เขียนแทนด้วย $\sqrt[n]{a} = b$ เมื่อ $b^n = a$

  • $n = 2$ คือรากที่สอง เขียน $\sqrt{a}$ หรือ $\sqrt[2]{a}$
  • $n = 3$ คือรากที่สาม เขียน $\sqrt[3]{a}$
  • $n = 4$ คือรากที่สี่ เขียน $\sqrt[4]{a}$

สมบัติของรากที่ n

เมื่อ $n$ เป็นจำนวนคี่:

  • $\sqrt[n]{a}$ มีค่าเดียว (ไม่ว่า $a$ จะเป็นบวก ลบ หรือศูนย์)
  • $\sqrt[n]{-a} = -\sqrt[n]{a}$
  • ตัวอย่าง: $\sqrt[3]{8} = 2, \sqrt[3]{-8} = -2$

เมื่อ $n$ เป็นจำนวนคู่:

  • $\sqrt[n]{a}$ หมายถึงค่าบวก (principal root) เมื่อ $a > 0$
  • $\sqrt[n]{a}$ ไม่นิยามเมื่อ $a < 0$
  • ตัวอย่าง: $\sqrt[4]{16} = 2$ (ไม่ใช่ $\pm 2$)

กฎการคำนวณรากที่ n

  • $\sqrt[n]{a} \times \sqrt[n]{b} = \sqrt[n]{ab}$
  • $\frac{\sqrt[n]{a}}{\sqrt[n]{b}} = \sqrt[n]{\frac{a}{b}}$ (เมื่อ $b \neq 0$)
  • $\sqrt[n]{a^n} = |a|$ (เมื่อ $n$ เป็นเลขคู่), $= a$ (เมื่อ $n$ เป็นเลขคี่)
  • $(\sqrt[n]{a})^n = a$
  • $\sqrt[m]{\sqrt[n]{a}} = \sqrt[mn]{a}$

ตัวอย่างที่ 1

โจทย์: จงหาค่าของ

ก) $\sqrt[3]{27}$    ข) $\sqrt[3]{-64}$    ค) $\sqrt[4]{81}$    ง) $\sqrt[5]{-32}$

วิธีทำ:

ก) $\sqrt[3]{27} = \sqrt[3]{3^3} = 3$

ข) $\sqrt[3]{-64} = \sqrt[3]{(-4)^3} = -4$

ค) $\sqrt[4]{81} = \sqrt[4]{3^4} = 3$

ง) $\sqrt[5]{-32} = \sqrt[5]{(-2)^5} = -2$

ตัวอย่างที่ 2

โจทย์: จงทำให้เป็นรูปง่าย

ก) $\sqrt[3]{54}$    ข) $\sqrt[3]{16} \times \sqrt[3]{2}$    ค) $\frac{\sqrt[3]{40}}{\sqrt[3]{5}}$

วิธีทำ:

ก) $\sqrt[3]{54} = \sqrt[3]{27 \times 2} = \sqrt[3]{3^3 \times 2} = 3\sqrt[3]{2}$

ข) $\sqrt[3]{16} \times \sqrt[3]{2} = \sqrt[3]{16 \times 2} = \sqrt[3]{32} = \sqrt[3]{2^5} = \sqrt[3]{8 \times 4} = 2\sqrt[3]{4}$

ค) $\frac{\sqrt[3]{40}}{\sqrt[3]{5}} = \sqrt[3]{\frac{40}{5}} = \sqrt[3]{8} = 2$

ตัวอย่างที่ 3

โจทย์: จงคำนวณ $\sqrt[3]{2} \times \sqrt[3]{4} \times \sqrt[3]{8}$

วิธีทำ:

$\sqrt[3]{2} \times \sqrt[3]{4} \times \sqrt[3]{8}$

$= \sqrt[3]{2 \times 4 \times 8}$

$= \sqrt[3]{64}$

$= \sqrt[3]{4^3}$

$= 4$

ตัวอย่างที่ 4

โจทย์: จงหาค่า $x$ ที่ทำให้

ก) $\sqrt[3]{x} = 5$    ข) $\sqrt[4]{x} = 3$    ค) $\sqrt[3]{x + 1} = 2$

วิธีทำ:

ก) $\sqrt[3]{x} = 5$

    ยกกำลัง 3 ทั้งสองข้าง: $x = 5^3 = 125$

ข) $\sqrt[4]{x} = 3$

    ยกกำลัง 4 ทั้งสองข้าง: $x = 3^4 = 81$

ค) $\sqrt[3]{x + 1} = 2$

    ยกกำลัง 3 ทั้งสองข้าง: $x + 1 = 2^3 = 8$

    $x = 7$

1.5 เลขยกกำลังเศษส่วน

ความหมาย

เลขยกกำลังเศษส่วน เป็นวิธีการเขียนรากที่ $n$ ในรูปของเลขยกกำลัง

$$a^{\frac{m}{n}} = \sqrt[n]{a^m} = (\sqrt[n]{a})^m$$

โดยเฉพาะ: $a^{\frac{1}{n}} = \sqrt[n]{a}$

กฎของเลขยกกำลังเศษส่วน

  • $a^{\frac{m}{n}} = \sqrt[n]{a^m} = (\sqrt[n]{a})^m$
  • $a^{\frac{1}{n}} = \sqrt[n]{a}$
  • $a^{-\frac{m}{n}} = \frac{1}{a^{\frac{m}{n}}}$
  • $(a^m)^n = a^{mn}$
  • $a^m \times a^n = a^{m+n}$
  • $\frac{a^m}{a^n} = a^{m-n}$
  • $(ab)^m = a^m b^m$
  • $\left(\frac{a}{b}\right)^m = \frac{a^m}{b^m}$

ตัวอย่างที่ 1

โจทย์: จงเขียนในรูปเลขยกกำลังเศษส่วน

ก) $\sqrt{5}$    ข) $\sqrt[3]{7}$    ค) $\sqrt[4]{x^3}$    ง) $(\sqrt[5]{a})^2$

วิธีทำ:

ก) $\sqrt{5} = 5^{\frac{1}{2}}$

ข) $\sqrt[3]{7} = 7^{\frac{1}{3}}$

ค) $\sqrt[4]{x^3} = x^{\frac{3}{4}}$

ง) $(\sqrt[5]{a})^2 = (a^{\frac{1}{5}})^2 = a^{\frac{2}{5}}$

ตัวอย่างที่ 2

โจทย์: จงหาค่าของ

ก) $8^{\frac{1}{3}}$    ข) $16^{\frac{3}{4}}$    ค) $27^{\frac{2}{3}}$    ง) $32^{\frac{2}{5}}$

วิธีทำ:

ก) $8^{\frac{1}{3}} = \sqrt[3]{8} = 2$

ข) $16^{\frac{3}{4}} = (\sqrt[4]{16})^3 = 2^3 = 8$

ค) $27^{\frac{2}{3}} = (\sqrt[3]{27})^2 = 3^2 = 9$

ง) $32^{\frac{2}{5}} = (\sqrt[5]{32})^2 = 2^2 = 4$

ตัวอย่างที่ 3

โจทย์: จงทำให้เป็นรูปง่าย

ก) $x^{\frac{1}{2}} \times x^{\frac{1}{3}}$    ข) $\frac{a^{\frac{3}{4}}}{a^{\frac{1}{4}}}$    ค) $(y^{\frac{2}{3}})^{\frac{3}{2}}$

วิธีทำ:

ก) $x^{\frac{1}{2}} \times x^{\frac{1}{3}} = x^{\frac{1}{2} + \frac{1}{3}} = x^{\frac{3+2}{6}} = x^{\frac{5}{6}}$

ข) $\frac{a^{\frac{3}{4}}}{a^{\frac{1}{4}}} = a^{\frac{3}{4} - \frac{1}{4}} = a^{\frac{2}{4}} = a^{\frac{1}{2}}$

ค) $(y^{\frac{2}{3}})^{\frac{3}{2}} = y^{\frac{2}{3} \times \frac{3}{2}} = y^1 = y$

ตัวอย่างที่ 4

โจทย์: จงหาค่าของ

ก) $4^{-\frac{1}{2}}$    ข) $8^{-\frac{2}{3}}$    ค) $\left(\frac{9}{16}\right)^{\frac{1}{2}}$    ง) $\left(\frac{8}{27}\right)^{-\frac{1}{3}}$

วิธีทำ:

ก) $4^{-\frac{1}{2}} = \frac{1}{4^{\frac{1}{2}}} = \frac{1}{\sqrt{4}} = \frac{1}{2}$

ข) $8^{-\frac{2}{3}} = \frac{1}{8^{\frac{2}{3}}} = \frac{1}{(\sqrt[3]{8})^2} = \frac{1}{2^2} = \frac{1}{4}$

ค) $\left(\frac{9}{16}\right)^{\frac{1}{2}} = \frac{9^{\frac{1}{2}}}{16^{\frac{1}{2}}} = \frac{\sqrt{9}}{\sqrt{16}} = \frac{3}{4}$

ง) $\left(\frac{8}{27}\right)^{-\frac{1}{3}} = \left(\frac{27}{8}\right)^{\frac{1}{3}} = \frac{27^{\frac{1}{3}}}{8^{\frac{1}{3}}} = \frac{\sqrt[3]{27}}{\sqrt[3]{8}} = \frac{3}{2}$

1.6 การประมาณค่า

ความหมาย

การประมาณค่า คือการหาค่าใกล้เคียงของจำนวนที่ซับซ้อน โดยใช้จำนวนที่เรียบง่ายกว่า มี 2 วิธีหลัก:

  • การปัดเศษ: ปัดค่าให้เหลือจำนวนหลักที่ต้องการ
  • การประมาณจำนวนอตรรกยะ: หาค่าใกล้เคียงโดยใช้จำนวนที่รู้แล้ว

หลักการปัดเศษ

  • ถ้าตัวเลขหลักถัดไป < 5 ให้ปัดลง (คงค่าเดิม)
  • ถ้าตัวเลขหลักถัดไป ≥ 5 ให้ปัดขึ้น (เพิ่มค่า 1)

ตัวอย่าง:

  • 3.14159 ≈ 3.14 (ปัดทศนิยม 2 ตำแหน่ง)
  • 3.14159 ≈ 3.1 (ปัดทศนิยม 1 ตำแหน่ง)
  • 3.14159 ≈ 3 (ปัดเป็นจำนวนเต็ม)

การประมาณค่ารากที่สอง

ใช้จำนวนกำลังสองสมบูรณ์ที่ใกล้เคียง:

  • $1^2 = 1, 2^2 = 4, 3^2 = 9, 4^2 = 16, 5^2 = 25, ...$
  • $6^2 = 36, 7^2 = 49, 8^2 = 64, 9^2 = 81, 10^2 = 100$

วิธีประมาณ: หาจำนวนเต็มสองจำนวนที่รากที่สองของมันอยู่ระหว่างจำนวนที่ต้องการหา

ตัวอย่างที่ 1

โจทย์: จงประมาณค่า $\sqrt{50}$ โดยให้ค่าเป็นจำนวนเต็มที่ใกล้เคียงที่สุด

วิธีทำ:

หาจำนวนกำลังสองสมบูรณ์ที่ใกล้เคียงกับ 50:

$7^2 = 49$ และ $8^2 = 64$

ดังนั้น $7 < \sqrt{50} < 8$

เนื่องจาก $50 - 49 = 1$ และ $64 - 50 = 14$

$\sqrt{50}$ ใกล้ 7 มากกว่า 8

ตอบ: $\sqrt{50} \approx 7$ (ค่าจริง ≈ 7.07)

ตัวอย่างที่ 2

โจทย์: จงประมาณค่า $\sqrt{75}$ ให้เป็นทศนิยม 1 ตำแหน่ง

วิธีทำ:

$8^2 = 64$ และ $9^2 = 81$

ดังนั้น $8 < \sqrt{75} < 9$

หาค่ากลาง: $75 - 64 = 11$ และ $81 - 75 = 6$

$\sqrt{75}$ อยู่ประมาณ $\frac{11}{11+6} = \frac{11}{17} \approx 0.65$ ของช่วาง

$\sqrt{75} \approx 8 + 0.65 = 8.65$

ปัดทศนิยม 1 ตำแหน่ง: $\sqrt{75} \approx 8.7$

ตอบ: $\sqrt{75} \approx 8.7$ (ค่าจริง ≈ 8.66)

ตัวอย่างที่ 3

โจทย์: จงปัดเศษ $\pi + \sqrt{2}$ ให้เป็นทศนิยม 2 ตำแหน่ง

วิธีทำ:

$\pi \approx 3.14159...$

$\sqrt{2} \approx 1.41421...$

$\pi + \sqrt{2} \approx 3.14159 + 1.41421$

$\approx 4.55580...$

ปัดทศนิยม 2 ตำแหน่ง: $4.56$

ตอบ: $\pi + \sqrt{2} \approx 4.56$

ตัวอย่างที่ 4

โจทย์: จงประมาณค่า $\sqrt[3]{100}$ โดยให้อยู่ระหว่างจำนวนเต็มสองจำนวน

วิธีทำ:

หาจำนวนกำลังสามสมบูรณ์ที่ใกล้เคียง:

$4^3 = 64$ และ $5^3 = 125$

เนื่องจาก $64 < 100 < 125$

ดังนั้น $4 < \sqrt[3]{100} < 5$

เนื่องจาก $100 - 64 = 36$ และ $125 - 100 = 25$

$\sqrt[3]{100}$ ใกล้ 5 มากกว่า 4

ตอบ: $4 < \sqrt[3]{100} < 5$ และ $\sqrt[3]{100} \approx 4.6$ (ค่าจริง ≈ 4.64)

แบบฝึกหัดบทที่ 1

ส่วนที่ 1: จำนวนจริงและจำนวนตรรกยะ (3 คะแนน)

  1. จงระบุว่าจำนวนต่อไปนี้เป็นจำนวนตรรกยะหรืออตรรกยะ: $0.125, \sqrt{36}, \sqrt{11}, \frac{7}{9}, \pi$
  2. จงเขียน $0.\overline{6}$ ในรูปเศษส่วนอย่างต่ำ
  3. จงหาจำนวนตรรกยะ 2 จำนวนที่อยู่ระหว่าง $\frac{2}{5}$ และ $\frac{1}{2}$

เฉลย ส่วนที่ 1:

1. $0.125 = \frac{125}{1000} = \frac{1}{8}$ (ตรรกยะ), $\sqrt{36} = 6$ (ตรรกยะ), $\sqrt{11}$ (อตรรกยะ), $\frac{7}{9}$ (ตรรกยะ), $\pi$ (อตรรกยะ)

2. ให้ $x = 0.\overline{6} = 0.666...$

    $10x = 6.666...$

    $10x - x = 6$

    $9x = 6$

    $x = \frac{6}{9} = \frac{2}{3}$

3. $\frac{2}{5} = 0.4, \frac{1}{2} = 0.5$

    ตัวอย่าง: $0.42 = \frac{42}{100} = \frac{21}{50}$ และ $0.45 = \frac{45}{100} = \frac{9}{20}$

ส่วนที่ 2: การดำเนินการกับรากที่สอง (3 คะแนน)

  1. จงทำให้เป็นรูปง่าย: $\sqrt{32} + \sqrt{98} - \sqrt{18}$
  2. จงคำนวณ: $\sqrt{6} \times \sqrt{24}$
  3. จงทำให้ตัวส่วนเป็นจำนวนตรรกยะ: $\frac{5}{\sqrt{2} + \sqrt{3}}$

เฉลย ส่วนที่ 2:

4. $\sqrt{32} + \sqrt{98} - \sqrt{18}$

    $= \sqrt{16 \times 2} + \sqrt{49 \times 2} - \sqrt{9 \times 2}$

    $= 4\sqrt{2} + 7\sqrt{2} - 3\sqrt{2} = 8\sqrt{2}$

5. $\sqrt{6} \times \sqrt{24} = \sqrt{6 \times 24} = \sqrt{144} = 12$

6. $\frac{5}{\sqrt{2} + \sqrt{3}} = \frac{5}{\sqrt{2} + \sqrt{3}} \times \frac{\sqrt{3} - \sqrt{2}}{\sqrt{3} - \sqrt{2}}$

    $= \frac{5(\sqrt{3} - \sqrt{2})}{3 - 2} = 5\sqrt{3} - 5\sqrt{2}$

ส่วนที่ 3: รากที่สามและรากที่ n (3 คะแนน)

  1. จงหาค่าของ: $\sqrt[3]{-125}, \sqrt[4]{256}, \sqrt[5]{243}$
  2. จงทำให้เป็นรูปง่าย: $\sqrt[3]{54} + \sqrt[3]{128}$
  3. จงหาค่า $x$ ที่ทำให้ $\sqrt[3]{2x - 1} = 3$

เฉลย ส่วนที่ 3:

7. $\sqrt[3]{-125} = \sqrt[3]{(-5)^3} = -5$

    $\sqrt[4]{256} = \sqrt[4]{4^4} = 4$

    $\sqrt[5]{243} = \sqrt[5]{3^5} = 3$

8. $\sqrt[3]{54} + \sqrt[3]{128}$

    $= \sqrt[3]{27 \times 2} + \sqrt[3]{64 \times 2}$

    $= 3\sqrt[3]{2} + 4\sqrt[3]{2} = 7\sqrt[3]{2}$

9. $\sqrt[3]{2x - 1} = 3$

    ยกกำลัง 3: $2x - 1 = 27$

    $2x = 28$

    $x = 14$

ส่วนที่ 4: เลขยกกำลังเศษส่วน (3 คะแนน)

  1. จงเขียนในรูปเลขยกกำลังเศษส่วน: $\sqrt[4]{x^5}, (\sqrt[3]{a^2})^4$
  2. จงหาค่าของ: $64^{\frac{2}{3}}, 125^{-\frac{1}{3}}, \left(\frac{16}{81}\right)^{\frac{3}{4}}$
  3. จงทำให้เป็นรูปง่าย: $a^{\frac{2}{3}} \times a^{\frac{1}{6}} \div a^{\frac{1}{2}}$

เฉลย ส่วนที่ 4:

10. $\sqrt[4]{x^5} = x^{\frac{5}{4}}$

    $(\sqrt[3]{a^2})^4 = (a^{\frac{2}{3}})^4 = a^{\frac{8}{3}}$

11. $64^{\frac{2}{3}} = (\sqrt[3]{64})^2 = 4^2 = 16$

    $125^{-\frac{1}{3}} = \frac{1}{125^{\frac{1}{3}}} = \frac{1}{\sqrt[3]{125}} = \frac{1}{5}$

    $\left(\frac{16}{81}\right)^{\frac{3}{4}} = \frac{16^{\frac{3}{4}}}{81^{\frac{3}{4}}} = \frac{(\sqrt[4]{16})^3}{(\sqrt[4]{81})^3} = \frac{2^3}{3^3} = \frac{8}{27}$

12. $a^{\frac{2}{3}} \times a^{\frac{1}{6}} \div a^{\frac{1}{2}}$

    $= a^{\frac{2}{3} + \frac{1}{6} - \frac{1}{2}}$

    $= a^{\frac{4+1-3}{6}} = a^{\frac{2}{6}} = a^{\frac{1}{3}}$

ส่วนที่ 5: การประมาณค่า (3 คะแนน)

  1. จงประมาณค่า $\sqrt{60}$ โดยให้อยู่ระหว่างจำนวนเต็มสองจำนวน และบอกว่าใกล้จำนวนใดมากกว่า
  2. จงปัดเศษ $3\sqrt{2} + \pi$ ให้เป็นทศนิยม 2 ตำแหน่ง (กำหนดให้ $\sqrt{2} \approx 1.414, \pi \approx 3.142$)
  3. จงเรียงจำนวนต่อไปนี้จากน้อยไปมาก: $\sqrt{15}, 3.8, \frac{15}{4}, \sqrt[3]{60}$

เฉลย ส่วนที่ 5:

13. $7^2 = 49, 8^2 = 64$

    ดังนั้น $7 < \sqrt{60} < 8$

    $60 - 49 = 11, 64 - 60 = 4$

    $\sqrt{60}$ ใกล้ 8 มากกว่า

14. $3\sqrt{2} + \pi \approx 3(1.414) + 3.142$

    $\approx 4.242 + 3.142 = 7.384$

    ปัดทศนิยม 2 ตำแหน่ง: $7.38$

15. $\sqrt{15} \approx 3.873, 3.8 = 3.8, \frac{15}{4} = 3.75, \sqrt[3]{60} \approx 3.915$

    เรียง: $\frac{15}{4} < 3.8 < \sqrt{15} < \sqrt[3]{60}$
