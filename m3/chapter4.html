บทที่ 4: ฟังก์ชัน

ฟังก์ชัน เป็นความสัมพันธ์พิเศษระหว่างสองเซต ซึ่งเป็นแนวคิดพื้นฐานที่สำคัญในคณิตศาสตร์ ในบทนี้จะศึกษาความหมายของฟังก์ชัน กราฟของฟังก์ชัน โดยเฉพาะฟังก์ชันเชิงเส้น การหาความชัน สมการเส้นตรง และการประยุกต์ใช้ในชีวิตประจำวัน ซึ่งจะเป็นพื้นฐานสำหรับการศึกษาฟังก์ชันที่ซับซ้อนยิ่งขึ้นในระดับที่สูงขึ้น

4.1 ความหมายของฟังก์ชัน

ความหมาย

ฟังก์ชัน (Function) คือ ความสัมพันธ์จากเซต $A$ ไปยังเซต $B$ ซึ่งสมาชิกแต่ละตัวในเซต $A$ สัมพันธ์กับสมาชิกในเซต $B$ ได้เพียงตัวเดียว

สัญลักษณ์: เขียนแทนฟังก์ชันด้วย $f, g, h$ หรือตัวอักษรอื่นๆ

ถ้า $f$ เป็นฟังก์ชันจาก $A$ ไป $B$ เขียนแทนด้วย $f: A \rightarrow B$

$$f(x) = y$$

อ่านว่า "$f$ ของ $x$ เท่ากับ $y$" หมายความว่า เมื่อนำค่า $x$ ไปแทนในฟังก์ชัน $f$ จะได้ค่า $y$

คำศัพท์สำคัญ:

  • โดเมน (Domain): เซตของค่า $x$ ทั้งหมดที่สามารถนำเข้าไปในฟังก์ชันได้
  • เรนจ์ (Range): เซตของค่า $y$ ทั้งหมดที่ได้จากฟังก์ชัน
  • ตัวแปรอิสระ (Independent Variable): ตัวแปร $x$
  • ตัวแปรตาม (Dependent Variable): ตัวแปร $y$ ซึ่งขึ้นอยู่กับค่า $x$

ตัวอย่างที่ 1: พิจารณาว่าเป็นฟังก์ชันหรือไม่

โจทย์: ความสัมพันธ์ต่อไปนี้ ข้อใดเป็นฟังก์ชัน
ก. $(1, 2), (2, 3), (3, 4), (4, 5)$
ข. $(1, 2), (2, 3), (1, 4), (3, 5)$
ค. $(1, 5), (2, 5), (3, 5), (4, 5)$

วิธีทำ:

ข้อ ก. สมาชิกแต่ละตัวในโดเมน $\{1, 2, 3, 4\}$ สัมพันธ์กับสมาชิกในเรนจ์ได้เพียงตัวเดียว
ดังนั้น เป็นฟังก์ชัน

ข้อ ข. สมาชิก $1$ สัมพันธ์กับทั้ง $2$ และ $4$ (มากกว่าหนึ่งตัว)
ดังนั้น ไม่เป็นฟังก์ชัน

ข้อ ค. สมาชิกแต่ละตัวในโดเมน $\{1, 2, 3, 4\}$ สัมพันธ์กับสมาชิก $5$ เพียงตัวเดียว
ดังนั้น เป็นฟังก์ชัน

ตอบ ข้อ ก. และ ข้อ ค. เป็นฟังก์ชัน ส่วนข้อ ข. ไม่เป็นฟังก์ชัน

ตัวอย่างที่ 2: หาค่าของฟังก์ชัน

โจทย์: ถ้า $f(x) = 2x + 3$ จงหาค่า
ก. $f(0)$
ข. $f(2)$
ค. $f(-1)$

วิธีทำ:

ก. $f(0) = 2(0) + 3 = 0 + 3 = 3$

ข. $f(2) = 2(2) + 3 = 4 + 3 = 7$

ค. $f(-1) = 2(-1) + 3 = -2 + 3 = 1$

ตอบ $f(0) = 3, f(2) = 7, f(-1) = 1$

ตัวอย่างที่ 3: หาค่า x เมื่อกำหนด f(x)

โจทย์: ถ้า $f(x) = 3x - 5$ และ $f(a) = 10$ จงหาค่า $a$

วิธีทำ:

จาก $f(a) = 10$

$$3a - 5 = 10$$

$$3a = 15$$

$$a = 5$$

ตรวจสอบ: $f(5) = 3(5) - 5 = 15 - 5 = 10$ ✓

ตอบ $a = 5$

ตัวอย่างที่ 4: ฟังก์ชันในชีวิตประจำวัน

โจทย์: ร้านเช่ารถจักรยานคิดค่าเช่า 20 บาทต่อชั่วโมง จงเขียนฟังก์ชันที่แสดงความสัมพันธ์ระหว่างเวลาที่เช่า (ชั่วโมง) กับค่าเช่า (บาท) แล้วหาค่าเช่าถ้าเช่า 3 ชั่วโมง

วิธีทำ:

กำหนดให้ $x$ = เวลาที่เช่า (ชั่วโมง)

และ $f(x)$ = ค่าเช่า (บาท)

จากโจทย์: ค่าเช่า = 20 × เวลาที่เช่า

$$f(x) = 20x$$

เมื่อเช่า 3 ชั่วโมง:

$$f(3) = 20(3) = 60 \text{ บาท}$$

ตอบ ฟังก์ชันคือ $f(x) = 20x$ และค่าเช่า 3 ชั่วโมง เท่ากับ 60 บาท

4.2 กราฟของฟังก์ชัน

ความหมาย

กราฟของฟังก์ชัน คือ ภาพแทนของฟังก์ชันบนระนาบพิกัด ซึ่งประกอบด้วยจุด $(x, y)$ ทุกจุดที่ $y = f(x)$

วิธีเขียนกราฟของฟังก์ชัน:

  1. สร้างตารางค่า โดยเลือกค่า $x$ หลายๆ ค่า
  2. คำนวณหาค่า $y = f(x)$ สำหรับแต่ละค่า $x$
  3. ลงจุด $(x, y)$ บนระนาบพิกัด
  4. ลากเส้นหรือเชื่อมจุดต่างๆ

การทดสอบว่ากราฟเป็นกราฟของฟังก์ชันหรือไม่:

ใช้ การทดสอบด้วยเส้นตรงแนวตั้ง (Vertical Line Test) - ถ้าเส้นตรงแนวตั้งใดๆ ตัดกราฟได้ไม่เกิน 1 จุด แสดงว่ากราฟนั้นเป็นกราฟของฟังก์ชัน

ตัวอย่างที่ 1: สร้างตารางค่าและกราฟ

โจทย์: จงสร้างตารางค่าและเขียนกราฟของฟังก์ชัน $f(x) = x + 2$ เมื่อ $x \in \{-2, -1, 0, 1, 2\}$

วิธีทำ:

สร้างตารางค่า:

$x$ -2 -1 0 1 2
$f(x) = x + 2$ 0 1 2 3 4

จุดบนกราฟ: $(-2, 0), (-1, 1), (0, 2), (1, 3), (2, 4)$

ตอบ ลงจุดทั้ง 5 จุดบนระนาบพิกัดแล้วลากเส้นตรงผ่านจุดเหล่านี้

ตัวอย่างที่ 2: หาค่าจากกราฟ

โจทย์: จากกราฟของฟังก์ชัน $f(x)$ ถ้ากราฟผ่านจุด $(3, 7)$ และ $(-1, -1)$ จงหาค่า
ก. $f(3)$
ข. $f(-1)$
ค. $x$ เมื่อ $f(x) = 7$

วิธีทำ:

ก. กราฟผ่านจุด $(3, 7)$ หมายความว่า เมื่อ $x = 3$ ได้ $y = 7$
ดังนั้น $f(3) = 7$

ข. กราฟผ่านจุด $(-1, -1)$ หมายความว่า เมื่อ $x = -1$ ได้ $y = -1$
ดังนั้น $f(-1) = -1$

ค. หา $x$ เมื่อ $f(x) = 7$ คือหาจุดบนกราฟที่มี $y = 7$
จากกราฟผ่านจุด $(3, 7)$ ดังนั้น $x = 3$

ตอบ ก. $f(3) = 7$ ข. $f(-1) = -1$ ค. $x = 3$

ตัวอย่างที่ 3: กราฟของฟังก์ชันกำลังสอง

โจทย์: จงสร้างตารางค่าของฟังก์ชัน $f(x) = x^2$ เมื่อ $x \in \{-2, -1, 0, 1, 2\}$

วิธีทำ:

$x$ -2 -1 0 1 2
$f(x) = x^2$ 4 1 0 1 4

จุดบนกราฟ: $(-2, 4), (-1, 1), (0, 0), (1, 1), (2, 4)$

ตอบ กราฟเป็นรูปพาราโบลา (เส้นโค้ง) ที่มีจุดต่ำสุดที่ $(0, 0)$ เปิดขึ้นด้านบน

ตัวอย่างที่ 4: ทดสอบว่าเป็นกราฟของฟังก์ชันหรือไม่

โจทย์: กราฟต่อไปนี้ ข้อใดเป็นกราฟของฟังก์ชัน
ก. วงกลม
ข. เส้นตรงแนวนอน
ค. เส้นตรงแนวตั้ง

วิธีทำ: ใช้การทดสอบด้วยเส้นตรงแนวตั้ง

ก. วงกลม: เส้นตรงแนวตั้งบางเส้นตัดวงกลมได้ 2 จุด
ดังนั้น ไม่เป็นกราฟของฟังก์ชัน

ข. เส้นตรงแนวนอน: เส้นตรงแนวตั้งทุกเส้นตัดเส้นตรงแนวนอนได้ 1 จุด
ดังนั้น เป็นกราฟของฟังก์ชัน

ค. เส้นตรงแนวตั้ง: มีเส้นตรงแนวตั้งที่ซ้อนทับกับกราฟ ตัดได้เป็นจำนวนอนันต์
ดังนั้น ไม่เป็นกราฟของฟังก์ชัน

ตอบ เฉพาะข้อ ข. เท่านั้นที่เป็นกราฟของฟังก์ชัน

4.3 ฟังก์ชันเชิงเส้น

ความหมาย

ฟังก์ชันเชิงเส้น (Linear Function) คือ ฟังก์ชันที่อยู่ในรูป

$$f(x) = ax + b$$

เมื่อ $a$ และ $b$ เป็นค่าคงที่ และ $a \neq 0$

ลักษณะของกราฟฟังก์ชันเชิงเส้น:

  • กราฟเป็นเส้นตรง
  • $a$ คือความชัน (slope) ของเส้นตรง
  • $b$ คือจุดตัดแกน $y$ (y-intercept)
  • ถ้า $a > 0$ เส้นตรงลาดขึ้น
  • ถ้า $a < 0$ เส้นตรงลาดลง
  • ถ้า $a = 0$ เส้นตรงเป็นแนวนอน

ตัวอย่างที่ 1: ระบุว่าเป็นฟังก์ชันเชิงเส้นหรือไม่

โจทย์: ฟังก์ชันต่อไปนี้ ข้อใดเป็นฟังก์ชันเชิงเส้น
ก. $f(x) = 3x + 5$
ข. $f(x) = x^2 - 1$
ค. $f(x) = 7 - 2x$
ง. $f(x) = \frac{1}{x}$

วิธีทำ:

ก. $f(x) = 3x + 5$ อยู่ในรูป $ax + b$ โดย $a = 3, b = 5$ → เป็นฟังก์ชันเชิงเส้น

ข. $f(x) = x^2 - 1$ มีเลขยกกำลัง 2 → ไม่เป็นฟังก์ชันเชิงเส้น

ค. $f(x) = 7 - 2x = -2x + 7$ อยู่ในรูป $ax + b$ โดย $a = -2, b = 7$ → เป็นฟังก์ชันเชิงเส้น

ง. $f(x) = \frac{1}{x}$ ไม่อยู่ในรูป $ax + b$ → ไม่เป็นฟังก์ชันเชิงเส้น

ตอบ ข้อ ก. และ ค. เป็นฟังก์ชันเชิงเส้น

ตัวอย่างที่ 2: หาจุดตัดแกน

โจทย์: จงหาจุดตัดแกน $x$ และแกน $y$ ของกราฟฟังก์ชัน $f(x) = 2x - 4$

วิธีทำ:

หาจุดตัดแกน y: กำหนด $x = 0$

$$f(0) = 2(0) - 4 = -4$$

ดังนั้น จุดตัดแกน $y$ คือ $(0, -4)$

หาจุดตัดแกน x: กำหนด $f(x) = 0$

$$2x - 4 = 0$$

$$2x = 4$$

$$x = 2$$

ดังนั้น จุดตัดแกน $x$ คือ $(2, 0)$

ตอบ จุดตัดแกน $x$ คือ $(2, 0)$ และจุดตัดแกน $y$ คือ $(0, -4)$

ตัวอย่างที่ 3: เขียนกราฟฟังก์ชันเชิงเส้น

โจทย์: จงเขียนกราฟของฟังก์ชัน $f(x) = -x + 3$

วิธีทำ:

วิธีที่ 1: หาจุดตัดแกน

จุดตัดแกน $y$: กำหนด $x = 0 \Rightarrow f(0) = 3$ ได้จุด $(0, 3)$

จุดตัดแกน $x$: กำหนด $f(x) = 0 \Rightarrow -x + 3 = 0 \Rightarrow x = 3$ ได้จุด $(3, 0)$

ลงจุด $(0, 3)$ และ $(3, 0)$ แล้วลากเส้นตรงผ่านจุดทั้งสอง

วิธีที่ 2: ใช้ความชันและจุดตัดแกน y

จาก $f(x) = -x + 3$ มี $a = -1$ (ความชัน) และ $b = 3$ (จุดตัดแกน $y$)

เริ่มที่จุด $(0, 3)$ แล้วเคลื่อนตามความชัน -1 (ลง 1 ขวา 1)

ตอบ กราฟเป็นเส้นตรงผ่านจุด $(0, 3)$ และ $(3, 0)$ ลาดลงจากซ้ายไปขวา

ตัวอย่างที่ 4: การประยุกต์

โจทย์: อุณหภูมิในเซลเซียส ($C$) สามารถเปลี่ยนเป็นฟาเรนไฮต์ ($F$) โดยใช้สูตร $F = \frac{9}{5}C + 32$ จงหาอุณหภูมิในฟาเรนไฮต์เมื่ออุณหภูมิในเซลเซียสเท่ากับ 25 องศา

วิธีทำ:

แทน $C = 25$ ในสูตร

$$F = \frac{9}{5}(25) + 32$$

$$F = 9 \times 5 + 32$$

$$F = 45 + 32$$

$$F = 77$$

ตอบ อุณหภูมิ 25 องศาเซลเซียส เท่ากับ 77 องศาฟาเรนไฮต์
