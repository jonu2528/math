บทที่ 4: เรขาคณิต

เรขาคณิตเป็นสาขาของคณิตศาสตร์ที่ศึกษาเกี่ยวกับรูปร่าง ขนาด และตำแหน่งของวัตถุในอวกาศ ในบทนี้เราจะเรียนรู้เกี่ยวกับรูปเรขาคณิตพื้นฐาน มุม และคุณสมบัติต่างๆ ของรูปเรขาคณิต

4.1 จุด เส้นตรง รังสี และส่วนของเส้นตรง

จุด (Point)

ตำแหน่งในอวกาศที่ไม่มีขนาด แทนด้วยจุดและใช้ตัวอักษรพิมพ์ใหญ่กำกับ เช่น จุด $A$, จุด $B$

เส้นตรง (Line)

เส้นที่ยาวไม่มีที่สิ้นสุดทั้งสองทาง แทนด้วยสัญลักษณ์ $\overleftrightarrow{AB}$ หรือเส้น $AB$

รังสี (Ray)

ส่วนหนึ่งของเส้นตรงที่มีจุดเริ่มต้นและยาวไม่มีที่สิ้นสุดทางเดียว แทนด้วย $\overrightarrow{AB}$

จุด $A$ คือจุดเริ่มต้น และรังสีผ่านจุด $B$

ส่วนของเส้นตรง (Line Segment)

ส่วนหนึ่งของเส้นตรงที่มีจุดปลายทั้งสองข้าง แทนด้วย $\overline{AB}$ หรือ $AB$

ความยาวของส่วนของเส้นตรง $AB$ แทนด้วย $|AB|$ หรือ $AB$

ตัวอย่างที่ 1: การเรียกชื่อเส้นและส่วนของเส้น

โจทย์: ให้จุด $A$, $B$, $C$ อยู่บนเส้นตรงเดียวกัน โดย $B$ อยู่ระหว่าง $A$ และ $C$

จงเขียนสัญลักษณ์ของ:

  • เส้นตรงที่ผ่านจุดทั้งสาม: $\overleftrightarrow{AC}$ หรือ $\overleftrightarrow{AB}$ หรือ $\overleftrightarrow{BC}$
  • รังสีที่มีจุดเริ่มต้นที่ $B$ และผ่าน $C$: $\overrightarrow{BC}$
  • ส่วนของเส้นตรงที่มีจุดปลายคือ $A$ และ $C$: $\overline{AC}$

จุดกึ่งกลาง (Midpoint)

จุดที่แบ่งส่วนของเส้นตรงออกเป็นสองส่วนเท่ากัน

ถ้า $M$ เป็นจุดกึ่งกลางของ $\overline{AB}$ แล้ว $AM = MB = \frac{1}{2}AB$

ตัวอย่างที่ 2: การหาความยาวส่วนของเส้นตรง

โจทย์: ให้ $M$ เป็นจุดกึ่งกลางของ $\overline{AB}$ ถ้า $AB = 24$ ซม. จงหา $AM$

วิธีทำ:

$$AM = \frac{1}{2}AB = \frac{1}{2}(24) = 12 \text{ ซม.}$$

ตัวอย่างที่ 3: จุดบนเส้นตรง

โจทย์: จุด $P$ อยู่บน $\overline{AB}$ โดย $AP = 8$ ซม. และ $PB = 5$ ซม. จงหา $AB$

วิธีทำ:

$$AB = AP + PB = 8 + 5 = 13 \text{ ซม.}$$

4.2 มุมและชนิดของมุม

มุม (Angle)

รูปที่เกิดจากรังสีสองรังสีที่มีจุดเริ่มต้นร่วมกัน

แทนด้วย $\angle ABC$ หรือ $\angle B$ โดย $B$ เป็นจุดยอดของมุม

วัดมุมด้วยหน่วยองศา (degree) แทนด้วย $^\circ$

ชนิดของมุม

  • มุมแหลม (Acute Angle): มุมที่มีขนาด $0^\circ < \theta < 90^\circ$
  • มุมฉาก (Right Angle): มุมที่มีขนาด $90^\circ$
  • มุมป้าน (Obtuse Angle): มุมที่มีขนาด $90^\circ < \theta < 180^\circ$
  • มุมตรง (Straight Angle): มุมที่มีขนาด $180^\circ$
  • มุมสะท้อน (Reflex Angle): มุมที่มีขนาด $180^\circ < \theta < 360^\circ$

ตัวอย่างที่ 4: การจำแนกมุม

โจทย์: จงจำแนกมุมต่อไปนี้

  • $\angle A = 45^\circ$ เป็นมุมแหลม
  • $\angle B = 90^\circ$ เป็นมุมฉาก
  • $\angle C = 120^\circ$ เป็นมุมป้าน
  • $\angle D = 180^\circ$ เป็นมุมตรง

มุมเสริม (Complementary Angles)

มุมสองมุมที่รวมกันได้ $90^\circ$

ถ้า $\angle A + \angle B = 90^\circ$ แล้ว $\angle A$ และ $\angle B$ เป็นมุมเสริมกัน

มุมประกอบ (Supplementary Angles)

มุมสองมุมที่รวมกันได้ $180^\circ$

ถ้า $\angle A + \angle B = 180^\circ$ แล้ว $\angle A$ และ $\angle B$ เป็นมุมประกอบกัน

ตัวอย่างที่ 5: มุมเสริม

โจทย์: ถ้า $\angle A = 35^\circ$ จงหามุมเสริมของ $\angle A$

วิธีทำ:

ให้มุมเสริมเป็น $x$

$$x + 35^\circ = 90^\circ$$

$$x = 90^\circ - 35^\circ = 55^\circ$$

ตัวอย่างที่ 6: มุมประกอบ

โจทย์: ถ้า $\angle B = 110^\circ$ จงหามุมประกอบของ $\angle B$

วิธีทำ:

ให้มุมประกอบเป็น $y$

$$y + 110^\circ = 180^\circ$$

$$y = 180^\circ - 110^\circ = 70^\circ$$

มุมตรงข้ามจุดยอด (Vertical Angles)

เมื่อเส้นตรงสองเส้นตัดกัน จะเกิดมุมตรงข้ามจุดยอดสองคู่

คุณสมบัติ: มุมตรงข้ามจุดยอดมีขนาดเท่ากัน

ตัวอย่างที่ 7: มุมตรงข้ามจุดยอด

โจทย์: เส้นตรง $AB$ และ $CD$ ตัดกันที่จุด $O$ ถ้า $\angle AOC = 65^\circ$ จงหา $\angle BOD$

วิธีทำ:

เนื่องจาก $\angle AOC$ และ $\angle BOD$ เป็นมุมตรงข้ามจุดยอด

$$\angle BOD = \angle AOC = 65^\circ$$

4.3 รูปสามเหลี่ยม

รูปสามเหลี่ยม (Triangle)

รูปปิดที่มีด้านสามด้าน และมีมุมสามมุม

แทนด้วย $\triangle ABC$ โดย $A$, $B$, $C$ เป็นจุดยอด

ทฤษฎีบทผลบวกมุมภายในรูปสามเหลี่ยม

ผลบวกของมุมทั้งสามมุมภายในรูปสามเหลี่ยมเท่ากับ $180^\circ$

$$\angle A + \angle B + \angle C = 180^\circ$$

ตัวอย่างที่ 8: การหามุมในรูปสามเหลี่ยม

โจทย์: ใน $\triangle ABC$ มี $\angle A = 50^\circ$ และ $\angle B = 60^\circ$ จงหา $\angle C$

วิธีทำ:

$$\angle A + \angle B + \angle C = 180^\circ$$

$$50^\circ + 60^\circ + \angle C = 180^\circ$$

$$\angle C = 180^\circ - 110^\circ = 70^\circ$$

การจำแนกรูปสามเหลี่ยมตามมุม

  • สามเหลี่ยมมุมแหลม: มุมทั้งสามเป็นมุมแหลม (น้อยกว่า $90^\circ$)
  • สามเหลี่ยมมุมฉาก: มีมุมหนึ่งเป็นมุมฉาก ($90^\circ$)
  • สามเหลี่ยมมุมป้าน: มีมุมหนึ่งเป็นมุมป้าน (มากกว่า $90^\circ$)

การจำแนกรูปสามเหลี่ยมตามด้าน

  • สามเหลี่ยมด้านเท่า: มีด้านทั้งสามยาวเท่ากัน มุมทั้งสามเท่ากับ $60^\circ$
  • สามเหลี่ยมหน้าจั่ว: มีสองด้านยาวเท่ากัน มุมที่ฐานสองมุมเท่ากัน
  • สามเหลี่ยมด้านไม่เท่า: มีด้านทั้งสามยาวไม่เท่ากัน

ตัวอย่างที่ 9: สามเหลี่ยมหน้าจั่ว

โจทย์: ใน $\triangle ABC$ เป็นสามเหลี่ยมหน้าจั่วที่ $AB = AC$ ถ้า $\angle A = 80^\circ$ จงหา $\angle B$ และ $\angle C$

วิธีทำ:

เนื่องจาก $AB = AC$ ดังนั้น $\angle B = \angle C$ (มุมที่ฐานเท่ากัน)

$$\angle A + \angle B + \angle C = 180^\circ$$

$$80^\circ + \angle B + \angle B = 180^\circ$$

$$2\angle B = 100^\circ$$

$$\angle B = \angle C = 50^\circ$$

ตัวอย่างที่ 10: การหาความยาวด้านในสามเหลี่ยมมุมฉาก

โจทย์: สามเหลี่ยมมุมฉาก $\triangle ABC$ โดยมุม $C$ เป็นมุมฉาก ถ้า $AC = 3$ ซม. และ $BC = 4$ ซม. จงหา $AB$

วิธีทำ:

ใช้ทฤษฎีบทพีทาโกรัส: $AB^2 = AC^2 + BC^2$

$$AB^2 = 3^2 + 4^2 = 9 + 16 = 25$$

$$AB = \sqrt{25} = 5 \text{ ซม.}$$

4.4 รูปสี่เหลี่ยม

รูปสี่เหลี่ยม (Quadrilateral)

รูปปิดที่มีด้านสี่ด้าน และมีมุมสี่มุม

คุณสมบัติ: ผลบวกของมุมภายในรูปสี่เหลี่ยมเท่ากับ $360^\circ$

ตัวอย่างที่ 11: การหามุมในรูปสี่เหลี่ยม

โจทย์: รูปสี่เหลี่ยม $ABCD$ มีมุม $\angle A = 80^\circ$, $\angle B = 110^\circ$, $\angle C = 90^\circ$ จงหา $\angle D$

วิธีทำ:

$$\angle A + \angle B + \angle C + \angle D = 360^\circ$$

$$80^\circ + 110^\circ + 90^\circ + \angle D = 360^\circ$$

$$\angle D = 360^\circ - 280^\circ = 80^\circ$$

รูปสี่เหลี่ยมผืนผ้า (Rectangle)

รูปสี่เหลี่ยมที่มีคุณสมบัติ:

  • มีมุมทั้งสี่เป็นมุมฉาก ($90^\circ$)
  • ด้านตรงข้ามยาวเท่ากันและขนานกัน
  • เส้นทแยงมุมยาวเท่ากันและแบ่งครึ่งกัน

สูตร:

  • พื้นที่ $= l \times w$ (ความยาว × ความกว้าง)
  • ปริมาตร $= 2(l + w)$

รูปสี่เหลี่ยมจัตุรัส (Square)

รูปสี่เหลี่ยมผืนผ้าที่มีด้านทั้งสี่ยาวเท่ากัน

สูตร:

  • พื้นที่ $= s^2$ ($s$ = ความยาวด้าน)
  • ปริมาตร $= 4s$

ตัวอย่างที่ 12: การหาพื้นที่รูปสี่เหลี่ยมผืนผ้า

โจทย์: รูปสี่เหลี่ยมผืนผ้ามีความยาว 8 ซม. และความกว้าง 5 ซม. จงหาพื้นที่และปริมาตร

วิธีทำ:

พื้นที่ $= l \times w = 8 \times 5 = 40$ ตร.ซม.

ปริมาตร $= 2(l + w) = 2(8 + 5) = 2(13) = 26$ ซม.

ตัวอย่างที่ 13: การหาพื้นที่รูปสี่เหลี่ยมจัตุรัส

โจทย์: รูปสี่เหลี่ยมจัตุรัสมีความยาวด้าน 6 ซม. จงหาพื้นที่และปริมาตร

วิธีทำ:

พื้นที่ $= s^2 = 6^2 = 36$ ตร.ซม.

ปริมาตร $= 4s = 4(6) = 24$ ซม.

รูปสี่เหลี่ยมด้านขนาน (Parallelogram)

รูปสี่เหลี่ยมที่มีด้านตรงข้ามขนานกันและยาวเท่ากัน

คุณสมบัติ: มุมตรงข้ามเท่ากัน

สูตร: พื้นที่ $= \text{ฐาน} \times \text{สูง}$

รูปสี่เหลี่ยมคางหมู (Trapezoid)

รูปสี่เหลี่ยมที่มีด้านคู่หนึ่งขนานกัน

สูตร: พื้นที่ $= \frac{1}{2}(a + b) \times h$

โดย $a$ และ $b$ เป็นความยาวของด้านที่ขนานกัน และ $h$ เป็นความสูง

ตัวอย่างที่ 14: การหาพื้นที่รูปสี่เหลี่ยมคางหมู

โจทย์: รูปสี่เหลี่ยมคางหมูมีด้านขนานยาว 10 ซม. และ 6 ซม. สูง 4 ซม. จงหาพื้นที่

วิธีทำ:

$$\text{พื้นที่} = \frac{1}{2}(a + b) \times h$$

$$= \frac{1}{2}(10 + 6) \times 4$$

$$= \frac{1}{2}(16) \times 4 = 8 \times 4 = 32 \text{ ตร.ซม.}$$

4.5 วงกลม

วงกลม (Circle)

เส้นโค้งปิดที่จุดทุกจุดบนเส้นโค้งอยู่ห่างจากจุดคงที่จุดหนึ่งเป็นระยะเท่ากัน

  • จุดศูนย์กลาง (Center): จุดคงที่ที่กล่าวถึง แทนด้วย $O$
  • รูปสำหรับารัศมี (Radius): ระยะห่างจากจุดศูนย์กลางไปยังจุดบนวงกลม แทนด้วย $r$
  • เส้นผ่านศูนย์กลาง (Diameter): ส่วนของเส้นตรงที่ผ่านจุดศูนย์กลางและมีจุดปลายอยู่บนวงกลม แทนด้วย $d$

ความสัมพันธ์: $d = 2r$ หรือ $r = \frac{d}{2}$

เส้นรอบวงและพื้นที่วงกลม

เส้นรอบวง: $C = 2\pi r = \pi d$

พื้นที่: $A = \pi r^2$

โดย $\pi \approx 3.14$ หรือ $\pi \approx \frac{22}{7}$

ตัวอย่างที่ 15: การหารัศมีจากเส้นผ่านศูนย์กลาง

โจทย์: วงกลมมีเส้นผ่านศูนย์กลาง 14 ซม. จงหารัศมี

วิธีทำ:

$$r = \frac{d}{2} = \frac{14}{2} = 7 \text{ ซม.}$$

ตัวอย่างที่ 16: การหาเส้นรอบวงวงกลม

โจทย์: วงกลมมีรัศมี 7 ซม. จงหาเส้นรอบวง (ใช้ $\pi = \frac{22}{7}$)

วิธีทำ:

$$C = 2\pi r = 2 \times \frac{22}{7} \times 7$$

$$= 2 \times 22 = 44 \text{ ซม.}$$

ตัวอย่างที่ 17: การหาพื้นที่วงกลม

โจทย์: วงกลมมีรัศมี 10 ซม. จงหาพื้นที่ (ใช้ $\pi = 3.14$)

วิธีทำ:

$$A = \pi r^2 = 3.14 \times 10^2$$

$$= 3.14 \times 100 = 314 \text{ ตร.ซม.}$$

ส่วนอื่นๆ ของวงกลม

  • คอร์ด (Chord): ส่วนของเส้นตรงที่มีจุดปลายอยู่บนวงกลม
  • ส่วนโค้ง (Arc): ส่วนหนึ่งของเส้นรอบวง
  • สี่เหลี่ยมภาคเซกเตอร์ (Sector): ส่วนของวงกลมที่ถูกล้อมรอบด้วยรัศมีสองเส้นและส่วนโค้ง

4.6 ความสมมาตร

แกนสมมาตร (Line of Symmetry)

เส้นตรงที่แบ่งรูปออกเป็นสองส่วนเท่ากัน โดยส่วนหนึ่งเป็นภาพสะท้อนของอีกส่วนหนึ่ง

ตัวอย่างที่ 18: แกนสมมาตรของรูปต่างๆ

  • รูปสี่เหลี่ยมจัตุรัส: มีแกนสมมาตร 4 เส้น
  • รูปสี่เหลี่ยมผืนผ้า: มีแกนสมมาตร 2 เส้น
  • รูปสามเหลี่ยมด้านเท่า: มีแกนสมมาตร 3 เส้น
  • รูปสามเหลี่ยมหน้าจั่ว: มีแกนสมมาตร 1 เส้น
  • วงกลม: มีแกนสมมาตรจำนวนไม่จำกัด

จุดสมมาตร (Point Symmetry)

รูปที่มีจุดสมมาตร คือ เมื่อหมุนรูปรอบจุดนั้น $180^\circ$ แล้วได้รูปเดิม

ตัวอย่างที่ 19: จุดสมมาตร

  • รูปสี่เหลี่ยมจัตุรัสมีจุดสมมาตรที่จุดศูนย์กลาง
  • รูปสี่เหลี่ยมผืนผ้ามีจุดสมมาตรที่จุดตัดของเส้นทแยงมุม
  • วงกลมมีจุดสมมาตรที่จุดศูนย์กลาง

ตัวอย่างที่ 20: การหาแกนสมมาตร

โจทย์: รูปสี่เหลี่ยมคางหมูที่มีด้านข้างเท่ากันมีแกนสมมาตรกี่เส้น

วิธีทำ:

รูปสี่เหลี่ยมคางหมูที่มีด้านข้างเท่ากันมีแกนสมมาตร 1 เส้น

(เป็นเส้นตั้งฉากกับด้านที่ขนานกันและผ่านจุดกึ่งกลางของด้านทั้งสอง)

↑ กลับไปด้านบน

แบบฝึกหัดบทที่ 4

ส่วนที่ 1: จุด เส้นตรง และมุม (2 คะแนน)

  1. ถ้า $M$ เป็นจุดกึ่งกลางของ $\overline{AB}$ และ $AB = 36$ ซม. จงหา $AM$
  2. ถ้า $\angle A = 25^\circ$ จงหามุมเสริมของ $\angle A$

เฉลย ส่วนที่ 1:

1. $AM = \frac{1}{2}AB = \frac{1}{2}(36) = 18$ ซม.

2. มุมเสริม $= 90^\circ - 25^\circ = 65^\circ$

ส่วนที่ 2: รูปสามเหลี่ยม (2 คะแนน)

  1. ใน $\triangle ABC$ มี $\angle A = 45^\circ$ และ $\angle B = 70^\circ$ จงหา $\angle C$
  2. สามเหลี่ยมมุมฉากมีด้านประมาณมุมฉากยาว 6 ซม. และ 8 ซม. จงหาความยาวด้านตรงข้ามมุมฉาก

เฉลย ส่วนที่ 2:

3. $\angle C = 180^\circ - 45^\circ - 70^\circ = 65^\circ$

4. $c^2 = 6^2 + 8^2 = 36 + 64 = 100$, ดังนั้น $c = 10$ ซม.

ส่วนที่ 3: รูปสี่เหลี่ยม (2 คะแนน)

  1. รูปสี่เหลี่ยมผืนผ้ามีความยาว 12 ซม. และความกว้าง 7 ซม. จงหาพื้นที่
  2. รูปสี่เหลี่ยมจัตุรัสมีความยาวด้าน 9 ซม. จงหาปริมาตร

เฉลย ส่วนที่ 3:

5. พื้นที่ $= 12 \times 7 = 84$ ตร.ซม.

6. ปริมาตร $= 4 \times 9 = 36$ ซม.

ส่วนที่ 4: วงกลม (2 คะแนน)

  1. วงกลมมีรัศมี 14 ซม. จงหาเส้นรอบวง (ใช้ $\pi = \frac{22}{7}$)
  2. วงกลมมีรัศมี 5 ซม. จงหาพื้นที่ (ใช้ $\pi = 3.14$)

เฉลย ส่วนที่ 4:

7. $C = 2\pi r = 2 \times \frac{22}{7} \times 14 = 88$ ซม.

8. $A = \pi r^2 = 3.14 \times 5^2 = 3.14 \times 25 = 78.5$ ตร.ซม.

ส่วนที่ 5: ความสมมาตร (2 คะแนน)

  1. รูปสามเหลี่ยมด้านเท่ามีแกนสมมาตรกี่เส้น
  2. รูปสี่เหลี่ยมคางหมูที่มีด้านขนานยาว 8 ซม. และ 4 ซม. สูง 5 ซม. จงหาพื้นที่

เฉลย ส่วนที่ 5:

9. รูปสามเหลี่ยมด้านเท่ามีแกนสมมาตร 3 เส้น

10. พื้นที่ $= \frac{1}{2}(8 + 4) \times 5 = \frac{1}{2}(12) \times 5 = 30$ ตร.ซม.
