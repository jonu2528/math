บทที่ 3: พีชคณิตเบื้องต้น

พีชคณิตเป็นสาขาหนึ่งของคณิตศาสตร์ที่ใช้ตัวอักษรแทนตัวเลขที่ไม่ทราบค่า เราเรียกตัวอักษรเหล่านี้ว่า "ตัวแปร" การเรียนรู้พีชคณิตจะช่วยให้เราสามารถแก้ปัญหาที่ซับซ้อนได้อย่างมีระบบ

3.1 ตัวแปรและนิพจน์พีชคณิต

ตัวแปร (Variable)

ตัวอักษรที่ใช้แทนค่าของจำนวนที่ไม่ทราบค่า เช่น $x$, $y$, $a$, $b$ เป็นต้น

นิพจน์พีชคณิต (Algebraic Expression)

การนำตัวเลข ตัวแปร และเครื่องหมายดำเนินการมาเรียงต่อกัน เช่น $3x + 5$, $2a - 7$, $x^2 + 3x - 4$

พจน์ (Term)

ส่วนประกอบของนิพจน์ที่คั่นด้วยเครื่องหมาย $+$ หรือ $-$

ในนิพจน์ $3x + 5y - 2$ มีพจน์คือ $3x$, $5y$, และ $-2$

สัมประสิทธิ์ (Coefficient)

ตัวเลขที่อยู่หน้าตัวแปร เช่น ในพจน์ $5x$ สัมประสิทธิ์คือ $5$

พจน์พื้นฐาน (Like Terms)

พจน์ที่มีตัวแปรและเลขชี้กำลังเหมือนกัน เช่น $3x$ และ $7x$ เป็นพจน์พื้นฐานเดียวกัน

ตัวอย่างที่ 1: การระบุส่วนประกอบของนิพจน์

โจทย์: จงระบุจำนวนพจน์ สัมประสิทธิ์ และตัวคงที่ของนิพจน์ $5x - 3y + 7$

วิธีทำ:

  • จำนวนพจน์: 3 พจน์ คือ $5x$, $-3y$, $7$
  • สัมประสิทธิ์ของ $x$ คือ $5$
  • สัมประสิทธิ์ของ $y$ คือ $-3$
  • ตัวคงที่ (Constant) คือ $7$

ตัวอย่างที่ 2: การหาพจน์พื้นฐาน

โจทย์: จากนิพจน์ $4x + 3y - 2x + 5y - 1$ จงระบุพจน์พื้นฐานเดียวกัน

วิธีทำ:

  • พจน์ที่มี $x$: $4x$ และ $-2x$ เป็นพจน์พื้นฐานเดียวกัน
  • พจน์ที่มี $y$: $3y$ และ $5y$ เป็นพจน์พื้นฐานเดียวกัน
  • ตัวคงที่: $-1$

ตัวอย่างที่ 3: การเขียนนิพจน์จากโจทย์

โจทย์: "จำนวนหนึ่งบวกกับ 5 แล้วคูณด้วย 3" เขียนเป็นนิพจน์พีชคณิตได้อย่างไร

วิธีทำ:

ให้จำนวนที่ไม่ทราบค่าเป็น $x$

นิพจน์ที่ได้คือ $3(x + 5)$ หรือ $3x + 15$

3.2 การหาค่าของนิพจน์พีชคณิต

การหาค่าของนิพจน์พีชคณิต คือ การแทนค่าตัวแปรด้วยตัวเลขที่กำหนดให้ แล้วคำนวณหาผลลัพธ์

ตัวอย่างที่ 4: การหาค่านิพจน์เมื่อกำหนดค่าตัวแปร

โจทย์: จงหาค่าของ $3x + 5$ เมื่อ $x = 4$

วิธีทำ:

$$3x + 5 = 3(4) + 5 = 12 + 5 = 17$$

ตัวอย่างที่ 5: นิพจน์ที่มีหลายตัวแปร

โจทย์: จงหาค่าของ $2a - 3b + 4$ เมื่อ $a = 5$ และ $b = 2$

วิธีทำ:

$$2a - 3b + 4 = 2(5) - 3(2) + 4$$

$$= 10 - 6 + 4 = 8$$

ตัวอย่างที่ 6: นิพจน์ที่มีเลขยกกำลัง

โจทย์: จงหาค่าของ $x^2 - 2x + 1$ เมื่อ $x = 3$

วิธีทำ:

$$x^2 - 2x + 1 = (3)^2 - 2(3) + 1$$

$$= 9 - 6 + 1 = 4$$

ตัวอย่างที่ 7: นิพจน์ที่มีเศษส่วน

โจทย์: จงหาค่าของ $\frac{2x + 6}{4}$ เมื่อ $x = 5$

วิธีทำ:

$$\frac{2x + 6}{4} = \frac{2(5) + 6}{4} = \frac{10 + 6}{4} = \frac{16}{4} = 4$$

3.3 การบวกและลบพจน์

กฎการบวกและลบพจน์

  • สามารถบวกหรือลบได้เฉพาะพจน์พื้นฐานเดียวกันเท่านั้น
  • การบวกลบพจน์พื้นฐาน ให้บวกหรือลบสัมประสิทธิ์ แล้วเขียนตัวแปรตาม

ตัวอย่างที่ 8: การบวกพจน์พื้นฐานเดียวกัน

โจทย์: $5x + 3x = ?$

วิธีทำ:

$$5x + 3x = (5 + 3)x = 8x$$

ตัวอย่างที่ 9: การลบพจน์พื้นฐานเดียวกัน

โจทย์: $7y - 4y = ?$

วิธีทำ:

$$7y - 4y = (7 - 4)y = 3y$$

ตัวอย่างที่ 10: การจัดรูปนิพจน์

โจทย์: จัดรูป $4x + 3y - 2x + 5y$

วิธีทำ:

รวมพจน์ที่มี $x$: $4x - 2x = 2x$

รวมพจน์ที่มี $y$: $3y + 5y = 8y$

$$\therefore 4x + 3y - 2x + 5y = 2x + 8y$$

ตัวอย่างที่ 11: การจัดรูปนิพจน์ที่ซับซ้อน

โจทย์: จัดรูป $6a - 2b + 3a - 4b + 7$

วิธีทำ:

รวมพจน์ที่มี $a$: $6a + 3a = 9a$

รวมพจน์ที่มี $b$: $-2b - 4b = -6b$

ตัวคงที่: $7$

$$\therefore 6a - 2b + 3a - 4b + 7 = 9a - 6b + 7$$

⚠️ ข้อควรระวัง

ไม่สามารถบวกหรือลบพจน์ที่มีตัวแปรต่างกันได้ เช่น $3x + 2y$ ไม่สามารถรวมเป็น $5xy$ ได้

↑ กลับไปด้านบน

3.4 การคูณและหารพจน์

กฎการคูณพจน์

  • คูณสัมประสิทธิ์เข้าด้วยกัน
  • คูณตัวแปรโดยใช้กฎเลขยกกำลัง: $x^m \times x^n = x^{m+n}$

ตัวอย่างที่ 12: การคูณพจน์เดี่ยว

โจทย์: $3x \times 4y = ?$

วิธีทำ:

$$3x \times 4y = (3 \times 4)(x \times y) = 12xy$$

ตัวอย่างที่ 13: การคูณพจน์ที่มีตัวแปรเดียวกัน

โจทย์: $5x \times 2x = ?$

วิธีทำ:

$$5x \times 2x = (5 \times 2)(x \times x) = 10x^2$$

ตัวอย่างที่ 14: การกระจายพจน์เดี่ยวเข้าในวงเล็บ

โจทย์: $3(x + 4) = ?$

วิธีทำ:

$$3(x + 4) = 3 \times x + 3 \times 4 = 3x + 12$$

ตัวอย่างที่ 15: การกระจายที่ซับซ้อน

โจทย์: $-2(3x - 5) = ?$

วิธีทำ:

$$-2(3x - 5) = -2 \times 3x - 2 \times (-5)$$

$$= -6x + 10$$

กฎการหารพจน์

  • หารสัมประสิทธิ์ทำนองเดียวกับการหารจำนวน
  • หารตัวแปรโดยใช้กฎเลขยกกำลัง: $x^m \div x^n = x^{m-n}$ (เมื่อ $m > n$)

ตัวอย่างที่ 16: การหารพจน์

โจทย์: $12x \div 4 = ?$

วิธีทำ:

$$12x \div 4 = \frac{12x}{4} = \frac{12}{4}x = 3x$$

ตัวอย่างที่ 17: การหารพจน์ที่มีตัวแปรเหมือนกัน

โจทย์: $15x^3 \div 3x = ?$

วิธีทำ:

$$15x^3 \div 3x = \frac{15x^3}{3x} = \frac{15}{3} \times \frac{x^3}{x} = 5x^2$$

3.5 สมการเชิงเส้นตัวแปรเดียว

สมการเชิงเส้นตัวแปรเดียว

สมการที่มีตัวแปรเพียงตัวเดียวและเลขยกกำลังของตัวแปรเป็น 1 เช่น $x + 5 = 8$, $2x - 3 = 7$

วิธีแก้สมการ

  1. นำพจน์ที่มีตัวแปรไปอยู่ข้างเดียวกัน
  2. นำตัวคงที่ไปอยู่อีกข้างหนึ่ง
  3. หาค่าตัวแปร

หลักสำคัญ: สิ่งที่ทำกับข้างหนึ่งต้องทำกับอีกข้างด้วย

ตัวอย่างที่ 18: แก้สมการพื้นฐาน

โจทย์: แก้สมการ $x + 7 = 12$

วิธีทำ:

$$x + 7 = 12$$

$$x + 7 - 7 = 12 - 7$$

$$x = 5$$

ตัวอย่างที่ 19: สมการที่มีสัมประสิทธิ์

โจทย์: แก้สมการ $3x = 15$

วิธีทำ:

$$3x = 15$$

$$\frac{3x}{3} = \frac{15}{3}$$

$$x = 5$$

ตัวอย่างที่ 20: สมการที่ซับซ้อนขึ้น

โจทย์: แก้สมการ $2x + 5 = 13$

วิธีทำ:

$$2x + 5 = 13$$

$$2x + 5 - 5 = 13 - 5$$

$$2x = 8$$

$$\frac{2x}{2} = \frac{8}{2}$$

$$x = 4$$

ตัวอย่างที่ 21: สมการที่มีตัวแปรทั้งสองข้าง

โจทย์: แก้สมการ $5x - 3 = 2x + 9$

วิธีทำ:

$$5x - 3 = 2x + 9$$

$$5x - 2x = 9 + 3$$

$$3x = 12$$

$$x = 4$$

ตัวอย่างที่ 22: สมการที่มีวงเล็บ

โจทย์: แก้สมการ $3(x - 2) = 12$

วิธีทำ:

$$3(x - 2) = 12$$

$$3x - 6 = 12$$

$$3x = 12 + 6$$

$$3x = 18$$

$$x = 6$$

3.6 การแก้โจทย์ปัญหา

ขั้นตอนการแก้โจทย์ปัญหา

  1. อ่านโจทย์ให้เข้าใจ
  2. กำหนดตัวแปรให้กับสิ่งที่ไม่ทราบค่า
  3. เขียนสมการจากโจทย์
  4. แก้สมการ
  5. ตรวจคำตอบ

ตัวอย่างที่ 23: โจทย์เกี่ยวกับอายุ

โจทย์: อายุของพี่มากกว่าอายุของน้อง 5 ปี ถ้าอายุรวมกันเป็น 25 ปี จงหาอายุของพี่และน้อง

วิธีทำ:

ให้ อายุของน้อง $= x$ ปี

ดังนั้น อายุของพี่ $= x + 5$ ปี

จากโจทย์: $x + (x + 5) = 25$

$$2x + 5 = 25$$

$$2x = 20$$

$$x = 10$$

ตอบ: น้องอายุ 10 ปี, พี่อายุ 15 ปี

ตัวอย่างที่ 24: โจทย์เกี่ยวกับเงิน

โจทย์: มานีมีเงิน 200 บาท เมื่อซื้อดินสอแล้วเหลือเงิน 140 บาท ดินสอราคาเท่าไร

วิธีทำ:

ให้ ราคาดินสอ $= x$ บาท

จากโจทย์: $200 - x = 140$

$$-x = 140 - 200$$

$$-x = -60$$

$$x = 60$$

ตอบ: ดินสอราคา 60 บาท

ตัวอย่างที่ 25: โจทย์เกี่ยวกับจำนวน

โจทย์: ถ้าเอาจำนวนหนึ่งคูณ 3 แล้วบวก 7 จะได้ 28 จำนวนนั้นเท่าไร

วิธีทำ:

ให้ จำนวนที่หา $= x$

จากโจทย์: $3x + 7 = 28$

$$3x = 28 - 7$$

$$3x = 21$$

$$x = 7$$

ตอบ: จำนวนนั้นคือ 7

แบบฝึกหัดบทที่ 3

ส่วนที่ 1: ตัวแปรและนิพจน์พีชคณิต (2 คะแนน)

  1. จากนิพจน์ $7x - 4y + 9$ จงระบุจำนวนพจน์และสัมประสิทธิ์ของ $x$
  2. จัดรูปนิพจน์ $8a + 3b - 5a + 2b - 1$

เฉลย ส่วนที่ 1:

1. มี 3 พจน์ คือ $7x$, $-4y$, $9$ และสัมประสิทธิ์ของ $x$ คือ 7

2. $8a + 3b - 5a + 2b - 1 = 3a + 5b - 1$

ส่วนที่ 2: การหาค่านิพจน์ (2 คะแนน)

  1. จงหาค่าของ $5x - 3$ เมื่อ $x = 4$
  2. จงหาค่าของ $2a + 3b$ เมื่อ $a = 6$ และ $b = -2$

เฉลย ส่วนที่ 2:

3. $5(4) - 3 = 20 - 3 = 17$

4. $2(6) + 3(-2) = 12 - 6 = 6$

ส่วนที่ 3: การคูณและหารพจน์ (2 คะแนน)

  1. $4x \times 3y = ?$
  2. $5(2x - 3) = ?$

เฉลย ส่วนที่ 3:

5. $4x \times 3y = 12xy$

6. $5(2x - 3) = 10x - 15$

ส่วนที่ 4: การแก้สมการ (2 คะแนน)

  1. แก้สมการ $x + 8 = 15$
  2. แก้สมการ $4x - 5 = 11$

เฉลย ส่วนที่ 4:

7. $x = 15 - 8 = 7$

8. $4x = 11 + 5 = 16$, ดังนั้น $x = 4$

ส่วนที่ 5: โจทย์ปัญหา (2 คะแนน)

  1. แก้สมการ $3(x + 2) = 18$
  2. ถ้าเอาจำนวนหนึ่งคูณ 4 แล้วลบ 3 จะได้ 21 จำนวนนั้นเท่าไร

เฉลย ส่วนที่ 5:

9. $3(x + 2) = 18 \Rightarrow 3x + 6 = 18 \Rightarrow 3x = 12 \Rightarrow x = 4$

10. ให้จำนวนที่หา $= x$, จากโจทย์ $4x - 3 = 21 \Rightarrow 4x = 24 \Rightarrow x = 6$
