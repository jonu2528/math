บทที่ 5: เรขาคณิต

เรขาคณิตเป็นสาขาหนึ่งของคณิตศาสตร์ที่ศึกษาเกี่ยวกับรูปร่าง ขนาด ตำแหน่ง และสมบัติของรูปเรขาคณิตต่างๆ ในบทนี้เราจะเรียนรู้เกี่ยวกับเส้นขนาน มุม รูปสามเหลี่ยม รูปสี่เหลี่ยม การคำนวณพื้นที่ ทฤษฎีบทพีทาโกรัส และปริมาตรของทรงสามมิติต่างๆ ซึ่งเป็นพื้นฐานสำคัญในการศึกษาเรขาคณิตขั้นสูงต่อไป

5.1 เส้นขนานและมุม

ความหมาย

เส้นขนาน คือ เส้นตรงสองเส้นที่อยู่บนระนาบเดียวกัน และไม่ตัดกันเลย ไม่ว่าจะยืดออกไปทางใดทางหนึ่งก็ตาม

เส้นตัด คือ เส้นตรงที่ตัดผ่านเส้นขนานอย่างน้อย 2 เส้น

สมบัติของมุมที่เกิดจากเส้นตัดตัดเส้นขนาน

เมื่อเส้นตัดตัดเส้นขนานสองเส้น จะได้มุมที่มีความสัมพันธ์กัน ดังนี้:

  • มุมแย้ง (Vertical Angles): มุมที่อยู่ตรงข้ามกันจะเท่ากัน
  • มุมคู่ภายใน (Alternate Interior Angles): มุมคู่ภายในเท่ากัน
  • มุมคู่ภายนอก (Alternate Exterior Angles): มุมคู่ภายนอกเท่ากัน
  • มุมประกอบภายใน (Consecutive Interior Angles): มุมประกอบภายในรวมกันเท่ากับ $180°$
  • มุมตรงข้าม (Corresponding Angles): มุมตรงข้ามเท่ากัน

ตัวอย่างที่ 1

โจทย์: ถ้าเส้นตรง $AB$ ขนานกับเส้นตรง $CD$ และมีเส้นตัด $EF$ ตัดทั้งสองเส้น ถ้ามุมหนึ่งมีขนาด $65°$ จงหามุมแย้งกับมุมนี้

วิธีทำ:

ตามสมบัติของมุมแย้ง มุมที่อยู่ตรงข้ามกันจะมีขนาดเท่ากัน

ดังนั้น มุมแย้งมีขนาด $= 65°$

ตอบ: $65°$

ตัวอย่างที่ 2

โจทย์: ถ้าเส้นตรง $PQ$ ขนานกับเส้นตรง $RS$ และมีเส้นตัดตัดทั้งสองเส้น ถ้ามุมหนึ่งมีขนาด $72°$ จงหามุมประกอบภายในกับมุมนี้

วิธีทำ:

ตามสมบัติของมุมประกอบภายใน มุมทั้งสองจะรวมกันเท่ากับ $180°$

$$\text{มุมประกอบภายใน} = 180° - 72°$$

$$= 108°$$

ตอบ: $108°$

ตัวอย่างที่ 3

โจทย์: เส้นตรง $L_1$ ขนานกับเส้นตรง $L_2$ มีเส้นตัดตัดทั้งสองเส้น ถ้ามุมคู่ภายในมุมหนึ่งมีขนาด $(3x + 10)°$ และอีกมุมหนึ่งมีขนาด $(2x + 35)°$ จงหาค่าของ $x$

วิธีทำ:

มุมคู่ภายในมีขนาดเท่ากัน ดังนั้น

$$3x + 10 = 2x + 35$$

$$3x - 2x = 35 - 10$$

$$x = 25$$

ตอบ: $x = 25$

ตัวอย่างที่ 4

โจทย์: ถ้ามุมสองมุมอยู่ข้างเดียวกันของเส้นตัด และอยู่ระหว่างเส้นขนานสองเส้น (มุมประกอบภายใน) โดยมุมหนึ่งมีขนาด $(4x - 20)°$ และอีกมุมหนึ่งมีขนาด $(2x + 80)°$ จงหาค่าของ $x$

วิธีทำ:

มุมประกอบภายในรวมกันเท่ากับ $180°$ ดังนั้น

$$(4x - 20) + (2x + 80) = 180$$

$$6x + 60 = 180$$

$$6x = 120$$

$$x = 20$$

ตอบ: $x = 20$

5.2 รูปสามเหลี่ยมและมุม

ความหมาย

รูปสามเหลี่ยม คือ รูปปิดที่มี 3 ด้าน 3 มุม และ 3 จุดยอด

สมบัติของมุมในรูปสามเหลี่ยม

1. ผลบวกของมุมทั้งสามมุมในรูปสามเหลี่ยมเท่ากับ 180°

$$\angle A + \angle B + \angle C = 180°$$

2. มุมภายนอกของรูปสามเหลี่ยม

มุมภายนอกของรูปสามเหลี่ยมเท่ากับผลบวกของมุมภายในสองมุมที่ไม่ประชิดกับมุมภายนอกนั้น

$$\text{มุมภายนอก} = \text{มุมภายในที่ไม่ประชิด}_1 + \text{มุมภายในที่ไม่ประชิด}_2$$

ประเภทของรูปสามเหลี่ยม

แบ่งตามด้าน:

  • สามเหลี่ยมด้านเท่า: มี 3 ด้านเท่ากันทุกด้าน และทุกมุมเท่ากับ $60°$
  • สามเหลี่ยมหน้าจั่ว: มี 2 ด้านเท่ากัน และมุมที่ฐานทั้งสองเท่ากัน
  • สามเหลี่ยมด้านไม่เท่า: ทั้ง 3 ด้านไม่เท่ากัน

แบ่งตามมุม:

  • สามเหลี่ยมมุมแหลม: ทุกมุมเป็นมุมแหลม (น้อยกว่า $90°$)
  • สามเหลี่ยมมุมฉาก: มี 1 มุมเป็นมุมฉาก ($90°$)
  • สามเหลี่ยมมุมป้าน: มี 1 มุมเป็นมุมป้าน (มากกว่า $90°$ แต่น้อยกว่า $180°$)

ตัวอย่างที่ 1

โจทย์: ในรูปสามเหลี่ยม $ABC$ มุม $A = 75°$ และมุม $B = 48°$ จงหามุม $C$

วิธีทำ:

ผลบวกของมุมทั้งสามในรูปสามเหลี่ยมเท่ากับ $180°$

$$\angle A + \angle B + \angle C = 180°$$

$$75° + 48° + \angle C = 180°$$

$$123° + \angle C = 180°$$

$$\angle C = 180° - 123°$$

$$\angle C = 57°$$

ตอบ: มุม $C = 57°$

ตัวอย่างที่ 2

โจทย์: รูปสามเหลี่ยม $DEF$ มีมุมภายนอกที่จุด $E$ เท่ากับ $115°$ ถ้ามุม $D = 62°$ จงหามุม $F$

วิธีทำ:

มุมภายนอก $= $ มุม $D + $ มุม $F$

$$115° = 62° + \angle F$$

$$\angle F = 115° - 62°$$

$$\angle F = 53°$$

ตอบ: มุม $F = 53°$

ตัวอย่างที่ 3

โจทย์: รูปสามเหลี่ยมหน้าจั่ว $PQR$ มีมุมที่ยอดเท่ากับ $40°$ จงหามุมที่ฐานแต่ละมุม

วิธีทำ:

ให้มุมที่ฐานแต่ละมุม $= x°$

ผลบวกของมุมทั้งสามเท่ากับ $180°$

$$40° + x + x = 180°$$

$$40° + 2x = 180°$$

$$2x = 140°$$

$$x = 70°$$

ตอบ: มุมที่ฐานแต่ละมุมเท่ากับ $70°$

ตัวอย่างที่ 4

โจทย์: รูปสามเหลี่ยม $XYZ$ มีมุม $X = (2x + 10)°$, มุม $Y = (3x - 5)°$ และมุม $Z = (x + 25)°$ จงหาค่าของ $x$ และมุมทั้งสาม

วิธีทำ:

$$\angle X + \angle Y + \angle Z = 180°$$

$$(2x + 10) + (3x - 5) + (x + 25) = 180$$

$$6x + 30 = 180$$

$$6x = 150$$

$$x = 25$$

แทนค่า $x$ เพื่อหามุมทั้งสาม:

$$\angle X = 2(25) + 10 = 60°$$

$$\angle Y = 3(25) - 5 = 70°$$

$$\angle Z = 25 + 25 = 50°$$

ตอบ: $x = 25$, มุม $X = 60°$, มุม $Y = 70°$, มุม $Z = 50°$

5.3 รูปสี่เหลี่ยม

ความหมาย

รูปสี่เหลี่ยม คือ รูปปิดที่มี 4 ด้าน 4 มุม และ 4 จุดยอด

สมบัติของรูปสี่เหลี่ยม

ผลบวกของมุมทั้งสี่มุมในรูปสี่เหลี่ยมเท่ากับ 360°

$$\angle A + \angle B + \angle C + \angle D = 360°$$

ประเภทของรูปสี่เหลี่ยม

1. รูปสี่เหลี่ยมจัตุรัส

  • ทั้ง 4 ด้านเท่ากัน
  • ทั้ง 4 มุมเป็นมุมฉาก ($90°$)
  • เส้นทแยงมุมตัดกันที่มุมฉาก และแบ่งครึ่งกัน

2. รูปสี่เหลี่ยมผืนผ้า

  • ด้านตรงข้ามขนานและเท่ากัน
  • ทั้ง 4 มุมเป็นมุมฉาก ($90°$)
  • เส้นทแยงมุมเท่ากันและแบ่งครึ่งกัน

3. รูปสี่เหลี่ยมขนมเปียกปูน (รูปหรี่)

  • ทั้ง 4 ด้านเท่ากัน
  • ด้านตรงข้ามขนานกัน
  • มุมตรงข้ามเท่ากัน
  • เส้นทแยงมุมตัดกันที่มุมฉากและแบ่งครึ่งกัน

4. รูปสี่เหลี่ยมด้านขนาน

  • ด้านตรงข้ามขนานและเท่ากัน
  • มุมตรงข้ามเท่ากัน
  • เส้นทแยงมุมแบ่งครึ่งกัน

5. รูปสี่เหลี่ยมคางหมู

  • มีด้านคู่หนึ่งขนานกัน

ตัวอย่างที่ 1

โจทย์: รูปสี่เหลี่ยม $ABCD$ มีมุม $A = 85°$, มุม $B = 95°$ และมุม $C = 82°$ จงหามุม $D$

วิธีทำ:

ผลบวกของมุมทั้งสี่ในรูปสี่เหลี่ยมเท่ากับ $360°$

$$\angle A + \angle B + \angle C + \angle D = 360°$$

$$85° + 95° + 82° + \angle D = 360°$$

$$262° + \angle D = 360°$$

$$\angle D = 360° - 262°$$

$$\angle D = 98°$$

ตอบ: มุม $D = 98°$

ตัวอย่างที่ 2

โจทย์: รูปสี่เหลี่ยมด้านขนาน $PQRS$ มีมุม $P = 65°$ จงหามุม $Q$, $R$ และ $S$

วิธีทำ:

ในรูปสี่เหลี่ยมด้านขนาน มุมตรงข้ามเท่ากัน และมุมประชิดรวมกันเท่ากับ $180°$

มุม $R$ ตรงข้ามมุม $P$ ดังนั้น มุม $R = 65°$

มุม $Q$ ประชิดกับมุม $P$ ดังนั้น

$$\angle P + \angle Q = 180°$$

$$65° + \angle Q = 180°$$

$$\angle Q = 115°$$

มุม $S$ ตรงข้ามมุม $Q$ ดังนั้น มุม $S = 115°$

ตอบ: มุม $Q = 115°$, มุม $R = 65°$, มุม $S = 115°$

ตัวอย่างที่ 3

โจทย์: รูปสี่เหลี่ยมคางหมู $KLMN$ มี $KL$ ขนานกับ $NM$ มุม $K = 72°$ และมุม $L = 68°$ จงหามุม $M$ และ $N$

วิธีทำ:

ในรูปสี่เหลี่ยมคางหมู มุมที่อยู่บนด้านเดียวกันรวมกันเท่ากับ $180°$

$$\angle K + \angle N = 180°$$

$$72° + \angle N = 180°$$

$$\angle N = 108°$$

$$\angle L + \angle M = 180°$$

$$68° + \angle M = 180°$$

$$\angle M = 112°$$

ตอบ: มุม $M = 112°$, มุม $N = 108°$

ตัวอย่างที่ 4

โจทย์: รูปสี่เหลี่ยม $WXYZ$ มีมุม $W = (2x + 15)°$, มุม $X = (3x - 10)°$, มุม $Y = (x + 40)°$ และมุม $Z = (2x + 35)°$ จงหาค่าของ $x$

วิธีทำ:

$$\angle W + \angle X + \angle Y + \angle Z = 360°$$

$$(2x + 15) + (3x - 10) + (x + 40) + (2x + 35) = 360$$

$$8x + 80 = 360$$

$$8x = 280$$

$$x = 35$$

ตอบ: $x = 35$

5.4 พื้นที่รูปหลายเหลี่ยม

ความหมาย

พื้นที่ คือ ขนาดของพื้นผิวของรูปเรขาคณิต วัดเป็นตารางหน่วย เช่น ตารางเซนติเมตร ($\text{cm}^2$) ตารางเมตร ($\text{m}^2$)

สูตรพื้นที่รูปต่างๆ

1. รูปสี่เหลี่ยมจัตุรัส

$$\text{พื้นที่} = \text{ด้าน} \times \text{ด้าน} = s^2$$

โดย $s$ = ความยาวด้าน

2. รูปสี่เหลี่ยมผืนผ้า

$$\text{พื้นที่} = \text{ความกว้าง} \times \text{ความยาว} = w \times l$$

3. รูปสามเหลี่ยม

$$\text{พื้นที่} = \frac{1}{2} \times \text{ฐาน} \times \text{สูง} = \frac{1}{2}bh$$

4. รูปสี่เหลี่ยมด้านขนาน

$$\text{พื้นที่} = \text{ฐาน} \times \text{สูง} = bh$$

5. รูปสี่เหลี่ยมขนมเปียกปูน

$$\text{พื้นที่} = \frac{1}{2} \times d_1 \times d_2$$

โดย $d_1, d_2$ = ความยาวของเส้นทแยงมุมทั้งสอง

6. รูปสี่เหลี่ยมคางหมู

$$\text{พื้นที่} = \frac{1}{2} \times (\text{ฐานบน} + \text{ฐานล่าง}) \times \text{สูง} = \frac{1}{2}(a + b)h$$

7. รูปวงกลม

$$\text{พื้นที่} = \pi r^2$$

โดย $r$ = รัศมี, $\pi \approx 3.14$ หรือ $\frac{22}{7}$

ตัวอย่างที่ 1

โจทย์: รูปสี่เหลี่ยมจัตุรัสมีด้านยาว $8$ เซนติเมตร จงหาพื้นที่

วิธีทำ:

$$\text{พื้นที่} = s^2$$

$$= 8^2$$

$$= 64 \text{ ตร.ซม.}$$

ตอบ: $64$ ตารางเซนติเมตร

ตัวอย่างที่ 2

โจทย์: รูปสามเหลี่ยมมีฐานยาว $12$ เซนติเมตร และสูง $9$ เซนติเมตร จงหาพื้นที่

วิธีทำ:

$$\text{พื้นที่} = \frac{1}{2}bh$$

$$= \frac{1}{2} \times 12 \times 9$$

$$= \frac{108}{2}$$

$$= 54 \text{ ตร.ซม.}$$

ตอบ: $54$ ตารางเซนติเมตร

ตัวอย่างที่ 3

โจทย์: รูปสี่เหลี่ยมคางหมูมีฐานบนยาว $6$ เมตร ฐานล่างยาว $10$ เมตร และสูง $5$ เมตร จงหาพื้นที่

วิธีทำ:

$$\text{พื้นที่} = \frac{1}{2}(a + b)h$$

$$= \frac{1}{2}(6 + 10) \times 5$$

$$= \frac{1}{2} \times 16 \times 5$$

$$= \frac{80}{2}$$

$$= 40 \text{ ตร.ม.}$$

ตอบ: $40$ ตารางเมตร

ตัวอย่างที่ 4

โจทย์: วงกลมมีรัศมี $7$ เซนติเมตร จงหาพื้นที่ (ใช้ $\pi = \frac{22}{7}$)

วิธีทำ:

$$\text{พื้นที่} = \pi r^2$$

$$= \frac{22}{7} \times 7^2$$

$$= \frac{22}{7} \times 49$$

$$= 22 \times 7$$

$$= 154 \text{ ตร.ซม.}$$

ตอบ: $154$ ตารางเซนติเมตร

5.5 ทฤษฎีบทพีทาโกรัส

ความหมาย

ทฤษฎีบทพีทาโกรัส เป็นทฤษฎีบทที่สำคัญที่สุดในเรขาคณิต ค้นพบโดยนักคณิตศาสตร์ชาวกรีกชื่อพีทาโกรัส (Pythagoras)

ทฤษฎีบทนี้กล่าวว่า ในรูปสามเหลี่ยมมุมฉาก กำลังสองของด้านตรงข้ามมุมฉาก (ด้านตรงข้ามมุมฉากเรียกว่า ด้านฮาร์พอเทนุส) เท่ากับผลบวกของกำลังสองของอีกสองด้าน

สูตรทฤษฎีบทพีทาโกรัส

ในรูปสามเหลี่ยมมุมฉาก ถ้า $c$ คือด้านตรงข้ามมุมฉาก และ $a, b$ คือด้านประกอบมุมฉาก

$$c^2 = a^2 + b^2$$

หรือ

$$c = \sqrt{a^2 + b^2}$$

$$a = \sqrt{c^2 - b^2}$$

$$b = \sqrt{c^2 - a^2}$$

สามเหลี่ยมพีทาโกรัส (Pythagorean Triples)

คือชุดของจำนวนเต็มบวกสามจำนวน ที่สามารถเป็นความยาวของด้านทั้งสามในรูปสามเหลี่ยมมุมฉาก

ตัวอย่างที่พบบ่อย:

  • $(3, 4, 5)$: $3^2 + 4^2 = 9 + 16 = 25 = 5^2$
  • $(5, 12, 13)$: $5^2 + 12^2 = 25 + 144 = 169 = 13^2$
  • $(8, 15, 17)$: $8^2 + 15^2 = 64 + 225 = 289 = 17^2$
  • $(7, 24, 25)$: $7^2 + 24^2 = 49 + 576 = 625 = 25^2$

ตัวอย่างที่ 1

โจทย์: รูปสามเหลี่ยมมุมฉากมีด้านประกอบมุมฉาก $6$ ซม. และ $8$ ซม. จงหาด้านตรงข้ามมุมฉาก

วิธีทำ:

ให้ด้านตรงข้ามมุมฉาก $= c$ ซม.

$$c^2 = a^2 + b^2$$

$$c^2 = 6^2 + 8^2$$

$$c^2 = 36 + 64$$

$$c^2 = 100$$

$$c = \sqrt{100}$$

$$c = 10 \text{ ซม.}$$

ตอบ: ด้านตรงข้ามมุมฉากยาว $10$ เซนติเมตร

ตัวอย่างที่ 2

โจทย์: รูปสามเหลี่ยมมุมฉากมีด้านตรงข้ามมุมฉาก $13$ ซม. และมีด้านหนึ่งยาว $5$ ซม. จงหาอีกด้านหนึ่ง

วิธีทำ:

ให้อีกด้านหนึ่ง $= b$ ซม.

$$c^2 = a^2 + b^2$$

$$13^2 = 5^2 + b^2$$

$$169 = 25 + b^2$$

$$b^2 = 169 - 25$$

$$b^2 = 144$$

$$b = \sqrt{144}$$

$$b = 12 \text{ ซม.}$$

ตอบ: อีกด้านหนึ่งยาว $12$ เซนติเมตร

ตัวอย่างที่ 3

โจทย์: บันไดยาว $10$ เมตร พาดกับผนังโดยมีฐานห่างจากผนัง $6$ เมตร จงหาว่าบันไดสูงจากพื้นเท่าไร

วิธีทำ:

ให้ความสูงของบันได $= h$ เมตร

ความยาวบันได $= 10$ ม. (ด้านตรงข้ามมุมฉาก)

ระยะจากผนัง $= 6$ ม. (ด้านประกอบมุมฉาก)

$$10^2 = 6^2 + h^2$$

$$100 = 36 + h^2$$

$$h^2 = 64$$

$$h = 8 \text{ ม.}$$

ตอบ: บันไดสูงจากพื้น $8$ เมตร

ตัวอย่างที่ 4

โจทย์: สนามสี่เหลี่ยมผืนผ้ามีความกว้าง $9$ เมตร และความยาว $12$ เมตร จงหาความยาวของเส้นทแยงมุม

วิธีทำ:

เส้นทแยงมุมของสี่เหลี่ยมผืนผ้าแบ่งเป็นสามเหลี่ยมมุมฉาก

ให้ความยาวของเส้นทแยงมุม $= d$ เมตร

$$d^2 = 9^2 + 12^2$$

$$d^2 = 81 + 144$$

$$d^2 = 225$$

$$d = \sqrt{225}$$

$$d = 15 \text{ ม.}$$

ตอบ: ความยาวของเส้นทแยงมุมเท่ากับ $15$ เมตร

5.6 ปริมาตร

ความหมาย

ปริมาตร คือ ความจุของวัตถุสามมิติ หรือปริมาณพื้นที่ที่อยู่ภายในวัตถุสามมิติ วัดเป็นลูกบาศก์หน่วย เช่น ลูกบาศก์เซนติเมตร ($\text{cm}^3$ หรือ ซีซี) ลูกบาศก์เมตร ($\text{m}^3$)

สูตรปริมาตรของทรงสามมิติต่างๆ

1. ทรงสี่เหลี่ยมมุมฉาก (กล่องสี่เหลี่ยม)

$$V = \text{ความยาว} \times \text{ความกว้าง} \times \text{ความสูง}$$

$$V = l \times w \times h$$

2. ทรงลูกบาศก์

$$V = \text{ด้าน}^3 = s^3$$

โดย $s$ = ความยาวของด้าน

3. ทรงกระบอก

$$V = \pi r^2 h$$

โดย $r$ = รัศมีของฐาน, $h$ = ความสูง

4. ทรงกรวย

$$V = \frac{1}{3}\pi r^2 h$$

โดย $r$ = รัศมีของฐาน, $h$ = ความสูง

5. ทรงพีระมิด

$$V = \frac{1}{3} \times \text{พื้นที่ฐาน} \times \text{ความสูง}$$

6. ทรงกลม

$$V = \frac{4}{3}\pi r^3$$

โดย $r$ = รัศมี

ตัวอย่างที่ 1

โจทย์: กล่องสี่เหลี่ยมมุมฉากมีความยาว $12$ ซม. ความกว้าง $8$ ซม. และความสูง $5$ ซม. จงหาปริมาตร

วิธีทำ:

$$V = l \times w \times h$$

$$V = 12 \times 8 \times 5$$

$$V = 480 \text{ ลบ.ซม.}$$

ตอบ: $480$ ลูกบาศก์เซนติเมตร

ตัวอย่างที่ 2

โจทย์: ทรงลูกบาศก์มีด้านยาว $7$ เซนติเมตร จงหาปริมาตร

วิธีทำ:

$$V = s^3$$

$$V = 7^3$$

$$V = 343 \text{ ลบ.ซม.}$$

ตอบ: $343$ ลูกบาศก์เซนติเมตร

ตัวอย่างที่ 3

โจทย์: ทรงกระบอกมีรัศมีฐาน $7$ เซนติเมตร และสูง $10$ เซนติเมตร จงหาปริมาตร (ใช้ $\pi = \frac{22}{7}$)

วิธีทำ:

$$V = \pi r^2 h$$

$$V = \frac{22}{7} \times 7^2 \times 10$$

$$V = \frac{22}{7} \times 49 \times 10$$

$$V = 22 \times 7 \times 10$$

$$V = 1{,}540 \text{ ลบ.ซม.}$$

ตอบ: $1{,}540$ ลูกบาศก์เซนติเมตร

ตัวอย่างที่ 4

โจทย์: ทรงกรวยมีรัศมีฐาน $6$ เซนติเมตร และสูง $12$ เซนติเมตร จงหาปริมาตร (ใช้ $\pi = 3.14$)

วิธีทำ:

$$V = \frac{1}{3}\pi r^2 h$$

$$V = \frac{1}{3} \times 3.14 \times 6^2 \times 12$$

$$V = \frac{1}{3} \times 3.14 \times 36 \times 12$$

$$V = \frac{1}{3} \times 1{,}356.48$$

$$V = 452.16 \text{ ลบ.ซม.}$$

ตอบ: $452.16$ ลูกบาศก์เซนติเมตร

แบบฝึกหัดบทที่ 5

ส่วนที่ 1: เส้นขนานและมุม (3 คะแนน)

  1. เส้นตรง $AB$ ขนานกับเส้นตรง $CD$ มีเส้นตัดตัดทั้งสองเส้น ถ้ามุมหนึ่งเท่ากับ $118°$ จงหามุมประกอบภายในกับมุมนี้
  2. มุมคู่ภายในสองมุมมีขนาด $(5x - 10)°$ และ $(3x + 30)°$ จงหาค่าของ $x$
  3. เส้นขนานสองเส้นถูกตัดด้วยเส้นตัด ถ้ามุมหนึ่งเท่ากับ $75°$ จงหามุมตรงข้ามกับมุมนี้

เฉลย ส่วนที่ 1:

1. มุมประกอบภายใน $= 180° - 118° = 62°$

2. มุมคู่ภายในเท่ากัน: $5x - 10 = 3x + 30$, $2x = 40$, $x = 20$

3. มุมตรงข้าม (Corresponding angles) เท่ากัน = $75°$

ส่วนที่ 2: รูปสามเหลี่ยมและมุม (3 คะแนน)

  1. รูปสามเหลี่ยม $ABC$ มีมุม $A = 55°$ และมุม $B = 72°$ จงหามุม $C$
  2. รูปสามเหลี่ยมหน้าจั่วมีมุมที่ฐานมุมหนึ่งเท่ากับ $65°$ จงหามุมที่ยอด
  3. มุมภายนอกของรูปสามเหลี่ยมเท่ากับ $125°$ ถ้ามุมภายในมุมหนึ่งเท่ากับ $60°$ จงหาอีกมุมหนึ่งที่ไม่ประชิดกับมุมภายนอก

เฉลย ส่วนที่ 2:

4. มุม $C = 180° - 55° - 72° = 53°$

5. มุมที่ฐานอีกมุม = $65°$ (เท่ากัน), มุมที่ยอด = $180° - 65° - 65° = 50°$

6. มุมภายนอก = ผลบวกของมุมภายในสองมุมที่ไม่ประชิด: $125° = 60° + x$, $x = 65°$

ส่วนที่ 3: รูปสี่เหลี่ยม (3 คะแนน)

  1. รูปสี่เหลี่ยม $PQRS$ มีมุม $P = 92°$, มุม $Q = 88°$, มุม $R = 85°$ จงหามุม $S$
  2. รูปสี่เหลี่ยมด้านขนานมีมุมหนึ่งเท่ากับ $70°$ จงหามุมที่เหลือทั้งสาม
  3. รูปสี่เหลี่ยมคางหมูมีด้านขนาน มุมหนึ่งเท่ากับ $105°$ จงหามุมที่อยู่บนด้านเดียวกันกับมุมนี้

เฉลย ส่วนที่ 3:

7. มุม $S = 360° - 92° - 88° - 85° = 95°$

8. มุมตรงข้าม = $70°$, มุมประชิด = $180° - 70° = 110°$ (สองมุม)

9. มุมที่อยู่บนด้านเดียวกัน = $180° - 105° = 75°$

ส่วนที่ 4: พื้นที่และทฤษฎีบทพีทาโกรัส (4 คะแนน)

  1. รูปสามเหลี่ยมมีฐาน $15$ ซม. และสูง $8$ ซม. จงหาพื้นที่
  2. รูปสี่เหลี่ยมคางหมูมีฐานบน $5$ ม. ฐานล่าง $9$ ม. และสูง $6$ ม. จงหาพื้นที่
  3. รูปสามเหลี่ยมมุมฉากมีด้านประกอบมุมฉาก $9$ ซม. และ $12$ ซม. จงหาด้านตรงข้ามมุมฉาก
  4. รูปสี่เหลี่ยมผืนผ้ามีความกว้าง $5$ ซม. และเส้นทแยงมุมยาว $13$ ซม. จงหาความยาว

เฉลย ส่วนที่ 4:

10. พื้นที่ $= \frac{1}{2} \times 15 \times 8 = 60$ ตร.ซม.

11. พื้นที่ $= \frac{1}{2}(5 + 9) \times 6 = \frac{1}{2} \times 14 \times 6 = 42$ ตร.ม.

12. $c^2 = 9^2 + 12^2 = 81 + 144 = 225$, $c = 15$ ซม.

13. $13^2 = 5^2 + l^2$, $169 = 25 + l^2$, $l^2 = 144$, $l = 12$ ซม.

ส่วนที่ 5: ปริมาตร (3 คะแนน)

  1. ทรงลูกบาศก์มีด้านยาว $5$ ซม. จงหาปริมาตร
  2. กล่องสี่เหลี่ยมมุมฉากมีความยาว $8$ ซม. ความกว้าง $6$ ซม. และความสูง $4$ ซม. จงหาปริมาตร
  3. ทรงกระบอกมีรัศมีฐาน $7$ ซม. และสูง $15$ ซม. จงหาปริมาตร (ใช้ $\pi = \frac{22}{7}$)

เฉลย ส่วนที่ 5:

14. ปริมาตร $= 5^3 = 125$ ลบ.ซม.

15. ปริมาตร $= 8 \times 6 \times 4 = 192$ ลบ.ซม.

16. ปริมาตร $= \frac{22}{7} \times 7^2 \times 15 = 22 \times 7 \times 15 = 2{,}310$ ลบ.ซม.
