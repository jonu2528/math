บทที่ 3: พหุนาม

พหุนามเป็นนิพจน์พีชคณิตที่สำคัญในคณิตศาสตร์ บทนี้จะเรียนรู้เกี่ยวกับนิพจน์พีชคณิต การบวก ลบ คูณพหุนาม การแยกตัวประกอบ การหาห.ร.ม.และค.ร.น.ของพหุนาม รวมถึงการหารพหุนาม ซึ่งเป็นพื้นฐานสำคัญสำหรับการเรียนคณิตศาสตร์ในระดับที่สูงขึ้น

3.1 นิพจน์พีชคณิต

ความหมาย

นิพจน์พีชคณิต (Algebraic Expression) คือ นิพจน์ที่ประกอบด้วยตัวเลข ตัวแปร และเครื่องหมายการดำเนินการทางคณิตศาสตร์ (บวก ลบ คูณ หาร ยกกำลัง)


ส่วนประกอบของนิพจน์พีชคณิต:

  • พจน์ (Term) คือ ส่วนของนิพจน์ที่แยกด้วยเครื่องหมาย + หรือ -
  • สัมประสิทธิ์ (Coefficient) คือ ตัวเลขที่คูณกับตัวแปร
  • ตัวประกอบ (Factor) คือ จำนวนหรือนิพจน์ที่คูณกัน
  • ดีกรี (Degree) คือ เลขชี้กำลังสูงสุดของตัวแปรในพจน์นั้น

พหุนาม (Polynomial) คือ นิพจน์พีชคณิตที่มีเลขชี้กำลังของตัวแปรเป็นจำนวนเต็มไม่เป็นลบ

รูปแบบทั่วไปของพหุนาม

$$a_nx^n + a_{n-1}x^{n-1} + \cdots + a_2x^2 + a_1x + a_0$$

เมื่อ $a_n, a_{n-1}, \ldots, a_1, a_0$ เป็นค่าคงที่ และ $n$ เป็นจำนวนเต็มไม่เป็นลบ

ตัวอย่างที่ 1: ระบุส่วนประกอบของนิพจน์

โจทย์: จากนิพจน์ $5x^2 - 3x + 7$ จงระบุ

ก) จำนวนพจน์

ข) สัมประสิทธิ์ของแต่ละพจน์

ค) ดีกรีของพหุนาม

วิธีทำ:

ก) พจน์ที่ 1: $5x^2$, พจน์ที่ 2: $-3x$, พจน์ที่ 3: $7$

ดังนั้น มี 3 พจน์

ข) สัมประสิทธิ์ของ $x^2$ คือ $5$

สัมประสิทธิ์ของ $x$ คือ $-3$

พจน์คงที่ คือ $7$

ค) เลขชี้กำลังสูงสุดคือ 2 ดังนั้น ดีกรีของพหุนามคือ 2

ตัวอย่างที่ 2: ระบุว่าเป็นพหุนามหรือไม่

โจทย์: จงระบุว่านิพจน์ต่อไปนี้เป็นพหุนามหรือไม่ พร้อมให้เหตุผล

ก) $3x^2 + 2x - 5$

ข) $\frac{1}{x} + x^2$

ค) $\sqrt{x} + 3$

ง) $4x^3 - 2x + 1$

วิธีทำ:

ก) $3x^2 + 2x - 5$ เป็นพหุนาม เพราะเลขชี้กำลังของ $x$ เป็นจำนวนเต็มไม่เป็นลบ (2, 1, 0)

ข) $\frac{1}{x} + x^2 = x^{-1} + x^2$ ไม่เป็นพหุนาม เพราะมีเลขชี้กำลังเป็นลบ $(-1)$

ค) $\sqrt{x} + 3 = x^{1/2} + 3$ ไม่เป็นพหุนาม เพราะเลขชี้กำลังเป็นเศษส่วน $(1/2)$

ง) $4x^3 - 2x + 1$ เป็นพหุนาม เพราะเลขชี้กำลังของ $x$ เป็นจำนวนเต็มไม่เป็นลบ (3, 1, 0)

ตัวอย่างที่ 3: คำนวณค่านิพจน์

โจทย์: จงหาค่าของนิพจน์ $2x^2 - 3x + 5$ เมื่อ $x = 2$

วิธีทำ:

แทนค่า $x = 2$ ในนิพจน์

$$\begin{align} 2x^2 - 3x + 5 &= 2(2)^2 - 3(2) + 5\\ &= 2(4) - 6 + 5\\ &= 8 - 6 + 5\\ &= 7 \end{align}$$

ตอบ $7$

ตัวอย่างที่ 4: เรียงพจน์ตามลำดับดีกรี

โจทย์: จงเรียงพจน์ของนิพจน์ $3 - 2x^2 + 5x^4 - x + 7x^3$ ตามลำดับดีกรีจากมากไปน้อย

วิธีทำ:

เรียงตามเลขชี้กำลังจากมากไปน้อย:

$$5x^4 + 7x^3 - 2x^2 - x + 3$$

พหุนามนี้มีดีกรี 4 (เลขชี้กำลังสูงสุด)

แบบฝึกหัดท้ายเรื่อง 3.1

  1. จากนิพจน์ $7x^3 - 2x^2 + 5x - 9$ จงระบุจำนวนพจน์และสัมประสิทธิ์ของแต่ละพจน์
  2. จงหาค่าของนิพจน์ $x^2 - 4x + 3$ เมื่อ $x = 5$
  3. นิพจน์ใดต่อไปนี้ไม่เป็นพหุนาม: $2x^3 + 1$, $x^{-2} + 3$, $5x + 7$
  4. จงเรียงพจน์ของนิพจน์ $4 + 2x - 3x^3 + x^2$ ตามลำดับดีกรีจากมากไปน้อย
  5. พหุนาม $5x^4 - 3x^2 + 2$ มีดีกรีเท่าใด

เฉลย:

1. มี 4 พจน์, สัมประสิทธิ์: $7, -2, 5, -9$

2. $5^2 - 4(5) + 3 = 25 - 20 + 3 = 8$

3. $x^{-2} + 3$ (เพราะมีเลขชี้กำลังเป็นลบ)

4. $-3x^3 + x^2 + 2x + 4$

5. ดีกรี 4

3.2 การบวกลบพหุนาม

หลักการบวกลบพหุนาม

การบวกหรือลบพหุนาม ทำได้โดยการนำพจน์ที่เหมือนกันมารวมกัน


พจน์ที่เหมือนกัน (Like Terms) คือ พจน์ที่มีตัวแปรและเลขชี้กำลังเหมือนกัน

  • $3x^2$ และ $5x^2$ เป็นพจน์ที่เหมือนกัน
  • $2xy$ และ $7xy$ เป็นพจน์ที่เหมือนกัน
  • $4x$ และ $4x^2$ ไม่เป็นพจน์ที่เหมือนกัน (เลขชี้กำลังต่างกัน)

วิธีการ:

  1. ถอดวงเล็บ (ถ้ามี) โดยคำนึงถึงเครื่องหมายหน้าวงเล็บ
  2. จัดกลุ่มพจน์ที่เหมือนกัน
  3. บวกหรือลบสัมประสิทธิ์ของพจน์ที่เหมือนกัน
  4. เรียงลำดับพจน์ตามดีกรีจากมากไปน้อย

สูตรการบวกลบพหุนาม

$(ax^n + bx^n) = (a+b)x^n$

$(ax^n - bx^n) = (a-b)x^n$

ตัวอย่างที่ 1: การบวกพหุนาม (ง่าย)

โจทย์: จงหาผลบวก $(3x + 5) + (2x + 7)$

วิธีทำ:

$$\begin{align} (3x + 5) + (2x + 7) &= 3x + 5 + 2x + 7\\ &= 3x + 2x + 5 + 7\\ &= (3+2)x + (5+7)\\ &= 5x + 12 \end{align}$$

ตอบ $5x + 12$

ตัวอย่างที่ 2: การลบพหุนาม

โจทย์: จงหาผลลบ $(5x^2 - 3x + 4) - (2x^2 + x - 1)$

วิธีทำ:

ขั้นตอนที่ 1: ถอดวงเล็บ (เปลี่ยนเครื่องหมายในวงเล็บหลัง)

$$= 5x^2 - 3x + 4 - 2x^2 - x + 1$$

ขั้นตอนที่ 2: จัดกลุ่มพจน์ที่เหมือนกัน

$$= 5x^2 - 2x^2 - 3x - x + 4 + 1$$

ขั้นตอนที่ 3: รวมพจน์

$$= 3x^2 - 4x + 5$$

ตอบ $3x^2 - 4x + 5$

ตัวอย่างที่ 3: การบวกลบพหุนามหลายพจน์

โจทย์: จงหาผลลัพธ์ของ $(2x^3 - 5x + 3) + (x^3 + 4x^2 - 2) - (3x^3 - x^2 + x)$

วิธีทำ:

ขั้นตอนที่ 1: ถอดวงเล็บทุกตัว

$$= 2x^3 - 5x + 3 + x^3 + 4x^2 - 2 - 3x^3 + x^2 - x$$

ขั้นตอนที่ 2: จัดกลุ่มพจน์ที่มีเลขชี้กำลังเดียวกัน

$$= 2x^3 + x^3 - 3x^3 + 4x^2 + x^2 - 5x - x + 3 - 2$$

ขั้นตอนที่ 3: รวมพจน์แต่ละกลุ่ม

$$\begin{align} &= (2+1-3)x^3 + (4+1)x^2 + (-5-1)x + (3-2)\\ &= 0x^3 + 5x^2 - 6x + 1\\ &= 5x^2 - 6x + 1 \end{align}$$

ตอบ $5x^2 - 6x + 1$

ตัวอย่างที่ 4: โจทย์ประยุกต์

โจทย์: ถ้า $P = 2x^2 - 3x + 1$ และ $Q = x^2 + 5x - 4$ จงหาค่าของ $P + Q$ และ $2P - Q$

วิธีทำ:

หา $P + Q$:

$$\begin{align} P + Q &= (2x^2 - 3x + 1) + (x^2 + 5x - 4)\\ &= 2x^2 + x^2 - 3x + 5x + 1 - 4\\ &= 3x^2 + 2x - 3 \end{align}$$

หา $2P - Q$:

$$\begin{align} 2P - Q &= 2(2x^2 - 3x + 1) - (x^2 + 5x - 4)\\ &= 4x^2 - 6x + 2 - x^2 - 5x + 4\\ &= 4x^2 - x^2 - 6x - 5x + 2 + 4\\ &= 3x^2 - 11x + 6 \end{align}$$

ตอบ $P + Q = 3x^2 + 2x - 3$ และ $2P - Q = 3x^2 - 11x + 6$

แบบฝึกหัดท้ายเรื่อง 3.2

  1. $(4x + 3) + (2x - 5)$
  2. $(7x^2 - 2x + 1) + (3x^2 + 5x - 4)$
  3. $(6x - 8) - (2x + 3)$
  4. $(5x^2 + 3x - 2) - (2x^2 - 4x + 1)$
  5. $(x^3 - 2x + 5) + (3x^2 + x - 1) - (2x^3 + x^2)$
  6. ถ้า $A = 3x^2 - x + 2$ และ $B = x^2 + 4x - 3$ จงหา $A + B$
  7. ถ้า $P = 5x - 7$ และ $Q = 2x + 9$ จงหา $P - Q$
  8. $(8x^2 - 3x + 1) - (5x^2 + 2x - 6) + (x^2 - x + 3)$

เฉลย:

1. $6x - 2$

2. $10x^2 + 3x - 3$

3. $4x - 11$

4. $3x^2 + 7x - 3$

5. $-x^3 + 2x^2 - x + 4$

6. $4x^2 + 3x - 1$

7. $3x - 16$

8. $4x^2 - 6x + 10$

3.3 การคูณพหุนาม

หลักการคูณพหุนาม

การคูณพหุนาม ทำได้โดยใช้สมบัติการแจกแจง (Distributive Property) คือ นำทุกพจน์ในวงเล็บแรกคูณกับทุกพจน์ในวงเล็บหลัง


วิธีการ:

  1. กระจายโดยนำแต่ละพจน์ในวงเล็บแรกคูณกับทุกพจน์ในวงเล็บหลัง
  2. คูณสัมประสิทธิ์และบวกเลขชี้กำลัง $(a^m \times a^n = a^{m+n})$
  3. รวมพจน์ที่เหมือนกัน
  4. เรียงลำดับพจน์ตามดีกรีจากมากไปน้อย

สูตรการคูณพหุนามที่สำคัญ

$(a+b)(c+d) = ac + ad + bc + bd$


สูตรพิเศษ:

1. $(a+b)^2 = a^2 + 2ab + b^2$

2. $(a-b)^2 = a^2 - 2ab + b^2$

3. $(a+b)(a-b) = a^2 - b^2$

ตัวอย่างที่ 1: การคูณพหุนามแบบง่าย

โจทย์: จงคูณ $3x(2x^2 - 5x + 4)$

วิธีทำ:

กระจายโดยนำ $3x$ คูณกับทุกพจน์ในวงเล็บ

$$\begin{align} 3x(2x^2 - 5x + 4) &= 3x \cdot 2x^2 + 3x \cdot (-5x) + 3x \cdot 4\\ &= 6x^3 - 15x^2 + 12x \end{align}$$

ตอบ $6x^3 - 15x^2 + 12x$

ตัวอย่างที่ 2: การคูณพหุนาม 2 วงเล็บ

โจทย์: จงคูณ $(x + 3)(2x - 5)$

วิธีทำ:

กระจายโดยนำทุกพจน์ในวงเล็บแรกคูณกับทุกพจน์ในวงเล็บหลัง

$$\begin{align} (x + 3)(2x - 5) &= x \cdot 2x + x \cdot (-5) + 3 \cdot 2x + 3 \cdot (-5)\\ &= 2x^2 - 5x + 6x - 15\\ &= 2x^2 + x - 15 \end{align}$$

ตอบ $2x^2 + x - 15$

ตัวอย่างที่ 3: ใช้สูตร $(a+b)^2$

โจทย์: จงกระจาย $(2x + 3)^2$

วิธีทำ:

ใช้สูตร $(a+b)^2 = a^2 + 2ab + b^2$ โดยให้ $a = 2x$ และ $b = 3$

$$\begin{align} (2x + 3)^2 &= (2x)^2 + 2(2x)(3) + (3)^2\\ &= 4x^2 + 12x + 9 \end{align}$$

วิธีตรวจสอบ: กระจายแบบธรรมดา

$$\begin{align} (2x + 3)^2 &= (2x + 3)(2x + 3)\\ &= 4x^2 + 6x + 6x + 9\\ &= 4x^2 + 12x + 9 \end{align}$$

ตอบ $4x^2 + 12x + 9$

ตัวอย่างที่ 4: ใช้สูตร $(a+b)(a-b)$

โจทย์: จงคูณ $(3x + 5)(3x - 5)$

วิธีทำ:

สังเกตว่าเป็นรูปแบบ $(a+b)(a-b) = a^2 - b^2$ โดยให้ $a = 3x$ และ $b = 5$

$$\begin{align} (3x + 5)(3x - 5) &= (3x)^2 - (5)^2\\ &= 9x^2 - 25 \end{align}$$

ตอบ $9x^2 - 25$

ตัวอย่างที่ 5: การคูณพหุนามที่ซับซ้อน

โจทย์: จงคูณ $(x^2 - 2x + 3)(x + 2)$

วิธีทำ:

กระจายโดยนำทุกพจน์ในวงเล็บแรกคูณกับทุกพจน์ในวงเล็บหลัง

$$\begin{align} (x^2 - 2x + 3)(x + 2) &= x^2 \cdot x + x^2 \cdot 2 - 2x \cdot x - 2x \cdot 2 + 3 \cdot x + 3 \cdot 2\\ &= x^3 + 2x^2 - 2x^2 - 4x + 3x + 6\\ &= x^3 + (2-2)x^2 + (-4+3)x + 6\\ &= x^3 - x + 6 \end{align}$$

ตอบ $x^3 - x + 6$

แบบฝึกหัดท้ายเรื่อง 3.3

  1. $2x(3x - 4)$
  2. $(x + 4)(x + 5)$
  3. $(2x - 3)(x + 7)$
  4. $(x + 6)^2$
  5. $(3x - 2)^2$
  6. $(x + 4)(x - 4)$
  7. $(2x + 1)(2x - 1)$
  8. $(x^2 + 3x - 1)(x - 2)$
  9. $(x - 3)(x + 3)(x + 1)$
  10. กระจาย $(x + 2)^2 + (x - 1)^2$

เฉลย:

1. $6x^2 - 8x$

2. $x^2 + 9x + 20$

3. $2x^2 + 11x - 21$

4. $x^2 + 12x + 36$

5. $9x^2 - 12x + 4$

6. $x^2 - 16$

7. $4x^2 - 1$

8. $x^3 + x^2 - 7x + 2$

9. $(x^2 - 9)(x + 1) = x^3 + x^2 - 9x - 9$

10. $2x^2 + 2x + 5$

3.4 การแยกตัวประกอบ

ความหมายของการแยกตัวประกอบ

การแยกตัวประกอบ (Factorization) คือ การเขียนพหุนามในรูปผลคูณของพหุนามที่ง่ายกว่า


วิธีการแยกตัวประกอบ:

  1. หาตัวประกอบร่วม - นำตัวประกอบร่วมออกมาข้างหน้า
  2. ใช้สูตรพิเศษ - ใช้สูตรกำลังสองสมบูรณ์ หรือผลต่างกำลังสอง
  3. แยกพจน์กลาง - แยกพจน์กลางในพหุนามดีกรี 2
  4. จัดกลุ่ม - จัดพจน์เป็นกลุ่มแล้วหาตัวประกอบร่วม

สูตรที่ใช้ในการแยกตัวประกอบ

1. $a^2 + 2ab + b^2 = (a+b)^2$

2. $a^2 - 2ab + b^2 = (a-b)^2$

3. $a^2 - b^2 = (a+b)(a-b)$

4. $ax^2 + bx + c = (mx + p)(nx + q)$

ตัวอย่างที่ 1: หาตัวประกอบร่วม

โจทย์: จงแยกตัวประกอบ $6x^2 - 9x$

วิธีทำ:

หาตัวประกอบร่วมของ $6x^2$ และ $9x$

- ตัวประกอบร่วมของ 6 และ 9 คือ 3

- ตัวแปร $x$ มีเลขชี้กำลังต่ำสุดคือ $x^1$

ดังนั้น ตัวประกอบร่วมคือ $3x$

$$\begin{align} 6x^2 - 9x &= 3x(2x) - 3x(3)\\ &= 3x(2x - 3) \end{align}$$

ตอบ $3x(2x - 3)$

ตัวอย่างที่ 2: ใช้สูตรผลต่างกำลังสอง

โจทย์: จงแยกตัวประกอบ $x^2 - 25$

วิธีทำ:

สังเกตว่าเป็นรูปแบบ $a^2 - b^2 = (a+b)(a-b)$

โดย $a = x$ และ $b = 5$

$$x^2 - 25 = x^2 - 5^2 = (x+5)(x-5)$$

ตอบ $(x+5)(x-5)$

ตรวจสอบ: $(x+5)(x-5) = x^2 - 5x + 5x - 25 = x^2 - 25$ ✓

ตัวอย่างที่ 3: ใช้สูตรกำลังสองสมบูรณ์

โจทย์: จงแยกตัวประกอบ $4x^2 + 12x + 9$

วิธีทำ:

ตรวจสอบว่าเป็นรูปแบบ $a^2 + 2ab + b^2 = (a+b)^2$ หรือไม่

- พจน์แรก: $4x^2 = (2x)^2$ ดังนั้น $a = 2x$

- พจน์สุดท้าย: $9 = 3^2$ ดังนั้น $b = 3$

- พจน์กลาง: $2ab = 2(2x)(3) = 12x$ ✓

$$4x^2 + 12x + 9 = (2x)^2 + 2(2x)(3) + 3^2 = (2x + 3)^2$$

ตอบ $(2x + 3)^2$

ตัวอย่างที่ 4: แยกพจน์กลาง

โจทย์: จงแยกตัวประกอบ $x^2 + 5x + 6$

วิธีทำ:

หาจำนวนสองจำนวนที่:

- คูณกันได้ 6 (จากพจน์สุดท้าย)

- บวกกันได้ 5 (จากสัมประสิทธิ์ของ $x$)

ตอบ: 2 และ 3 (เพราะ $2 \times 3 = 6$ และ $2 + 3 = 5$)

$$\begin{align} x^2 + 5x + 6 &= x^2 + 2x + 3x + 6\\ &= x(x + 2) + 3(x + 2)\\ &= (x + 2)(x + 3) \end{align}$$

หรือ ใช้วิธีสังเกต: $x^2 + 5x + 6 = (x + 2)(x + 3)$

ตอบ $(x + 2)(x + 3)$

ตัวอย่างที่ 5: การแยกตัวประกอบแบบผสม

โจทย์: จงแยกตัวประกอบ $2x^2 - 50$

วิธีทำ:

ขั้นตอนที่ 1: หาตัวประกอบร่วมก่อน

$$2x^2 - 50 = 2(x^2 - 25)$$

ขั้นตอนที่ 2: แยกตัวประกอบในวงเล็บ (ผลต่างกำลังสอง)

$$= 2(x^2 - 5^2) = 2(x+5)(x-5)$$

ตอบ $2(x+5)(x-5)$

แบบฝึกหัดท้ายเรื่อง 3.4

  2. $6x^2 + 12x$
  3. $x^2 - 16$
  4. $9x^2 - 1$
  5. $x^2 + 8x + 16$
  6. $4x^2 - 20x + 25$
  7. $x^2 + 7x + 12$
  8. $x^2 - 3x - 10$
  9. $3x^2 - 27$
  10. $x^2 - 6x + 9$
  11. $2x^2 + 10x + 12$
  12. $x^2 - 9x + 20$

3.5 ห.ร.ม. และ ค.ร.น. ของพหุนาม

ความหมาย

ห.ร.ม. (หารร่วมมาก - Greatest Common Factor: GCF) ของพหุนาม คือ พหุนามที่มีดีกรีสูงสุดที่หารพหุนามทั้งหมดลงตัว


ค.ร.น. (คูณร่วมน้อย - Least Common Multiple: LCM) ของพหุนาม คือ พหุนามที่มีดีกรีต่ำสุดที่หารด้วยพหุนามทั้งหมดลงตัว


วิธีหา ห.ร.ม.:

  1. แยกตัวประกอบพหุนามแต่ละตัว
  2. เลือกตัวประกอบร่วมที่มีเลขชี้กำลังน้อยที่สุด
  3. นำตัวประกอบร่วมมาคูณกัน

วิธีหา ค.ร.น.:

  1. แยกตัวประกอบพหุนามแต่ละตัว
  2. เลือกตัวประกอบทุกตัวที่มีเลขชี้กำลังมากที่สุด
  3. นำตัวประกอบทั้งหมดมาคูณกัน

ความสัมพันธ์ระหว่าง ห.ร.ม. และ ค.ร.น.

$$\text{ห.ร.ม.} \times \text{ค.ร.น.} = \text{ผลคูณของพหุนามทั้งสอง}$$

ตัวอย่างที่ 1: หา ห.ร.ม. แบบง่าย

โจทย์: จงหา ห.ร.ม. ของ $6x^2$ และ $9x$

วิธีทำ:

แยกตัวประกอบ:

$6x^2 = 2 \times 3 \times x \times x = 2 \times 3 \times x^2$

$9x = 3 \times 3 \times x = 3^2 \times x$

ตัวประกอบร่วม:

- ตัวเลข: 3 (เลขชี้กำลังน้อยสุดคือ 1)

- ตัวแปร: $x$ (เลขชี้กำลังน้อยสุดคือ 1)

$$\text{ห.ร.ม.} = 3x$$

ตอบ $3x$

ตัวอย่างที่ 2: หา ค.ร.น. แบบง่าย

โจทย์: จงหา ค.ร.น. ของ $4x^2$ และ $6x^3$

วิธีทำ:

แยกตัวประกอบ:

$4x^2 = 2^2 \times x^2$

$6x^3 = 2 \times 3 \times x^3$

เลือกตัวประกอบที่มีเลขชี้กำลังสูงสุด:

- $2^2$ (จาก $4x^2$)

- $3$ (จาก $6x^3$)

- $x^3$ (จาก $6x^3$)

$$\text{ค.ร.น.} = 2^2 \times 3 \times x^3 = 12x^3$$

ตอบ $12x^3$

ตัวอย่างที่ 3: หา ห.ร.ม. ของพหุนามที่ซับซ้อน

โจทย์: จงหา ห.ร.ม. ของ $2x^2 - 8$ และ $x^2 - 4x + 4$

วิธีทำ:

แยกตัวประกอบพหุนามทั้งสอง:

$$2x^2 - 8 = 2(x^2 - 4) = 2(x+2)(x-2)$$

$$x^2 - 4x + 4 = (x-2)^2 = (x-2)(x-2)$$

ตัวประกอบร่วม: $(x-2)$ โดยเลขชี้กำลังน้อยสุดคือ 1

$$\text{ห.ร.ม.} = x - 2$$

ตอบ $x - 2$

ตัวอย่างที่ 4: หา ค.ร.น. ของพหุนามที่ซับซ้อน

โจทย์: จงหา ค.ร.น. ของ $x^2 - 9$ และ $x^2 + 6x + 9$

วิธีทำ:

แยกตัวประกอบพหุนามทั้งสอง:

$$x^2 - 9 = (x+3)(x-3)$$

$$x^2 + 6x + 9 = (x+3)^2 = (x+3)(x+3)$$

เลือกตัวประกอบที่มีเลขชี้กำลังสูงสุด:

- $(x+3)^2$ (เลขชี้กำลังสูงสุดคือ 2)

- $(x-3)$ (ปรากฏในพหุนามแรกเท่านั้น)

$$\text{ค.ร.น.} = (x+3)^2(x-3) = (x+3)(x+3)(x-3)$$

ตอบ $(x+3)^2(x-3)$

ตัวอย่างที่ 5: หาทั้ง ห.ร.ม. และ ค.ร.น.

โจทย์: จงหา ห.ร.ม. และ ค.ร.น. ของ $6x^2 - 6$ และ $4x^2 - 8x + 4$

วิธีทำ:

แยกตัวประกอบ:

$$6x^2 - 6 = 6(x^2 - 1) = 6(x+1)(x-1)$$

$$4x^2 - 8x + 4 = 4(x^2 - 2x + 1) = 4(x-1)^2$$

หา ห.ร.ม.:

- ตัวเลข: ห.ร.ม. ของ 6 และ 4 = 2

- ตัวประกอบร่วม: $(x-1)$ เลขชี้กำลังน้อยสุดคือ 1

$$\text{ห.ร.ม.} = 2(x-1)$$

หา ค.ร.น.:

- ตัวเลข: ค.ร.น. ของ 6 และ 4 = 12

- ตัวประกอบทั้งหมด: $(x+1)$, $(x-1)^2$

$$\text{ค.ร.น.} = 12(x+1)(x-1)^2$$

ตอบ ห.ร.ม. = $2(x-1)$, ค.ร.น. = $12(x+1)(x-1)^2$

แบบฝึกหัดท้ายเรื่อง 3.5

  1. จงหา ห.ร.ม. ของ $12x$ และ $18x^2$
  2. จงหา ค.ร.น. ของ $4x$ และ $6x^2$
  3. จงหา ห.ร.ม. ของ $x^2 - 4$ และ $x^2 + 4x + 4$
  4. จงหา ค.ร.น. ของ $x^2 - 1$ และ $x^2 + 2x + 1$
  5. จงหา ห.ร.ม. ของ $3x^2 - 12$ และ $2x^2 - 4x - 6$
  6. จงหา ค.ร.น. ของ $(x-2)(x+3)$ และ $(x-2)^2$
  7. จงหา ห.ร.ม. และ ค.ร.น. ของ $x^2 - 9$ และ $x^2 - 6x + 9$

เฉลย:

1. $6x$

2. $12x^2$

3. $x + 2$

4. $(x+1)^2(x-1)$

5. $x + 2$

6. $(x-2)^2(x+3)$

7. ห.ร.ม. = $x - 3$, ค.ร.น. = $(x+3)(x-3)^2$

3.6 การหารพหุนาม

หลักการหารพหุนาม

การหารพหุนาม คล้ายกับการหารเลขธรรมดา โดยจะได้ ผลหาร (Quotient) และ เศษเหลือ (Remainder)


ความสัมพันธ์ในการหาร:

$$\text{ตัวตั้ง} = (\text{ตัวหาร}) \times (\text{ผลหาร}) + \text{เศษเหลือ}$$

หรือ

$$\frac{\text{ตัวตั้ง}}{\text{ตัวหาร}} = \text{ผลหาร} + \frac{\text{เศษเหลือ}}{\text{ตัวหาร}}$$


วิธีการหารพหุนาม:

  1. การหารแบบแยกตัวประกอบ - ใช้เมื่อพหุนามแยกตัวประกอบได้
  2. การหารแบบยาว (Long Division) - ใช้เมื่อไม่สามารถแยกตัวประกอบได้ง่าย

ทฤษฎีบทเศษเหลือ (Remainder Theorem)

เมื่อหารพหุนาม $P(x)$ ด้วย $(x-a)$ จะได้เศษเหลือเป็น $P(a)$

หากหารลงตัว แสดงว่า $P(a) = 0$ และ $(x-a)$ เป็นตัวประกอบของ $P(x)$

ตัวอย่างที่ 1: การหารด้วยการแยกตัวประกอบ

โจทย์: จงหาร $(x^2 - 9) \div (x - 3)$

วิธีทำ:

แยกตัวประกอบตัวตั้ง:

$$x^2 - 9 = (x+3)(x-3)$$

หารด้วย $(x-3)$:

$$\frac{(x+3)(x-3)}{(x-3)} = x + 3$$

ตอบ ผลหาร = $x + 3$, เศษเหลือ = $0$

ตัวอย่างที่ 2: การหารแบบยาว (พื้นฐาน)

โจทย์: จงหาร $(2x^2 + 7x + 3) \div (x + 3)$

วิธีทำ: ใช้วิธีหารยาว

ขั้นตอนที่ 1: $2x^2 \div x = 2x$

$$2x(x+3) = 2x^2 + 6x$$

$$(2x^2 + 7x + 3) - (2x^2 + 6x) = x + 3$$

ขั้นตอนที่ 2: $x \div x = 1$

$$1(x+3) = x + 3$$

$$(x + 3) - (x + 3) = 0$$

$$\begin{array}{r|l} & 2x + 1\\ \hline x+3 & 2x^2 + 7x + 3\\ & 2x^2 + 6x\\ \hline & x + 3\\ & x + 3\\ \hline & 0 \end{array}$$

ตอบ ผลหาร = $2x + 1$, เศษเหลือ = $0$

ตัวอย่างที่ 3: การหารที่มีเศษเหลือ

โจทย์: จงหาร $(x^2 + 5x + 7) \div (x + 2)$

วิธีทำ:

ขั้นตอนที่ 1: $x^2 \div x = x$

$$x(x+2) = x^2 + 2x$$

$$(x^2 + 5x + 7) - (x^2 + 2x) = 3x + 7$$

ขั้นตอนที่ 2: $3x \div x = 3$

$$3(x+2) = 3x + 6$$

$$(3x + 7) - (3x + 6) = 1$$

$$\frac{x^2 + 5x + 7}{x + 2} = x + 3 + \frac{1}{x + 2}$$

ตอบ ผลหาร = $x + 3$, เศษเหลือ = $1$

ตรวจสอบ: $(x+2)(x+3) + 1 = x^2 + 5x + 6 + 1 = x^2 + 5x + 7$ ✓

ตัวอย่างที่ 4: ใช้ทฤษฎีบทเศษเหลือ

โจทย์: จงหาเศษเหลือเมื่อหาร $x^3 - 2x^2 + 3x - 5$ ด้วย $(x - 2)$

วิธีทำ:

ใช้ทฤษฎีบทเศษเหลือ: แทน $x = 2$ ในพหุนาม

$$\begin{align} P(2) &= (2)^3 - 2(2)^2 + 3(2) - 5\\ &= 8 - 8 + 6 - 5\\ &= 1 \end{align}$$

ตอบ เศษเหลือ = $1$

หมายเหตุ: เนื่องจากเศษเหลือไม่เป็น 0 แสดงว่า $(x-2)$ ไม่เป็นตัวประกอบของพหุนาม

ตัวอย่างที่ 5: การหารพหุนามดีกรีสูง

โจทย์: จงหาร $(x^3 + 2x^2 - 5x - 6) \div (x + 1)$

วิธีทำ: ใช้วิธีหารยาว

ขั้นที่ 1: $x^3 \div x = x^2$

$x^2(x+1) = x^3 + x^2$

$(x^3 + 2x^2 - 5x - 6) - (x^3 + x^2) = x^2 - 5x - 6$

ขั้นที่ 2: $x^2 \div x = x$

$x(x+1) = x^2 + x$

$(x^2 - 5x - 6) - (x^2 + x) = -6x - 6$

ขั้นที่ 3: $-6x \div x = -6$

$-6(x+1) = -6x - 6$

$(-6x - 6) - (-6x - 6) = 0$

ตอบ ผลหาร = $x^2 + x - 6$, เศษเหลือ = $0$

ตรวจสอบ: $(x+1)(x^2 + x - 6) = x^3 + x^2 - 6x + x^2 + x - 6 = x^3 + 2x^2 - 5x - 6$ ✓

แบบฝึกหัดท้ายเรื่อง 3.6

  1. $(6x^2 - 9x) \div 3x$
  2. $(x^2 - 16) \div (x - 4)$
  3. $(x^2 + 7x + 12) \div (x + 3)$
  4. $(2x^2 + 5x - 3) \div (x + 3)$
  5. $(x^2 + 4x + 5) \div (x + 2)$ (จงหาผลหารและเศษเหลือ)
  6. จงหาเศษเหลือเมื่อหาร $x^2 - 3x + 5$ ด้วย $(x - 1)$ โดยใช้ทฤษฎีบทเศษเหลือ
  7. $(x^3 - 8) \div (x - 2)$
  8. $(x^3 + 3x^2 - 4) \div (x + 2)$
  9. $(2x^3 - x^2 + 3x - 1) \div (x - 1)$ จงหาผลหารและเศษเหลือ
  10. พหุนาม $x^3 - 2x^2 + kx - 6$ หารด้วย $(x - 2)$ ลงตัว จงหาค่า $k$

เฉลย:

1. $2x - 3$

2. $x + 4$

3. $x + 4$

4. $2x - 1$

5. ผลหาร = $x + 2$, เศษเหลือ = $1$

6. $P(1) = 1 - 3 + 5 = 3$ ดังนั้น เศษเหลือ = $3$

7. $x^2 + 2x + 4$

8. $x^2 + x - 2$

9. ผลหาร = $2x^2 + x + 4$, เศษเหลือ = $3$

10. $P(2) = 8 - 8 + 2k - 6 = 2k - 6 = 0$ ดังนั้น $k = 3$

15. ผลหาร = $x + 2$, เศษเหลือ = $3$

16. $P(2) = 4 + 4 - 3 = 5$ ดังนั้น เศษเหลือ = $5$

ส่วนที่ 6: โจทย์ผสม (4 คะแนน)

  1. จงแยกตัวประกอบ $3x^2 - 27$ แล้วหารด้วย $(x + 3)$
  2. ถ้า $A = 2x^2 + x - 3$ และ $B = x^2 - 2x + 1$ จงหา $A - B$ และแยกตัวประกอบ
  3. จงกระจาย $(x + 2)^2 - (x - 1)^2$
  4. พหุนาม $x^3 - 3x^2 + ax - 4$ หารด้วย $(x - 2)$ ลงตัว จงหาค่า $a$

เฉลย ส่วนที่ 6:

17. $3x^2 - 27 = 3(x^2-9) = 3(x+3)(x-3)$ หารด้วย $(x+3)$ ได้ $3(x-3) = 3x - 9$

18. $A - B = x^2 + 3x - 4 = (x+4)(x-1)$

19. $(x^2+4x+4) - (x^2-2x+1) = 6x + 3 = 3(2x+1)$

20. $P(2) = 8 - 12 + 2a - 4 = 2a - 8 = 0$ ดังนั้น $a = 4$
