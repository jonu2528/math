คณิตศาสตร์ มัธยมศึกษาปีที่ 4

คณิตศาสตร์ ม.4 เป็นจุดเริ่มต้นของคณิตศาสตร์ระดับมัธยมปลาย มีเนื้อหาที่ลึกซึ้งและท้าทาย ครอบคลุมเซตและตรรกศาสตร์ ฟังก์ชันและกราฟ เลขยกกำลังและลอการิทึม ลำดับและอนุกรม ตรีโกณมิติ และเวกเตอร์ ซึ่งเป็นพื้นฐานสำคัญสำหรับการศึกษาในระดับที่สูงขึ้น

บทที่ 1: เซตและตรรกศาสตร์ (Sets and Logic)

1.1 ความหมายของเซต

เซต คือ กลุ่มของสิ่งต่างๆ ที่ชัดเจน เรียกสิ่งต่างๆ ในเซตว่า สมาชิกของเซต

ตัวอย่างที่ 1:

A = {1, 2, 3, 4, 5} เป็นเซตของจำนวนเต็มบวก 5 จำนวนแรก

B = {x | x เป็นจำนวนเต็มคู่ที่มากกว่า 0 และน้อยกว่า 10}

B = {2, 4, 6, 8}

1.2 ประเภทของเซต

  • เซตว่าง (∅): เซตที่ไม่มีสมาชิก
  • เซตจำกัด: เซตที่มีสมาชิกจำนวนจำกัด
  • เซตอนันต์: เซตที่มีสมาชิกจำนวนไม่จำกัด
  • เซตย่อย (⊆): A ⊆ B ถ้าสมาชิกทุกตัวของ A เป็นสมาชิกของ B

1.3 การดำเนินการกับเซต

สัญลักษณ์เซต:

A ∪ B = ยูเนียน (สมาชิกที่อยู่ใน A หรือ B หรือทั้งสอง)
A ∩ B = อินเตอร์เซกชัน (สมาชิกที่อยู่ใน A และ B)
A' = คอมพลีเมนต์ (สมาชิกที่ไม่อยู่ใน A)
A - B = ผลต่าง (สมาชิกที่อยู่ใน A แต่ไม่อยู่ใน B)

ตัวอย่างที่ 2:

กำหนด A = {1, 2, 3, 4} และ B = {3, 4, 5, 6}

A ∪ B = {1, 2, 3, 4, 5, 6}

A ∩ B = {3, 4}

A - B = {1, 2}

1.4 ตรรกศาสตร์เบื้องต้น

ประพจน์ คือ ข้อความที่มีค่าความจริงเป็นจริงหรือเท็จอย่างใดอย่างหนึ่ง

ตัวเชื่อมประพจน์:

p ∧ q (และ) - จริงก็ต่อเมื่อ p และ q จริงทั้งคู่
p ∨ q (หรือ) - จริงเมื่อ p หรือ q จริงอย่างน้อยหนึ่งตัว
~p (ไม่) - จริงก็ต่อเมื่อ p เท็จ
p → q (ถ้า...แล้ว) - เท็จก็ต่อเมื่อ p จริงและ q เท็จ

บทที่ 2: ฟังก์ชันและกราฟ

2.1 ประเภทของฟังก์ชัน

  • ฟังก์ชันเชิงเส้น: f(x) = mx + b
  • ฟังก์ชันกำลังสอง: f(x) = ax² + bx + c
  • ฟังก์ชันค่าสัมบูรณ์: f(x) = |x|
  • ฟังก์ชันชี้กำลัง: f(x) = aˣ

2.2 ฟังก์ชันผสม

การทำฟังก์ชันผสม (f ∘ g)(x) = f(g(x))

ตัวอย่างที่ 3:

กำหนด f(x) = 2x + 1 และ g(x) = x² จงหา (f ∘ g)(x)

วิธีทำ:

(f ∘ g)(x) = f(g(x)) = f(x²) = 2(x²) + 1 = 2x² + 1

ตอบ: 2x² + 1

2.3 ฟังก์ชันผกผัน

ฟังก์ชันผกผัน f⁻¹ จะสลับ domain และ range ของ f

ตัวอย่างที่ 4:

จงหาฟังก์ชันผกผันของ f(x) = 2x + 3

วิธีทำ:

ให้ y = 2x + 3

สลับ x และ y: x = 2y + 3

2y = x - 3

y = (x - 3)/2

ตอบ: f⁻¹(x) = (x - 3)/2

บทที่ 3: เลขยกกำลังและลอการิทึม

3.1 กฎของเลขยกกำลัง

สูตรเลขยกกำลัง:

aᵐ × aⁿ = aᵐ⁺ⁿ
aᵐ ÷ aⁿ = aᵐ⁻ⁿ
(aᵐ)ⁿ = aᵐⁿ
(ab)ⁿ = aⁿbⁿ
a⁰ = 1 (a ≠ 0)
a⁻ⁿ = 1/aⁿ

3.2 ลอการิทึม (Logarithm)

ลอการิทึม คือ เลขชี้กำลังที่ทำให้ได้จำนวนที่ต้องการ

นิยาม:

logₐ b = x ⟺ aˣ = b

โดยที่ a > 0, a ≠ 1, b > 0

ตัวอย่างที่ 5:

log₂ 8 = ? เพราะ 2³ = 8 ดังนั้น log₂ 8 = 3

log₁₀ 100 = ? เพราะ 10² = 100 ดังนั้น log₁₀ 100 = 2

3.3 กฎของลอการิทึม

สูตรลอการิทึม:

logₐ(mn) = logₐ m + logₐ n
logₐ(m/n) = logₐ m - logₐ n
logₐ mⁿ = n logₐ m
logₐ a = 1
logₐ 1 = 0

ตัวอย่างที่ 6:

จงหาค่าของ log₂ 32

วิธีทำ: 2ˣ = 32 = 2⁵

ดังนั้น x = 5

ตอบ: log₂ 32 = 5

บทที่ 4: ลำดับและอนุกรม

4.1 ลำดับเลขคณิต (Arithmetic Sequence)

ลำดับที่แต่ละพจน์ต่างกันด้วยผลต่างคงที่ (d)

สูตร:

aₙ = a₁ + (n-1)d
Sₙ = n/2 (a₁ + aₙ) หรือ Sₙ = n/2 [2a₁ + (n-1)d]

โดยที่ aₙ = พจน์ที่ n, d = ผลต่างร่วม, Sₙ = ผลรวมของ n พจน์แรก

ตัวอย่างที่ 7:

จงหาพจน์ที่ 10 ของลำดับ 3, 7, 11, 15, ...

วิธีทำ: a₁ = 3, d = 4

a₁₀ = 3 + (10-1)4 = 3 + 36 = 39

ตอบ: 39

4.2 ลำดับเรขาคณิต (Geometric Sequence)

ลำดับที่แต่ละพจน์มีอัตราส่วนร่วมคงที่ (r)

สูตร:

aₙ = a₁ × r⁽ⁿ⁻¹⁾
Sₙ = a₁(rⁿ - 1)/(r - 1) เมื่อ r ≠ 1
S∞ = a₁/(1 - r) เมื่อ |r| < 1

ตัวอย่างที่ 8:

จงหาพจน์ที่ 5 ของลำดับ 2, 6, 18, 54, ...

วิธีทำ: a₁ = 2, r = 3

a₅ = 2 × 3⁴ = 2 × 81 = 162

ตอบ: 162

บทที่ 5: ตรีโกณมิติ

5.1 เอกลักษณ์ตรีโกณมิติ

เอกลักษณ์พื้นฐาน:

sin²θ + cos²θ = 1
1 + tan²θ = sec²θ
1 + cot²θ = csc²θ
tan θ = sin θ / cos θ

5.2 กฎของไซน์และโคไซน์

กฎของไซน์:

a/sin A = b/sin B = c/sin C

กฎของโคไซน์:

c² = a² + b² - 2ab cos C

ตัวอย่างที่ 9:

ในสามเหลี่ยม ABC มี a = 8, b = 6, C = 60° จงหาความยาวด้าน c

วิธีทำ: ใช้กฎของโคไซน์

c² = 8² + 6² - 2(8)(6)cos 60°

c² = 64 + 36 - 96(1/2)

c² = 100 - 48 = 52

c = √52 = 2√13

ตอบ: 2√13 หน่วย

5.3 กราฟของฟังก์ชันตรีโกณมิติ

กราฟของ y = sin x และ y = cos x เป็นคลื่น มีคาบ 2π

กราฟของ y = tan x มีคาบ π และมีเส้นกำกับแนวดิ่ง

บทที่ 6: เวกเตอร์เบื้องต้น

6.1 ความหมายของเวกเตอร์

เวกเตอร์ คือ ปริมาณที่มีทั้งขนาดและทิศทาง แทนด้วย →a หรือ a

6.2 การบวกและลบเวกเตอร์

ถ้า →a = (a₁, a₂) และ →b = (b₁, b₂)

สูตร:

→a + →b = (a₁ + b₁, a₂ + b₂)
→a - →b = (a₁ - b₁, a₂ - b₂)
k→a = (ka₁, ka₂)

ตัวอย่างที่ 10:

กำหนด →a = (3, 4) และ →b = (1, 2) จงหา →a + →b

วิธีทำ:

→a + →b = (3+1, 4+2) = (4, 6)

ตอบ: (4, 6)

6.3 ขนาดของเวกเตอร์

สูตร:

|→a| = √(a₁² + a₂²)

แบบฝึกหัดท้ายบท

ข้อ 1: กำหนด A = {1, 2, 3} และ B = {2, 3, 4} จงหา A ∩ B

เฉลย: A ∩ B = {2, 3}

ข้อ 2: จงหาค่าของ log₃ 27

เฉลย: 3ˣ = 27 = 3³, ดังนั้น x = 3

ข้อ 3: จงหาพจน์ที่ 8 ของลำดับเลขคณิต 5, 9, 13, 17, ...

เฉลย: a₁ = 5, d = 4

a₈ = 5 + (8-1)4 = 5 + 28 = 33

ข้อ 4: กำหนด →a = (2, 3) และ →b = (4, 1) จงหา →a + →b

เฉลย: →a + →b = (2+4, 3+1) = (6, 4)

ข้อ 5: จงหาฟังก์ชันผกผันของ f(x) = 3x - 2

เฉลย:

y = 3x - 2

x = 3y - 2

3y = x + 2

y = (x + 2)/3

f⁻¹(x) = (x + 2)/3
