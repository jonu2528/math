# เว็บไซต์คณิตศาสตร์มัธยม (Math Learning Hub)

เว็บไซต์ให้ความรู้คณิตศาสตร์ระดับมัธยมศึกษาปีที่ 1-6 อย่างละเอียด พร้อมสำหรับการติดโฆษณา Google AdSense

## คุณสมบัติ

- ✅ เนื้อหาครบถ้วนทุกระดับชั้น ม.1-6
- ✅ ออกแบบ Responsive รองรับทุกอุปกรณ์
- ✅ พื้นที่สำหรับ AdSense พร้อมใช้งาน
- ✅ SEO Friendly
- ✅ เนื้อหาเป็นภาษาไทย
- ✅ ตัวอย่างและแบบฝึกหัดมากมาย


## เนื้อหาที่ครอบคลุม

### มัธยมศึกษาตอนต้น (ม.1-3)
- **ม.1**: จำนวนเต็ม, เศษส่วนและทศนิยม, พีชคณิตเบื้องต้น, เรขาคณิต
- **ม.2**: เลขยกกำลัง, สมการเชิงเส้น, อัตราส่วนและร้อยละ, พื้นที่และปริมาตร
- **ม.3**: สมการกำลังสอง, ฟังก์ชัน, ตรีโกณมิติเบื้องต้น, สถิติ

### มัธยมศึกษาตอนปลาย (ม.4-6)
- **ม.4**: เซตและตรรกศาสตร์, ฟังก์ชันและกราฟ, ลอการิทึม, ลำดับและอนุกรม, เวกเตอร์
- **ม.5**: เมทริกซ์, ความน่าจะเป็น, สถิติเชิงวิเคราะห์, ลิมิตและอนุพันธ์
- **ม.6**: ปริพันธ์, สมการเชิงอนุพันธ์, เวกเตอร์สามมิติ, เรขาคณิตวิเคราะห์

## การติดตั้ง Google AdSense

เว็บไซต์นี้มีพื้นที่สำหรับโฆษณา AdSense ในตำแหน่งต่างๆ:

1. **Top Banner** (728x90 หรือ Responsive)
2. **Sidebar Ads** (160x600, 300x250, 300x600)
3. **In-Article Ads**
4. **In-Feed Ads**
5. **Bottom Banner** (728x90)

### วิธีการติดตั้ง AdSense

1. สมัครบัญชี Google AdSense
2. รอการอนุมัติ
3. สร้างหน่วยโฆษณา
4. คัดลอกโค้ดโฆษณา
5. แทนที่ในส่วนที่มี comment `<!-- Google AdSense Code Here -->`

## การใช้งาน

1. เปิดไฟล์ `index.html` ในเบราว์เซอร์
2. สำรวจเนื้อหาในแต่ละระดับชั้น
3. ใช้เมนูด้านบนเพื่อนำทางระหว่างหน้า

## ฟีเจอร์พิเศษ

- **Mobile-Friendly**: ใช้งานได้ดีบนมือถือและแท็บเล็ต
- **Interactive**: มีปุ่มแสดง/ซ่อนเฉลยแบบฝึกหัด
- **Smooth Scrolling**: เลื่อนหน้าอย่างนุ่มนวล
- **Back to Top Button**: ปุ่มกลับขึ้นด้านบนอัตโนมัติ

## เทคโนโลยีที่ใช้

- HTML5
- CSS3 (Responsive Design)
- Vanilla JavaScript
- Google Fonts (Sarabun)
