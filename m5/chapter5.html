บทที่ 5: ลิมิตและความต่อเนื่อง

บทนี้จะเรียนรู้เกี่ยวกับ ลิมิตและความต่อเนื่องของฟังก์ชัน ซึ่งเป็นพื้นฐานสำคัญของแคลคูลัส เราจะศึกษาความหมายของลิมิต กฎการหาลิมิต ลิมิตที่อนันต์ ลิมิตเมื่อ x เข้าใกล้อนันต์ ความต่อเนื่องของฟังก์ชัน และทฤษฎีบทค่ากลาง ซึ่งจะนำไปใช้ในการศึกษาอนุพันธ์และปริพันธ์ในอนาคต

5.1 ลิมิตของฟังก์ชัน

ความหมายของลิมิต

ลิมิต (Limit) คือค่าที่ฟังก์ชัน $f(x)$ เข้าใกล้ เมื่อ $x$ เข้าใกล้ค่าใดค่าหนึ่ง

เขียนแทนด้วย $$\lim_{x \to a} f(x) = L$$

หมายความว่า เมื่อ $x$ เข้าใกล้ $a$ (แต่ $x \neq a$) แล้วค่า $f(x)$ จะเข้าใกล้ $L$

หมายเหตุ:

  • ลิมิตของ $f(x)$ ที่ $x = a$ อาจมีค่าต่างจากค่าของ $f(a)$
  • แม้ว่า $f(a)$ อาจไม่นิยาม แต่ลิมิตอาจมีค่าได้
  • เราพิจารณาค่าของ $f(x)$ เมื่อ $x$ เข้าใกล้ $a$ ทั้งจากทางซ้าย (Left-hand limit: $\lim_{x \to a^-}$) และทางขวา (Right-hand limit: $\lim_{x \to a^+}$)

ลิมิตพื้นฐาน

$$\lim_{x \to a} c = c \quad \text{(เมื่อ } c \text{ เป็นค่าคงที่)}$$

$$\lim_{x \to a} x = a$$

$$\lim_{x \to a} x^n = a^n$$

ตัวอย่างที่ 1: หาลิมิตโดยการแทนค่าโดยตรง

โจทย์: หา $\displaystyle\lim_{x \to 3} (2x + 5)$

วิธีทำ:

เนื่องจากฟังก์ชัน $f(x) = 2x + 5$ เป็นฟังก์ชันพหุนาม สามารถแทนค่าโดยตรงได้

$$\lim_{x \to 3} (2x + 5) = 2(3) + 5 = 6 + 5 = 11$$

ตอบ: $11$

ตัวอย่างที่ 2: หาลิมิตของฟังก์ชันกำลัง

โจทย์: หา $\displaystyle\lim_{x \to 2} (x^2 - 3x + 4)$

วิธีทำ:

แทนค่า $x = 2$ ลงในฟังก์ชัน

$$\lim_{x \to 2} (x^2 - 3x + 4) = 2^2 - 3(2) + 4$$

$$= 4 - 6 + 4 = 2$$

ตอบ: $2$

ตัวอย่างที่ 3: หาลิมิตของฟังก์ชันตรรกยะ (รูปแบบ 0/0)

โจทย์: หา $\displaystyle\lim_{x \to 2} \frac{x^2 - 4}{x - 2}$

วิธีทำ:

ถ้าแทนค่า $x = 2$ โดยตรง จะได้ $\frac{0}{0}$ ซึ่งไม่นิยาม

ดังนั้น ต้องทำการแยกตัวประกอบก่อน

$$\lim_{x \to 2} \frac{x^2 - 4}{x - 2} = \lim_{x \to 2} \frac{(x-2)(x+2)}{x - 2}$$

$$= \lim_{x \to 2} (x + 2)$$

$$= 2 + 2 = 4$$

ตอบ: $4$

ตัวอย่างที่ 4: หาลิมิตโดยการแยกตัวประกอบ

โจทย์: หา $\displaystyle\lim_{x \to -3} \frac{x^2 + 5x + 6}{x + 3}$

วิธีทำ:

แยกตัวประกอบเศษ:

$$\lim_{x \to -3} \frac{x^2 + 5x + 6}{x + 3} = \lim_{x \to -3} \frac{(x+2)(x+3)}{x + 3}$$

$$= \lim_{x \to -3} (x + 2)$$

$$= -3 + 2 = -1$$

ตอบ: $-1$

5.2 กฎการหาลิมิต

กฎของลิมิต (Limit Laws)

ถ้า $\displaystyle\lim_{x \to a} f(x) = L$ และ $\displaystyle\lim_{x \to a} g(x) = M$ แล้ว

กฎการหาลิมิต

1. กฎการบวก/ลบ:

$$\lim_{x \to a} [f(x) \pm g(x)] = \lim_{x \to a} f(x) \pm \lim_{x \to a} g(x) = L \pm M$$

2. กฎการคูณด้วยค่าคงที่:

$$\lim_{x \to a} [c \cdot f(x)] = c \cdot \lim_{x \to a} f(x) = c \cdot L$$

3. กฎการคูณ:

$$\lim_{x \to a} [f(x) \cdot g(x)] = \lim_{x \to a} f(x) \cdot \lim_{x \to a} g(x) = L \cdot M$$

4. กฎการหาร:

$$\lim_{x \to a} \frac{f(x)}{g(x)} = \frac{\lim_{x \to a} f(x)}{\lim_{x \to a} g(x)} = \frac{L}{M} \quad \text{(เมื่อ } M \neq 0)$$

5. กฎของเลขยกกำลัง:

$$\lim_{x \to a} [f(x)]^n = \left[\lim_{x \to a} f(x)\right]^n = L^n$$

6. กฎของรากที่ n:

$$\lim_{x \to a} \sqrt[n]{f(x)} = \sqrt[n]{\lim_{x \to a} f(x)} = \sqrt[n]{L}$$

ตัวอย่างที่ 1: ใช้กฎการบวกและคูณ

โจทย์: หา $\displaystyle\lim_{x \to 1} (3x^2 + 2x - 5)$

วิธีทำ:

$$\lim_{x \to 1} (3x^2 + 2x - 5) = \lim_{x \to 1} 3x^2 + \lim_{x \to 1} 2x - \lim_{x \to 1} 5$$

$$= 3\lim_{x \to 1} x^2 + 2\lim_{x \to 1} x - 5$$

$$= 3(1)^2 + 2(1) - 5$$

$$= 3 + 2 - 5 = 0$$

ตอบ: $0$

ตัวอย่างที่ 2: ใช้กฎการคูณและหาร

โจทย์: หา $\displaystyle\lim_{x \to 2} \frac{x^3 + 1}{2x - 1}$

วิธีทำ:

$$\lim_{x \to 2} \frac{x^3 + 1}{2x - 1} = \frac{\lim_{x \to 2} (x^3 + 1)}{\lim_{x \to 2} (2x - 1)}$$

$$= \frac{2^3 + 1}{2(2) - 1} = \frac{8 + 1}{4 - 1}$$

$$= \frac{9}{3} = 3$$

ตอบ: $3$

ตัวอย่างที่ 3: การทำตรรกยะเศษและส่วน (Rationalization)

โจทย์: หา $\displaystyle\lim_{x \to 0} \frac{\sqrt{x + 4} - 2}{x}$

วิธีทำ:

คูณทั้งเศษและส่วนด้วย $\sqrt{x + 4} + 2$

$$\lim_{x \to 0} \frac{\sqrt{x + 4} - 2}{x} \cdot \frac{\sqrt{x + 4} + 2}{\sqrt{x + 4} + 2}$$

$$= \lim_{x \to 0} \frac{(x + 4) - 4}{x(\sqrt{x + 4} + 2)}$$

$$= \lim_{x \to 0} \frac{x}{x(\sqrt{x + 4} + 2)}$$

$$= \lim_{x \to 0} \frac{1}{\sqrt{x + 4} + 2}$$

$$= \frac{1}{\sqrt{0 + 4} + 2} = \frac{1}{2 + 2} = \frac{1}{4}$$

ตอบ: $\frac{1}{4}$

ตัวอย่างที่ 4: ใช้กฎเลขยกกำลังและรากที่สอง

โจทย์: หา $\displaystyle\lim_{x \to 4} \sqrt{2x + 1}$

วิธีทำ:

$$\lim_{x \to 4} \sqrt{2x + 1} = \sqrt{\lim_{x \to 4} (2x + 1)}$$

$$= \sqrt{2(4) + 1}$$

$$= \sqrt{8 + 1} = \sqrt{9} = 3$$

ตอบ: $3$

5.3 ลิมิตที่อนันต์

ลิมิตที่อนันต์ (Infinite Limits)

ลิมิตที่อนันต์ เกิดขึ้นเมื่อค่าของฟังก์ชันเพิ่มขึ้นหรือลดลงไปเรื่อยๆ ไม่มีที่สิ้นสุด

$$\lim_{x \to a} f(x) = +\infty \quad \text{หมายความว่า } f(x) \text{ เพิ่มขึ้นไปเรื่อยๆ เมื่อ } x \to a$$

$$\lim_{x \to a} f(x) = -\infty \quad \text{หมายความว่า } f(x) \text{ ลดลงไปเรื่อยๆ เมื่อ } x \to a$$

เส้นกำกับดิ่ง (Vertical Asymptote): ถ้า $\displaystyle\lim_{x \to a} f(x) = \pm\infty$ แล้วกราฟของ $f(x)$ จะมีเส้นกำกับดิ่งที่ $x = a$

กฎการหาลิมิตที่อนันต์

$$\lim_{x \to a} \frac{c}{(x-a)^n} = \begin{cases} +\infty & \text{ถ้า } c > 0 \text{ และ } n \text{ เป็นจำนวนคู่} \\ -\infty & \text{ถ้า } c < 0 \text{ และ } n \text{ เป็นจำนวนคู่} \\ +\infty & \text{ถ้า } c > 0 \text{ และ } n \text{ เป็นจำนวนคี่, } x \to a^+ \\ -\infty & \text{ถ้า } c > 0 \text{ และ } n \text{ เป็นจำนวนคี่, } x \to a^- \end{cases}$$

ตัวอย่างที่ 1: ลิมิตที่อนันต์อย่างง่าย

โจทย์: หา $\displaystyle\lim_{x \to 0} \frac{1}{x^2}$

วิธีทำ:

เมื่อ $x \to 0$ จะได้ $x^2 \to 0$ และ $x^2 > 0$ เสมอ

ดังนั้น $\frac{1}{x^2} \to +\infty$

$$\lim_{x \to 0} \frac{1}{x^2} = +\infty$$

ตอบ: $+\infty$

ตัวอย่างที่ 2: ลิมิตทางซ้ายและทางขวา

โจทย์: หา $\displaystyle\lim_{x \to 2^+} \frac{1}{x-2}$ และ $\displaystyle\lim_{x \to 2^-} \frac{1}{x-2}$

วิธีทำ:

ลิมิตทางขวา: เมื่อ $x \to 2^+$ แล้ว $x > 2$ ทำให้ $x - 2 > 0$

$$\lim_{x \to 2^+} \frac{1}{x-2} = +\infty$$

ลิมิตทางซ้าย: เมื่อ $x \to 2^-$ แล้ว $x < 2$ ทำให้ $x - 2 < 0$

$$\lim_{x \to 2^-} \frac{1}{x-2} = -\infty$$

ตอบ: $\displaystyle\lim_{x \to 2^+} \frac{1}{x-2} = +\infty$ และ $\displaystyle\lim_{x \to 2^-} \frac{1}{x-2} = -\infty$

ตัวอย่างที่ 3: หาเส้นกำกับดิ่ง

โจทย์: หาเส้นกำกับดิ่งของฟังก์ชัน $f(x) = \frac{x+1}{x^2-9}$

วิธีทำ:

เส้นกำกับดิ่งเกิดเมื่อตัวส่วนเป็นศูนย์

$$x^2 - 9 = 0$$

$$(x-3)(x+3) = 0$$

$$x = 3 \text{ หรือ } x = -3$$

ตรวจสอบที่ $x = 3$:

$$\lim_{x \to 3} \frac{x+1}{x^2-9} = \lim_{x \to 3} \frac{x+1}{(x-3)(x+3)} = \pm\infty$$

ตรวจสอบที่ $x = -3$:

$$\lim_{x \to -3} \frac{x+1}{x^2-9} = \lim_{x \to -3} \frac{x+1}{(x-3)(x+3)} = \pm\infty$$

ตอบ: เส้นกำกับดิ่งคือ $x = 3$ และ $x = -3$

ตัวอย่างที่ 4: ลิมิตของฟังก์ชันตรรกยะที่อนันต์

โจทย์: หา $\displaystyle\lim_{x \to 1} \frac{2x}{(x-1)^2}$

วิธีทำ:

เมื่อ $x \to 1$ จะได้

เศษ: $2x \to 2(1) = 2 > 0$

ส่วน: $(x-1)^2 \to 0$ และ $(x-1)^2 > 0$ เสมอ

ดังนั้น $$\lim_{x \to 1} \frac{2x}{(x-1)^2} = +\infty$$

ตอบ: $+\infty$

5.4 ลิมิตเมื่อ x เข้าใกล้อนันต์

ลิมิตเมื่อ x เข้าใกล้อนันต์

ลิมิตเมื่อ x เข้าใกล้อนันต์ คือการหาค่าที่ฟังก์ชันเข้าใกล้เมื่อ $x$ มีค่ามากขึ้นเรื่อยๆ หรือน้อยลงเรื่อยๆ

$$\lim_{x \to +\infty} f(x) = L \quad \text{หมายความว่า } f(x) \to L \text{ เมื่อ } x \to +\infty$$

$$\lim_{x \to -\infty} f(x) = L \quad \text{หมายความว่า } f(x) \to L \text{ เมื่อ } x \to -\infty$$

เส้นกำกับราบ (Horizontal Asymptote): ถ้า $\displaystyle\lim_{x \to \pm\infty} f(x) = L$ แล้วกราฟของ $f(x)$ จะมีเส้นกำกับราบที่ $y = L$

กฎสำหรับหาลิมิตเมื่อ x → ±∞

$$\lim_{x \to \infty} \frac{c}{x^n} = 0 \quad (n > 0)$$

$$\lim_{x \to \infty} \frac{a_nx^n + a_{n-1}x^{n-1} + \cdots + a_0}{b_mx^m + b_{m-1}x^{m-1} + \cdots + b_0} = \begin{cases} \frac{a_n}{b_m} & \text{ถ้า } n = m \\ 0 & \text{ถ้า } n < m \\ \pm\infty & \text{ถ้า } n > m \end{cases}$$

ตัวอย่างที่ 1: ลิมิตเมื่อ x → ∞ ของฟังก์ชันตรรกยะ (เลขชี้กำลังเท่ากัน)

โจทย์: หา $\displaystyle\lim_{x \to \infty} \frac{3x^2 + 2x - 1}{2x^2 - x + 5}$

วิธีทำ:

หารทั้งเศษและส่วนด้วย $x^2$ (พจน์ที่มีเลขชี้กำลังสูงสุด)

$$\lim_{x \to \infty} \frac{3x^2 + 2x - 1}{2x^2 - x + 5} = \lim_{x \to \infty} \frac{3 + \frac{2}{x} - \frac{1}{x^2}}{2 - \frac{1}{x} + \frac{5}{x^2}}$$

เมื่อ $x \to \infty$ จะได้ $\frac{1}{x} \to 0$ และ $\frac{1}{x^2} \to 0$

$$= \frac{3 + 0 - 0}{2 - 0 + 0} = \frac{3}{2}$$

ตอบ: $\frac{3}{2}$ (เส้นกำกับราบคือ $y = \frac{3}{2}$)

ตัวอย่างที่ 2: ลิมิตเมื่อเลขชี้กำลังเศษน้อยกว่าส่วน

โจทย์: หา $\displaystyle\lim_{x \to \infty} \frac{5x + 3}{x^2 - 2x + 1}$

วิธีทำ:

หารทั้งเศษและส่วนด้วย $x^2$

$$\lim_{x \to \infty} \frac{5x + 3}{x^2 - 2x + 1} = \lim_{x \to \infty} \frac{\frac{5}{x} + \frac{3}{x^2}}{1 - \frac{2}{x} + \frac{1}{x^2}}$$

$$= \frac{0 + 0}{1 - 0 + 0} = 0$$

ตอบ: $0$ (เส้นกำกับราบคือ $y = 0$ หรือแกน $x$)

ตัวอย่างที่ 3: ลิมิตเมื่อเลขชี้กำลังเศษมากกว่าส่วน

โจทย์: หา $\displaystyle\lim_{x \to \infty} \frac{2x^3 - x}{x^2 + 1}$

วิธีทำ:

หารทั้งเศษและส่วนด้วย $x^3$

$$\lim_{x \to \infty} \frac{2x^3 - x}{x^2 + 1} = \lim_{x \to \infty} \frac{2 - \frac{1}{x^2}}{\frac{1}{x} + \frac{1}{x^3}}$$

$$= \frac{2 - 0}{0 + 0} = \frac{2}{0} = +\infty$$

ตอบ: $+\infty$ (ไม่มีเส้นกำกับราบ)

ตัวอย่างที่ 4: ลิมิตเมื่อ x → -∞

โจทย์: หา $\displaystyle\lim_{x \to -\infty} \frac{4x^2 + x - 3}{2x^2 + 5}$

วิธีทำ:

หารทั้งเศษและส่วนด้วย $x^2$

$$\lim_{x \to -\infty} \frac{4x^2 + x - 3}{2x^2 + 5} = \lim_{x \to -\infty} \frac{4 + \frac{1}{x} - \frac{3}{x^2}}{2 + \frac{5}{x^2}}$$

$$= \frac{4 + 0 - 0}{2 + 0} = \frac{4}{2} = 2$$

ตอบ: $2$

5.5 ความต่อเนื่อง

ความต่อเนื่องของฟังก์ชัน (Continuity)

ฟังก์ชัน $f(x)$ ต่อเนื่องที่ $x = a$ ก็ต่อเมื่อเงื่อนไขทั้ง 3 ข้อต่อไปนี้เป็นจริง:

  1. $f(a)$ มีค่านิยาม (มีค่าอยู่จริง)
  2. $\displaystyle\lim_{x \to a} f(x)$ มีค่า
  3. $\displaystyle\lim_{x \to a} f(x) = f(a)$

ฟังก์ชันต่อเนื่องบนช่วง: ฟังก์ชัน $f(x)$ เรียกว่า ต่อเนื่องบนช่วง $(a, b)$ ถ้า $f(x)$ ต่อเนื่องที่ทุกจุดในช่วงนั้น

จุดไม่ต่อเนื่อง (Discontinuity):

  • จุดไม่ต่อเนื่องแบบถอดออกได้ (Removable): เมื่อลิมิตมีค่าแต่ไม่เท่ากับค่าของฟังก์ชัน
  • จุดไม่ต่อเนื่องแบบกระโดด (Jump): เมื่อลิมิตทางซ้ายและทางขวาไม่เท่ากัน
  • จุดไม่ต่อเนื่องแบบอนันต์ (Infinite): เมื่อลิมิตเป็นอนันต์

สมบัติของฟังก์ชันต่อเนื่อง

ถ้า $f$ และ $g$ ต่อเนื่องที่ $x = a$ แล้ว

1. $f \pm g$ ต่อเนื่องที่ $x = a$

2. $c \cdot f$ ต่อเนื่องที่ $x = a$ (เมื่อ $c$ เป็นค่าคงที่)

3. $f \cdot g$ ต่อเนื่องที่ $x = a$

4. $\frac{f}{g}$ ต่อเนื่องที่ $x = a$ (เมื่อ $g(a) \neq 0$)

ตัวอย่างที่ 1: ตรวจสอบความต่อเนื่อง

โจทย์: ฟังก์ชัน $f(x) = x^2 - 3x + 2$ ต่อเนื่องที่ $x = 1$ หรือไม่

วิธีทำ:

ตรวจสอบเงื่อนไขทั้ง 3 ข้อ:

1. ตรวจสอบว่า $f(1)$ มีค่า:

$$f(1) = 1^2 - 3(1) + 2 = 1 - 3 + 2 = 0$$ ✓

2. ตรวจสอบว่าลิมิตมีค่า:

$$\lim_{x \to 1} f(x) = \lim_{x \to 1} (x^2 - 3x + 2) = 1^2 - 3(1) + 2 = 0$$ ✓

3. ตรวจสอบว่า $\displaystyle\lim_{x \to 1} f(x) = f(1)$:

$$\lim_{x \to 1} f(x) = 0 = f(1)$$ ✓

ตอบ: ฟังก์ชัน $f(x)$ ต่อเนื่องที่ $x = 1$

ตัวอย่างที่ 2: จุดไม่ต่อเนื่องแบบถอดออกได้

โจทย์: พิจารณาความต่อเนื่องของฟังก์ชัน $f(x) = \frac{x^2 - 4}{x - 2}$ ที่ $x = 2$

วิธีทำ:

1. ตรวจสอบค่า $f(2)$:

$$f(2) = \frac{2^2 - 4}{2 - 2} = \frac{0}{0}$$ ไม่นิยาม ✗

2. หาลิมิต:

$$\lim_{x \to 2} \frac{x^2 - 4}{x - 2} = \lim_{x \to 2} \frac{(x-2)(x+2)}{x - 2} = \lim_{x \to 2} (x + 2) = 4$$

สรุป: $f(2)$ ไม่นิยาม แต่ลิมิตมีค่าเป็น 4

ตอบ: ฟังก์ชันไม่ต่อเนื่องที่ $x = 2$ (จุดไม่ต่อเนื่องแบบถอดออกได้)

สามารถทำให้ต่อเนื่องได้โดยกำหนดให้ $f(2) = 4$

ตัวอย่างที่ 3: หาค่าคงที่ให้ฟังก์ชันต่อเนื่อง

โจทย์: หาค่า $k$ ที่ทำให้ฟังก์ชัน $$f(x) = \begin{cases} x^2 + 2x & \text{เมื่อ } x \leq 1 \\ kx + 3 & \text{เมื่อ } x > 1 \end{cases}$$ ต่อเนื่องที่ $x = 1$

วิธีทำ:

เพื่อให้ฟังก์ชันต่อเนื่องที่ $x = 1$ ต้องได้ว่า

$$\lim_{x \to 1^-} f(x) = \lim_{x \to 1^+} f(x) = f(1)$$

หาลิมิตทางซ้าย:

$$\lim_{x \to 1^-} f(x) = \lim_{x \to 1^-} (x^2 + 2x) = 1^2 + 2(1) = 3$$

หาลิมิตทางขวา:

$$\lim_{x \to 1^+} f(x) = \lim_{x \to 1^+} (kx + 3) = k(1) + 3 = k + 3$$

หาค่า $k$:

$$k + 3 = 3$$

$$k = 0$$

ตอบ: $k = 0$

ตัวอย่างที่ 4: ฟังก์ชันที่ต่อเนื่องทุกจุด

โจทย์: พิสูจน์ว่าฟังก์ชัน $f(x) = 3x + 5$ ต่อเนื่องทุกจุด

วิธีทำ:

เลือกจุด $x = a$ ใดๆ แล้วตรวจสอบ

1. ค่าของฟังก์ชัน:

$$f(a) = 3a + 5$$ (มีค่านิยามเสมอ)

2. ลิมิต:

$$\lim_{x \to a} f(x) = \lim_{x \to a} (3x + 5) = 3a + 5$$

3. ตรวจสอบ:

$$\lim_{x \to a} f(x) = 3a + 5 = f(a)$$ ✓

ตอบ: ฟังก์ชัน $f(x) = 3x + 5$ ต่อเนื่องทุกจุด (เพราะเป็นฟังก์ชันเชิงเส้น)

5.6 ทฤษฎีบทค่ากลาง

ทฤษฎีบทค่ากลาง (Intermediate Value Theorem - IVT)

ทฤษฎีบทค่ากลาง กล่าวว่า:

ถ้าฟังก์ชัน $f$ ต่อเนื่องบนช่วง $[a, b]$ และ $N$ เป็นจำนวนใดๆ ระหว่าง $f(a)$ และ $f(b)$ โดยที่ $f(a) \neq f(b)$ แล้วจะต้องมีจำนวน $c$ อย่างน้อยหนึ่งจำนวนในช่วง $(a, b)$ ที่ทำให้ $f(c) = N$

การประยุกต์ใช้:

  • พิสูจน์ว่าสมการมีคำตอบในช่วงที่กำหนด
  • หาค่าประมาณของรากของสมการ
  • พิสูจน์การมีอยู่ของจำนวนบางค่า

ทฤษฎีบทค่ากลาง

ถ้า $f$ ต่อเนื่องบน $[a, b]$ และ $f(a) < N < f(b)$ (หรือ $f(a) > N > f(b)$)

แล้วมี $c \in (a, b)$ ที่ทำให้ $f(c) = N$

กรณีพิเศษ (หารากสมการ):

ถ้า $f(a) \cdot f(b) < 0$ (มีเครื่องหมายตรงข้าม)

แล้วมี $c \in (a, b)$ ที่ทำให้ $f(c) = 0$

ตัวอย่างที่ 1: พิสูจน์การมีรากของสมการ

โจทย์: พิสูจน์ว่าสมการ $x^3 - x - 1 = 0$ มีรากอย่างน้อยหนึ่งรากในช่วง $(1, 2)$

วิธีทำ:

พิจารณาฟังก์ชัน $f(x) = x^3 - x - 1$

1. ตรวจสอบความต่อเนื่อง:

$f(x)$ เป็นฟังก์ชันพหุนาม จึงต่อเนื่องทุกจุด รวมทั้งบนช่วง $[1, 2]$ ✓

2. หาค่าของฟังก์ชัน:

$$f(1) = 1^3 - 1 - 1 = -1 < 0$$

$$f(2) = 2^3 - 2 - 1 = 8 - 2 - 1 = 5 > 0$$

3. ใช้ทฤษฎีบทค่ากลาง:

เนื่องจาก $f(1) < 0 < f(2)$ และ $f$ ต่อเนื่องบน $[1, 2]$

จากทฤษฎีบทค่ากลาง มี $c \in (1, 2)$ ที่ทำให้ $f(c) = 0$

ตอบ: สมการมีรากอย่างน้อยหนึ่งรากในช่วง $(1, 2)$

ตัวอย่างที่ 2: แสดงการมีอยู่ของค่า

โจทย์: ถ้า $f$ ต่อเนื่องบน $[0, 3]$ และ $f(0) = 2$, $f(3) = 8$ แสดงว่ามี $c \in (0, 3)$ ที่ทำให้ $f(c) = 5$

วิธีทำ:

1. ตรวจสอบเงื่อนไข:

- $f$ ต่อเนื่องบน $[0, 3]$ ✓

- $f(0) = 2 < 5 < 8 = f(3)$ ✓

2. ใช้ทฤษฎีบทค่ากลาง:

เนื่องจาก $5$ อยู่ระหว่าง $f(0) = 2$ และ $f(3) = 8$

และ $f$ ต่อเนื่องบน $[0, 3]$

จากทฤษฎีบทค่ากลาง ต้องมี $c \in (0, 3)$ ที่ทำให้ $f(c) = 5$

ตอบ: พิสูจน์ได้

ตัวอย่างที่ 3: หาช่วงที่มีรากของสมการ

โจทย์: สมการ $\cos x = x$ มีรากในช่วงไหน โดยพิจารณาช่วง $[0, \frac{\pi}{2}]$

วิธีทำ:

พิจารณาฟังก์ชัน $f(x) = \cos x - x$

1. ตรวจสอบความต่อเนื่อง:

$f(x) = \cos x - x$ ต่อเนื่องทุกจุด ✓

2. หาค่าของฟังก์ชัน:

$$f(0) = \cos 0 - 0 = 1 - 0 = 1 > 0$$

$$f\left(\frac{\pi}{2}\right) = \cos\frac{\pi}{2} - \frac{\pi}{2} = 0 - \frac{\pi}{2} \approx -1.57 < 0$$

3. ใช้ทฤษฎีบทค่ากลาง:

เนื่องจาก $f(0) > 0 > f(\frac{\pi}{2})$ และ $f$ ต่อเนื่องบน $[0, \frac{\pi}{2}]$

มี $c \in (0, \frac{\pi}{2})$ ที่ทำให้ $f(c) = 0$ หรือ $\cos c = c$

ตอบ: สมการ $\cos x = x$ มีรากในช่วง $(0, \frac{\pi}{2})$

ตัวอย่างที่ 4: การประยุกต์ใช้ในปัญหาจริง

โจทย์: อุณหภูมิในช่วงเช้าเวลา 6:00 น. เป็น 15°C และเวลา 12:00 น. เป็น 25°C สมมติว่าอุณหภูมิเปลี่ยนแปลงอย่างต่อเนื่อง แสดงว่ามีเวลาใดเวลาหนึ่งระหว่าง 6:00-12:00 น. ที่อุณหภูมิเป็น 20°C

วิธีทำ:

ให้ $T(t)$ แทนอุณหภูมิ ณ เวลา $t$ ชั่วโมงหลังเที่ยงคืน

1. กำหนดค่า:

$T(6) = 15$ °C (เวลา 6:00 น.)

$T(12) = 25$ °C (เวลา 12:00 น.)

2. เงื่อนไข:

- อุณหภูมิเปลี่ยนแปลงอย่างต่อเนื่อง หมายความว่า $T$ ต่อเนื่องบน $[6, 12]$ ✓

- $15 < 20 < 25$ ดังนั้น $T(6) < 20 < T(12)$ ✓

3. ใช้ทฤษฎีบทค่ากลาง:

จากทฤษฎีบทค่ากลาง มี $c \in (6, 12)$ ที่ทำให้ $T(c) = 20$

ตอบ: มีเวลาอย่างน้อยหนึ่งเวลาระหว่าง 6:00-12:00 น. ที่อุณหภูมิเป็น 20°C

แบบฝึกหัดบทที่ 5: ลิมิตและความต่อเนื่อง

ส่วนที่ 1: ลิมิตของฟังก์ชัน (4 ข้อ)

  1. หา $\displaystyle\lim_{x \to 2} (3x^2 - 5x + 1)$
  2. หา $\displaystyle\lim_{x \to -1} (x^3 + 2x^2 - x + 3)$
  3. หา $\displaystyle\lim_{x \to 3} \frac{x^2 - 9}{x - 3}$
  4. หา $\displaystyle\lim_{x \to 4} \frac{x^2 - 5x + 4}{x - 4}$

เฉลย ส่วนที่ 1:

1. หา $\displaystyle\lim_{x \to 2} (3x^2 - 5x + 1)$

วิธีทำ: แทนค่าโดยตรง

$$\lim_{x \to 2} (3x^2 - 5x + 1) = 3(2)^2 - 5(2) + 1$$

$$= 3(4) - 10 + 1 = 12 - 10 + 1 = 3$$

ตอบ: $3$

2. หา $\displaystyle\lim_{x \to -1} (x^3 + 2x^2 - x + 3)$

วิธีทำ: แทนค่าโดยตรง

$$\lim_{x \to -1} (x^3 + 2x^2 - x + 3) = (-1)^3 + 2(-1)^2 - (-1) + 3$$

$$= -1 + 2 + 1 + 3 = 5$$

ตอบ: $5$

3. หา $\displaystyle\lim_{x \to 3} \frac{x^2 - 9}{x - 3}$

วิธีทำ: แยกตัวประกอบ

$$\lim_{x \to 3} \frac{x^2 - 9}{x - 3} = \lim_{x \to 3} \frac{(x-3)(x+3)}{x - 3}$$

$$= \lim_{x \to 3} (x + 3) = 3 + 3 = 6$$

ตอบ: $6$

4. หา $\displaystyle\lim_{x \to 4} \frac{x^2 - 5x + 4}{x - 4}$

วิธีทำ: แยกตัวประกอบ

$$\lim_{x \to 4} \frac{x^2 - 5x + 4}{x - 4} = \lim_{x \to 4} \frac{(x-1)(x-4)}{x - 4}$$

$$= \lim_{x \to 4} (x - 1) = 4 - 1 = 3$$

ตอบ: $3$

ส่วนที่ 2: กฎการหาลิมิต (3 ข้อ)

  1. หา $\displaystyle\lim_{x \to 1} \frac{2x^2 + 3x - 5}{x^2 + 1}$
  2. หา $\displaystyle\lim_{x \to 0} \frac{\sqrt{x + 9} - 3}{x}$
  3. หา $\displaystyle\lim_{x \to 2} \sqrt{x^2 + 5}$

เฉลย ส่วนที่ 2:

5. หา $\displaystyle\lim_{x \to 1} \frac{2x^2 + 3x - 5}{x^2 + 1}$

วิธีทำ: ใช้กฎการหาร

$$\lim_{x \to 1} \frac{2x^2 + 3x - 5}{x^2 + 1} = \frac{\lim_{x \to 1}(2x^2 + 3x - 5)}{\lim_{x \to 1}(x^2 + 1)}$$

$$= \frac{2(1)^2 + 3(1) - 5}{1^2 + 1} = \frac{2 + 3 - 5}{1 + 1} = \frac{0}{2} = 0$$

ตอบ: $0$

6. หา $\displaystyle\lim_{x \to 0} \frac{\sqrt{x + 9} - 3}{x}$

วิธีทำ: ทำตรรกยะเศษและส่วน

$$\lim_{x \to 0} \frac{\sqrt{x + 9} - 3}{x} \cdot \frac{\sqrt{x + 9} + 3}{\sqrt{x + 9} + 3}$$

$$= \lim_{x \to 0} \frac{(x + 9) - 9}{x(\sqrt{x + 9} + 3)} = \lim_{x \to 0} \frac{x}{x(\sqrt{x + 9} + 3)}$$

$$= \lim_{x \to 0} \frac{1}{\sqrt{x + 9} + 3} = \frac{1}{\sqrt{9} + 3} = \frac{1}{3 + 3} = \frac{1}{6}$$

ตอบ: $\frac{1}{6}$

7. หา $\displaystyle\lim_{x \to 2} \sqrt{x^2 + 5}$

วิธีทำ: ใช้กฎรากที่สอง

$$\lim_{x \to 2} \sqrt{x^2 + 5} = \sqrt{\lim_{x \to 2}(x^2 + 5)}$$

$$= \sqrt{2^2 + 5} = \sqrt{4 + 5} = \sqrt{9} = 3$$

ตอบ: $3$

ส่วนที่ 3: ลิมิตที่อนันต์ (3 ข้อ)

  1. หา $\displaystyle\lim_{x \to 0} \frac{1}{x^4}$
  2. หา $\displaystyle\lim_{x \to 3^+} \frac{2}{x - 3}$ และ $\displaystyle\lim_{x \to 3^-} \frac{2}{x - 3}$
  3. หาเส้นกำกับดิ่งของฟังก์ชัน $f(x) = \frac{2x}{x^2 - 16}$

เฉลย ส่วนที่ 3:

8. หา $\displaystyle\lim_{x \to 0} \frac{1}{x^4}$

วิธีทำ: เมื่อ $x \to 0$, $x^4 \to 0$ และ $x^4 > 0$ เสมอ

$$\lim_{x \to 0} \frac{1}{x^4} = +\infty$$

ตอบ: $+\infty$

9. หา $\displaystyle\lim_{x \to 3^+} \frac{2}{x - 3}$ และ $\displaystyle\lim_{x \to 3^-} \frac{2}{x - 3}$

วิธีทำ:

ทางขวา: เมื่อ $x \to 3^+$, $x > 3$ ทำให้ $x - 3 > 0$

$$\lim_{x \to 3^+} \frac{2}{x - 3} = +\infty$$

ทางซ้าย: เมื่อ $x \to 3^-$, $x < 3$ ทำให้ $x - 3 < 0$

$$\lim_{x \to 3^-} \frac{2}{x - 3} = -\infty$$

ตอบ: $+\infty$ และ $-\infty$

10. หาเส้นกำกับดิ่งของฟังก์ชัน $f(x) = \frac{2x}{x^2 - 16}$

วิธีทำ: หาค่า $x$ ที่ทำให้ตัวส่วนเป็นศูนย์

$$x^2 - 16 = 0$$

$$(x-4)(x+4) = 0$$

$$x = 4 \text{ หรือ } x = -4$$

ตอบ: เส้นกำกับดิ่งคือ $x = 4$ และ $x = -4$

ส่วนที่ 4: ลิมิตเมื่อ x → ±∞ (4 ข้อ)

  1. หา $\displaystyle\lim_{x \to \infty} \frac{5x^2 - 3x + 1}{2x^2 + x - 4}$
  2. หา $\displaystyle\lim_{x \to \infty} \frac{3x + 7}{x^2 - 2}$
  3. หา $\displaystyle\lim_{x \to \infty} \frac{4x^3 + 2x}{x^2 - 1}$
  4. หา $\displaystyle\lim_{x \to -\infty} \frac{6x^2 + 5x}{3x^2 - 2x + 1}$

เฉลย ส่วนที่ 4:

11. หา $\displaystyle\lim_{x \to \infty} \frac{5x^2 - 3x + 1}{2x^2 + x - 4}$

วิธีทำ: หารทั้งเศษและส่วนด้วย $x^2$

$$\lim_{x \to \infty} \frac{5 - \frac{3}{x} + \frac{1}{x^2}}{2 + \frac{1}{x} - \frac{4}{x^2}} = \frac{5 - 0 + 0}{2 + 0 - 0} = \frac{5}{2}$$

ตอบ: $\frac{5}{2}$

12. หา $\displaystyle\lim_{x \to \infty} \frac{3x + 7}{x^2 - 2}$

วิธีทำ: หารทั้งเศษและส่วนด้วย $x^2$

$$\lim_{x \to \infty} \frac{\frac{3}{x} + \frac{7}{x^2}}{1 - \frac{2}{x^2}} = \frac{0 + 0}{1 - 0} = 0$$

ตอบ: $0$

13. หา $\displaystyle\lim_{x \to \infty} \frac{4x^3 + 2x}{x^2 - 1}$

วิธีทำ: หารทั้งเศษและส่วนด้วย $x^3$

$$\lim_{x \to \infty} \frac{4 + \frac{2}{x^2}}{\frac{1}{x} - \frac{1}{x^3}} = \frac{4 + 0}{0 - 0} = \frac{4}{0} = +\infty$$

ตอบ: $+\infty$

14. หา $\displaystyle\lim_{x \to -\infty} \frac{6x^2 + 5x}{3x^2 - 2x + 1}$

วิธีทำ: หารทั้งเศษและส่วนด้วย $x^2$

$$\lim_{x \to -\infty} \frac{6 + \frac{5}{x}}{3 - \frac{2}{x} + \frac{1}{x^2}} = \frac{6 + 0}{3 - 0 + 0} = \frac{6}{3} = 2$$

ตอบ: $2$

ส่วนที่ 5: ความต่อเนื่อง (3 ข้อ)

  1. ตรวจสอบว่าฟังก์ชัน $f(x) = x^2 - 4x + 3$ ต่อเนื่องที่ $x = 2$ หรือไม่
  2. พิจารณาความต่อเนื่องของฟังก์ชัน $f(x) = \frac{x^2 - 1}{x - 1}$ ที่ $x = 1$
  3. หาค่า $a$ ที่ทำให้ฟังก์ชัน $$f(x) = \begin{cases} x^2 - 1 & \text{เมื่อ } x < 2 \\ ax + 5 & \text{เมื่อ } x \geq 2 \end{cases}$$ ต่อเนื่องที่ $x = 2$

เฉลย ส่วนที่ 5:

15. ตรวจสอบว่าฟังก์ชัน $f(x) = x^2 - 4x + 3$ ต่อเนื่องที่ $x = 2$ หรือไม่

วิธีทำ:

1. $f(2) = 2^2 - 4(2) + 3 = 4 - 8 + 3 = -1$ (มีค่า ✓)

2. $\displaystyle\lim_{x \to 2} f(x) = 2^2 - 4(2) + 3 = -1$ (มีค่า ✓)

3. $\displaystyle\lim_{x \to 2} f(x) = -1 = f(2)$ ✓

ตอบ: ฟังก์ชันต่อเนื่องที่ $x = 2$

16. พิจารณาความต่อเนื่องของฟังก์ชัน $f(x) = \frac{x^2 - 1}{x - 1}$ ที่ $x = 1$

วิธีทำ:

1. $f(1) = \frac{1^2 - 1}{1 - 1} = \frac{0}{0}$ ไม่นิยาม ✗

2. $\displaystyle\lim_{x \to 1} \frac{x^2 - 1}{x - 1} = \lim_{x \to 1} \frac{(x-1)(x+1)}{x - 1} = \lim_{x \to 1} (x + 1) = 2$

ตอบ: ฟังก์ชันไม่ต่อเนื่องที่ $x = 1$ (จุดไม่ต่อเนื่องแบบถอดออกได้)

17. หาค่า $a$ ที่ทำให้ฟังก์ชันต่อเนื่องที่ $x = 2$

วิธีทำ:

ลิมิตทางซ้าย: $\displaystyle\lim_{x \to 2^-} f(x) = \lim_{x \to 2^-} (x^2 - 1) = 2^2 - 1 = 3$

ลิมิตทางขวา: $\displaystyle\lim_{x \to 2^+} f(x) = \lim_{x \to 2^+} (ax + 5) = 2a + 5$

ค่าฟังก์ชัน: $f(2) = a(2) + 5 = 2a + 5$

เพื่อให้ต่อเนื่อง: $2a + 5 = 3$

$$2a = -2$$

$$a = -1$$

ตอบ: $a = -1$

  1. พิสูจน์ว่าสมการ $x^3 + x - 5 = 0$ มีรากอย่างน้อยหนึ่งรากในช่วง $(1, 2)$
  2. ถ้า $f$ ต่อเนื่องบน $[1, 4]$ และ $f(1) = -2$, $f(4) = 7$ แสดงว่ามี $c \in (1, 4)$ ที่ทำให้ $f(c) = 0$
  3. พิสูจน์ว่าสมการ $x^2 = 2^x$ มีรากในช่วง $(1, 2)$

เฉลย ส่วนที่ 6:

18. พิสูจน์ว่าสมการ $x^3 + x - 5 = 0$ มีรากอย่างน้อยหนึ่งรากในช่วง $(1, 2)$

วิธีทำ:

พิจารณา $f(x) = x^3 + x - 5$ (เป็นฟังก์ชันพหุนาม จึงต่อเนื่องทุกจุด)

$f(1) = 1^3 + 1 - 5 = -3 < 0$

$f(2) = 2^3 + 2 - 5 = 8 + 2 - 5 = 5 > 0$

เนื่องจาก $f(1) < 0 < f(2)$ และ $f$ ต่อเนื่องบน $[1, 2]$

จากทฤษฎีบทค่ากลาง มี $c \in (1, 2)$ ที่ทำให้ $f(c) = 0$

ตอบ: สมการมีรากในช่วง $(1, 2)$

19. ถ้า $f$ ต่อเนื่องบน $[1, 4]$ และ $f(1) = -2$, $f(4) = 7$ แสดงว่ามี $c \in (1, 4)$ ที่ทำให้ $f(c) = 0$

วิธีทำ:

เงื่อนไข: $f$ ต่อเนื่องบน $[1, 4]$ ✓

$f(1) = -2 < 0 < 7 = f(4)$ ✓

เนื่องจาก $0$ อยู่ระหว่าง $f(1)$ และ $f(4)$

จากทฤษฎีบทค่ากลาง มี $c \in (1, 4)$ ที่ทำให้ $f(c) = 0$

ตอบ: พิสูจน์ได้

20. พิสูจน์ว่าสมการ $x^2 = 2^x$ มีรากในช่วง $(1, 2)$

วิธีทำ:

พิจารณา $f(x) = x^2 - 2^x$ (ต่อเนื่องทุกจุด)

$f(1) = 1^2 - 2^1 = 1 - 2 = -1 < 0$

$f(2) = 2^2 - 2^2 = 4 - 4 = 0$

เนื่องจาก $f(1) < 0 \leq f(2)$ แต่ $f(2) = 0$ แสดงว่า $x = 2$ เป็นรากของสมการ

หรืออาจพิจารณาช่วง $(1.5, 2)$:

$f(1.5) = 1.5^2 - 2^{1.5} = 2.25 - 2.83 \approx -0.58 < 0$

$f(2) = 0 > f(1.5)$

ตอบ: สมการมีรากคือ $x = 2$ (หรือมีรากในช่วง $(1, 2]$)
