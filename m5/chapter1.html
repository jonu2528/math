บทที่ 1: ตรีโกณมิติ

ตรีโกณมิติ (Trigonometry) เป็นสาขาหนึ่งของคณิตศาสตร์ที่ศึกษาความสัมพันธ์ระหว่างมุมและด้านของรูปสามเหลี่ยม โดยมีการประยุกต์ใช้ในชีวิตจริงหลากหลายด้าน เช่น วิศวกรรม ฟิสิกส์ ดาราศาสตร์ การสำรวจ และการนำทาง ในบทนี้เราจะศึกษาฟังก์ชันตรีโกณมิติ เอกลักษณ์ตรีโกณมิติ สมการตรีโกณมิติ กฎของไซน์และโคไซน์ รวมถึงการแก้สามเหลี่ยมในรูปแบบต่างๆ

1.1 ฟังก์ชันตรีโกณมิติ

ความหมายของฟังก์ชันตรีโกณมิติ

ฟังก์ชันตรีโกณมิติ (Trigonometric Functions) เป็นฟังก์ชันที่แสดงความสัมพันธ์ระหว่างมุมกับอัตราส่วนของด้านในรูปสามเหลี่ยมมุมฉาก มี 6 ฟังก์ชันหลัก ได้แก่:

1. ไซน์ (Sine): $\sin \theta = \frac{\text{ด้านตรงข้าม}}{\text{ด้านตรง}}$

2. โคไซน์ (Cosine): $\cos \theta = \frac{\text{ด้านประชิด}}{\text{ด้านตรง}}$

3. แทนเจนต์ (Tangent): $\tan \theta = \frac{\text{ด้านตรงข้าม}}{\text{ด้านประชิด}} = \frac{\sin \theta}{\cos \theta}$

4. โคซีแคนต์ (Cosecant): $\csc \theta = \frac{1}{\sin \theta}$

5. ซีแคนต์ (Secant): $\sec \theta = \frac{1}{\cos \theta}$

6. โคแทนเจนต์ (Cotangent): $\cot \theta = \frac{1}{\tan \theta} = \frac{\cos \theta}{\sin \theta}$

สูตรสำคัญ - ฟังก์ชันตรีโกณมิติในวงกลมหนึ่งหน่วย

กำหนดมุม $\theta$ ในตำแหน่งมาตรฐาน และจุด $P(x, y)$ บนวงกลมหนึ่งหน่วย

$$\sin \theta = y$$

$$\cos \theta = x$$

$$\tan \theta = \frac{y}{x}, \quad x \neq 0$$

$$\csc \theta = \frac{1}{y}, \quad y \neq 0$$

$$\sec \theta = \frac{1}{x}, \quad x \neq 0$$

$$\cot \theta = \frac{x}{y}, \quad y \neq 0$$

ค่าของฟังก์ชันตรีโกณมิติในมุมพิเศษ

มุม ($\theta$) $0°$ $30°$ $45°$ $60°$ $90°$
$\sin \theta$ $0$ $\frac{1}{2}$ $\frac{\sqrt{2}}{2}$ $\frac{\sqrt{3}}{2}$ $1$
$\cos \theta$ $1$ $\frac{\sqrt{3}}{2}$ $\frac{\sqrt{2}}{2}$ $\frac{1}{2}$ $0$
$\tan \theta$ $0$ $\frac{\sqrt{3}}{3}$ $1$ $\sqrt{3}$ ไม่กำหนด

ตัวอย่างที่ 1: หาค่าฟังก์ชันตรีโกณมิติจากสามเหลี่ยมมุมฉาก

โจทย์: ในรูปสามเหลี่ยมมุมฉาก ABC โดยมีมุมฉากที่ C ถ้า $AB = 13$ ซม. และ $BC = 5$ ซม. จงหาค่า $\sin A$, $\cos A$ และ $\tan A$

วิธีทำ:

ขั้นที่ 1: หาความยาวด้าน $AC$ โดยใช้ทฤษฎีพีทาโกรัส

$$AC^2 + BC^2 = AB^2$$

$$AC^2 + 5^2 = 13^2$$

$$AC^2 = 169 - 25 = 144$$

$$AC = 12 \text{ ซม.}$$

ขั้นที่ 2: หาค่าฟังก์ชันตรีโกณมิติ

สำหรับมุม A: ด้านตรงข้าม = $BC = 5$, ด้านประชิด = $AC = 12$, ด้านตรง = $AB = 13$

$$\sin A = \frac{\text{ด้านตรงข้าม}}{\text{ด้านตรง}} = \frac{5}{13}$$

$$\cos A = \frac{\text{ด้านประชิด}}{\text{ด้านตรง}} = \frac{12}{13}$$

$$\tan A = \frac{\text{ด้านตรงข้าม}}{\text{ด้านประชิด}} = \frac{5}{12}$$

ตอบ: $\sin A = \frac{5}{13}$, $\cos A = \frac{12}{13}$, $\tan A = \frac{5}{12}$

ตัวอย่างที่ 2: หาค่าฟังก์ชันตรีโกณมิติจากค่าที่กำหนด

โจทย์: ถ้า $\sin \theta = \frac{3}{5}$ และ $0° < \theta < 90°$ จงหาค่า $\cos \theta$ และ $\tan \theta$

วิธีทำ:

ขั้นที่ 1: ใช้เอกลักษณ์พีทาโกรัส $\sin^2 \theta + \cos^2 \theta = 1$

$$\left(\frac{3}{5}\right)^2 + \cos^2 \theta = 1$$

$$\frac{9}{25} + \cos^2 \theta = 1$$

$$\cos^2 \theta = 1 - \frac{9}{25} = \frac{16}{25}$$

$$\cos \theta = \frac{4}{5}$$ (เป็นบวกเพราะ $0° < \theta < 90°$)

ขั้นที่ 2: หาค่า $\tan \theta$

$$\tan \theta = \frac{\sin \theta}{\cos \theta} = \frac{3/5}{4/5} = \frac{3}{4}$$

ตอบ: $\cos \theta = \frac{4}{5}$ และ $\tan \theta = \frac{3}{4}$

ตัวอย่างที่ 3: คำนวณค่าฟังก์ชันตรีโกณมิติในมุมที่ใหญ่กว่า 90°

โจทย์: จงหาค่า $\sin 150°$, $\cos 210°$ และ $\tan 315°$

วิธีทำ:

หา $\sin 150°$:

$150° = 180° - 30°$ (มุมอ้างอิง = $30°$)

ในควอแดรนต์ที่ 2: sin เป็นบวก

$$\sin 150° = \sin 30° = \frac{1}{2}$$

หา $\cos 210°$:

$210° = 180° + 30°$ (มุมอ้างอิง = $30°$)

ในควอแดรนต์ที่ 3: cos เป็นลบ

$$\cos 210° = -\cos 30° = -\frac{\sqrt{3}}{2}$$

หา $\tan 315°$:

$315° = 360° - 45°$ (มุมอ้างอิง = $45°$)

ในควอแดรนต์ที่ 4: tan เป็นลบ

$$\tan 315° = -\tan 45° = -1$$

ตอบ: $\sin 150° = \frac{1}{2}$, $\cos 210° = -\frac{\sqrt{3}}{2}$, $\tan 315° = -1$

ตัวอย่างที่ 4: หาค่าฟังก์ชันซีแคนต์และโคแทนเจนต์

โจทย์: ถ้า $\cos \theta = -\frac{5}{13}$ และ $\theta$ อยู่ในควอแดรนต์ที่ 2 จงหาค่า $\sec \theta$, $\csc \theta$ และ $\cot \theta$

วิธีทำ:

ขั้นที่ 1: หา $\sec \theta$

$$\sec \theta = \frac{1}{\cos \theta} = \frac{1}{-5/13} = -\frac{13}{5}$$

ขั้นที่ 2: หา $\sin \theta$ โดยใช้เอกลักษณ์พีทาโกรัส

$$\sin^2 \theta + \cos^2 \theta = 1$$

$$\sin^2 \theta + \left(-\frac{5}{13}\right)^2 = 1$$

$$\sin^2 \theta = 1 - \frac{25}{169} = \frac{144}{169}$$

$$\sin \theta = \frac{12}{13}$$ (เป็นบวกในควอแดรนต์ที่ 2)

ขั้นที่ 3: หา $\csc \theta$ และ $\cot \theta$

$$\csc \theta = \frac{1}{\sin \theta} = \frac{1}{12/13} = \frac{13}{12}$$

$$\cot \theta = \frac{\cos \theta}{\sin \theta} = \frac{-5/13}{12/13} = -\frac{5}{12}$$

ตอบ: $\sec \theta = -\frac{13}{5}$, $\csc \theta = \frac{13}{12}$, $\cot \theta = -\frac{5}{12}$

1.2 เอกลักษณ์ตรีโกณมิติ

ความหมาย

เอกลักษณ์ตรีโกณมิติ (Trigonometric Identities) คือสมการที่เป็นจริงสำหรับทุกค่าของตัวแปรที่ทำให้นิพจน์ทั้งสองข้างของสมการมีความหมาย เอกลักษณ์เหล่านี้ใช้ในการลดรูปนิพจน์ตรีโกณมิติและการพิสูจน์

เอกลักษณ์พีทาโกรัส (Pythagorean Identities)

$$\sin^2 \theta + \cos^2 \theta = 1$$

$$1 + \tan^2 \theta = \sec^2 \theta$$

$$1 + \cot^2 \theta = \csc^2 \theta$$

เอกลักษณ์ผลรวมและผลต่างของมุม

$$\sin(A + B) = \sin A \cos B + \cos A \sin B$$

$$\sin(A - B) = \sin A \cos B - \cos A \sin B$$

$$\cos(A + B) = \cos A \cos B - \sin A \sin B$$

$$\cos(A - B) = \cos A \cos B + \sin A \sin B$$

$$\tan(A + B) = \frac{\tan A + \tan B}{1 - \tan A \tan B}$$

$$\tan(A - B) = \frac{\tan A - \tan B}{1 + \tan A \tan B}$$

เอกลักษณ์มุมสองเท่า (Double Angle Identities)

$$\sin 2\theta = 2\sin \theta \cos \theta$$

$$\cos 2\theta = \cos^2 \theta - \sin^2 \theta = 2\cos^2 \theta - 1 = 1 - 2\sin^2 \theta$$

$$\tan 2\theta = \frac{2\tan \theta}{1 - \tan^2 \theta}$$

เอกลักษณ์มุมครึ่งหนึ่ง (Half Angle Identities)

$$\sin^2 \frac{\theta}{2} = \frac{1 - \cos \theta}{2}$$

$$\cos^2 \frac{\theta}{2} = \frac{1 + \cos \theta}{2}$$

$$\tan \frac{\theta}{2} = \frac{1 - \cos \theta}{\sin \theta} = \frac{\sin \theta}{1 + \cos \theta}$$

ตัวอย่างที่ 1: พิสูจน์เอกลักษณ์ตรีโกณมิติ

โจทย์: พิสูจน์ว่า $\frac{1 - \cos 2\theta}{\sin 2\theta} = \tan \theta$

วิธีทำ:

พิจารณาทางซ้าย:

$$\frac{1 - \cos 2\theta}{\sin 2\theta}$$

ใช้เอกลักษณ์มุมสองเท่า: $\cos 2\theta = 1 - 2\sin^2 \theta$ และ $\sin 2\theta = 2\sin \theta \cos \theta$

$$= \frac{1 - (1 - 2\sin^2 \theta)}{2\sin \theta \cos \theta}$$

$$= \frac{2\sin^2 \theta}{2\sin \theta \cos \theta}$$

$$= \frac{\sin \theta}{\cos \theta}$$

$$= \tan \theta$$ (พิสูจน์แล้ว)

ตัวอย่างที่ 2: การใช้เอกลักษณ์ผลรวมของมุม

โจทย์: จงหาค่าที่แน่นอนของ $\sin 75°$ โดยใช้เอกลักษณ์ผลรวมของมุม

วิธีทำ:

เขียน $75° = 45° + 30°$

ใช้เอกลักษณ์: $\sin(A + B) = \sin A \cos B + \cos A \sin B$

$$\sin 75° = \sin(45° + 30°)$$

$$= \sin 45° \cos 30° + \cos 45° \sin 30°$$

$$= \frac{\sqrt{2}}{2} \cdot \frac{\sqrt{3}}{2} + \frac{\sqrt{2}}{2} \cdot \frac{1}{2}$$

$$= \frac{\sqrt{6}}{4} + \frac{\sqrt{2}}{4}$$

$$= \frac{\sqrt{6} + \sqrt{2}}{4}$$

ตอบ: $\sin 75° = \frac{\sqrt{6} + \sqrt{2}}{4}$

ตัวอย่างที่ 3: การใช้เอกลักษณ์มุมสองเท่า

โจทย์: ถ้า $\sin \theta = \frac{3}{5}$ และ $0° < \theta < 90°$ จงหาค่า $\sin 2\theta$ และ $\cos 2\theta$

วิธีทำ:

ขั้นที่ 1: หา $\cos \theta$ โดยใช้เอกลักษณ์พีทาโกรัส

$$\sin^2 \theta + \cos^2 \theta = 1$$

$$\left(\frac{3}{5}\right)^2 + \cos^2 \theta = 1$$

$$\cos^2 \theta = 1 - \frac{9}{25} = \frac{16}{25}$$

$$\cos \theta = \frac{4}{5}$$

ขั้นที่ 2: หา $\sin 2\theta$

$$\sin 2\theta = 2\sin \theta \cos \theta = 2 \cdot \frac{3}{5} \cdot \frac{4}{5} = \frac{24}{25}$$

ขั้นที่ 3: หา $\cos 2\theta$

$$\cos 2\theta = \cos^2 \theta - \sin^2 \theta = \left(\frac{4}{5}\right)^2 - \left(\frac{3}{5}\right)^2 = \frac{16}{25} - \frac{9}{25} = \frac{7}{25}$$

ตอบ: $\sin 2\theta = \frac{24}{25}$ และ $\cos 2\theta = \frac{7}{25}$

ตัวอย่างที่ 4: ลดรูปนิพจน์ตรีโกณมิติ

โจทย์: ลดรูป $\frac{\sin \theta}{1 + \cos \theta} + \frac{1 + \cos \theta}{\sin \theta}$

วิธีทำ:

$$\frac{\sin \theta}{1 + \cos \theta} + \frac{1 + \cos \theta}{\sin \theta}$$

นำมาหาร่วม:

$$= \frac{\sin^2 \theta + (1 + \cos \theta)^2}{\sin \theta(1 + \cos \theta)}$$

$$= \frac{\sin^2 \theta + 1 + 2\cos \theta + \cos^2 \theta}{\sin \theta(1 + \cos \theta)}$$

ใช้ $\sin^2 \theta + \cos^2 \theta = 1$:

$$= \frac{1 + 1 + 2\cos \theta}{\sin \theta(1 + \cos \theta)}$$

$$= \frac{2(1 + \cos \theta)}{\sin \theta(1 + \cos \theta)}$$

$$= \frac{2}{\sin \theta} = 2\csc \theta$$

ตอบ: $2\csc \theta$

1.3 สมการตรีโกณมิติ

ความหมาย

สมการตรีโกณมิติ (Trigonometric Equations) คือสมการที่มีฟังก์ชันตรีโกณมิติของตัวแปรที่ไม่ทราบค่า การแก้สมการคือการหาค่ามุมที่ทำให้สมการเป็นจริง

หลักการแก้สมการตรีโกณมิติ:

  • 1. แยกฟังก์ชันตรีโกณมิติออกมาให้อยู่ข้างเดียวของสมการ
  • 2. ใช้เอกลักษณ์ตรีโกณมิติช่วยลดรูปหรือแปลงสมการ
  • 3. หาค่ามุมพื้นฐาน (principal value)
  • 4. หาคำตอบทั่วไปในช่วงที่กำหนด

รูปแบบพื้นฐานของสมการตรีโกณมิติ

1. สมการไซน์: ถ้า $\sin \theta = k$ เมื่อ $-1 \leq k \leq 1$

คำตอบ: $\theta = \alpha + 360°n$ หรือ $\theta = (180° - \alpha) + 360°n$ เมื่อ $n$ เป็นจำนวนเต็ม

2. สมการโคไซน์: ถ้า $\cos \theta = k$ เมื่อ $-1 \leq k \leq 1$

คำตอบ: $\theta = \pm \alpha + 360°n$ เมื่อ $n$ เป็นจำนวนเต็ม

3. สมการแทนเจนต์: ถ้า $\tan \theta = k$

คำตอบ: $\theta = \alpha + 180°n$ เมื่อ $n$ เป็นจำนวนเต็ม

ตัวอย่างที่ 1: แก้สมการตรีโกณมิติพื้นฐาน

โจทย์: แก้สมการ $2\sin \theta - 1 = 0$ สำหรับ $0° \leq \theta < 360°$

วิธีทำ:

$$2\sin \theta - 1 = 0$$

$$2\sin \theta = 1$$

$$\sin \theta = \frac{1}{2}$$

ค่ามุมพื้นฐาน: $\theta = 30°$

เนื่องจาก $\sin \theta > 0$ ในควอแดรนต์ที่ 1 และ 2

คำตอบในช่วง $0° \leq \theta < 360°$ คือ:

$$\theta = 30° \quad \text{หรือ} \quad \theta = 180° - 30° = 150°$$

ตอบ: $\theta = 30°$ หรือ $150°$

ตัวอย่างที่ 2: แก้สมการที่มีฟังก์ชันกำลังสอง

โจทย์: แก้สมการ $2\cos^2 \theta + \cos \theta - 1 = 0$ สำหรับ $0° \leq \theta < 360°$

วิธีทำ:

ให้ $x = \cos \theta$ จะได้:

$$2x^2 + x - 1 = 0$$

แยกตัวประกอบ:

$$(2x - 1)(x + 1) = 0$$

$$x = \frac{1}{2} \quad \text{หรือ} \quad x = -1$$

กรณีที่ 1: $\cos \theta = \frac{1}{2}$

$$\theta = 60° \quad \text{หรือ} \quad \theta = 360° - 60° = 300°$$

กรณีที่ 2: $\cos \theta = -1$

$$\theta = 180°$$

ตอบ: $\theta = 60°, 180°, 300°$

ตัวอย่างที่ 3: แก้สมการโดยใช้เอกลักษณ์

โจทย์: แก้สมการ $\sin 2\theta = \cos \theta$ สำหรับ $0° \leq \theta < 360°$

วิธีทำ:

ใช้เอกลักษณ์ $\sin 2\theta = 2\sin \theta \cos \theta$

$$2\sin \theta \cos \theta = \cos \theta$$

$$2\sin \theta \cos \theta - \cos \theta = 0$$

$$\cos \theta(2\sin \theta - 1) = 0$$

กรณีที่ 1: $\cos \theta = 0$

$$\theta = 90° \quad \text{หรือ} \quad \theta = 270°$$

กรณีที่ 2: $2\sin \theta - 1 = 0$

$$\sin \theta = \frac{1}{2}$$

$$\theta = 30° \quad \text{หรือ} \quad \theta = 150°$$

ตอบ: $\theta = 30°, 90°, 150°, 270°$

ตัวอย่างที่ 4: แก้สมการที่มีสองฟังก์ชัน

โจทย์: แก้สมการ $\sin \theta + \cos \theta = 1$ สำหรับ $0° \leq \theta < 360°$

วิธีทำ:

$$\sin \theta + \cos \theta = 1$$

$$\sin \theta = 1 - \cos \theta$$

ยกกำลังสองทั้งสองข้าง:

$$\sin^2 \theta = (1 - \cos \theta)^2$$

$$\sin^2 \theta = 1 - 2\cos \theta + \cos^2 \theta$$

ใช้ $\sin^2 \theta = 1 - \cos^2 \theta$:

$$1 - \cos^2 \theta = 1 - 2\cos \theta + \cos^2 \theta$$

$$0 = 2\cos^2 \theta - 2\cos \theta$$

$$0 = 2\cos \theta(\cos \theta - 1)$$

กรณีที่ 1: $\cos \theta = 0$ ให้ $\theta = 90°$ หรือ $270°$

ตรวจสอบ: เมื่อ $\theta = 90°$: $\sin 90° + \cos 90° = 1 + 0 = 1$ ✓

เมื่อ $\theta = 270°$: $\sin 270° + \cos 270° = -1 + 0 = -1$ ✗

กรณีที่ 2: $\cos \theta = 1$ ให้ $\theta = 0°$

ตรวจสอบ: $\sin 0° + \cos 0° = 0 + 1 = 1$ ✓

ตอบ: $\theta = 0°, 90°$

1.4 กฎของไซน์

ความหมาย

กฎของไซน์ (Law of Sines หรือ Sine Rule) เป็นความสัมพันธ์ระหว่างด้านและมุมของรูปสามเหลี่ยมใดๆ ไม่จำเป็นต้องเป็นสามเหลี่ยมมุมฉาก กฎนี้มีประโยชน์ในการหาค่าด้านหรือมุมที่ไม่ทราบค่าในรูปสามเหลี่ยม

กฎของไซน์

สำหรับรูปสามเหลี่ยม ABC ที่มีด้าน $a$, $b$, $c$ ตรงข้ามกับมุม $A$, $B$, $C$ ตามลำดับ

$$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C}$$

หรือเขียนได้ว่า:

$$\frac{\sin A}{a} = \frac{\sin B}{b} = \frac{\sin C}{c}$$

การใช้งาน:

  • ใช้เมื่อทราบมุม 2 มุม และด้าน 1 ด้าน (AAS หรือ ASA)
  • ใช้เมื่อทราบด้าน 2 ด้าน และมุมตรงข้ามด้านหนึ่ง (SSA - ต้องระวังกรณีที่มีคำตอบสองค่า)

ตัวอย่างที่ 1: หาความยาวด้านโดยใช้กฎของไซน์ (กรณี ASA)

โจทย์: ในรูปสามเหลี่ยม ABC กำหนดให้ $A = 40°$, $B = 60°$ และ $c = 10$ ซม. จงหาความยาวของด้าน $a$

วิธีทำ:

ขั้นที่ 1: หามุม $C$

$$C = 180° - A - B = 180° - 40° - 60° = 80°$$

ขั้นที่ 2: ใช้กฎของไซน์หา $a$

$$\frac{a}{\sin A} = \frac{c}{\sin C}$$

$$\frac{a}{\sin 40°} = \frac{10}{\sin 80°}$$

$$a = \frac{10 \sin 40°}{\sin 80°}$$

$$a = \frac{10 \times 0.6428}{0.9848}$$

$$a \approx 6.53 \text{ ซม.}$$

ตอบ: $a \approx 6.53$ ซม.

ตัวอย่างที่ 2: หามุมโดยใช้กฎของไซน์

โจทย์: ในรูปสามเหลี่ยม ABC กำหนดให้ $a = 7$ ซม., $b = 9$ ซม. และ $A = 35°$ จงหามุม $B$

วิธีทำ:

ใช้กฎของไซน์:

$$\frac{\sin A}{a} = \frac{\sin B}{b}$$

$$\frac{\sin 35°}{7} = \frac{\sin B}{9}$$

$$\sin B = \frac{9 \sin 35°}{7}$$

$$\sin B = \frac{9 \times 0.5736}{7}$$

$$\sin B = 0.7372$$

$$B = \sin^{-1}(0.7372) \approx 47.5°$$

หรือ $B \approx 180° - 47.5° = 132.5°$ (แต่ต้องตรวจสอบว่า $A + B < 180°$)

เนื่องจาก $35° + 132.5° = 167.5° < 180°$ ทั้งสองคำตอบเป็นไปได้

ตอบ: $B \approx 47.5°$ หรือ $132.5°$ (กรณี SSA มีคำตอบสองค่า)

ตัวอย่างที่ 3: หาพื้นที่สามเหลี่ยมโดยใช้กฎของไซน์

โจทย์: ในรูปสามเหลี่ยม ABC กำหนดให้ $a = 12$ ซม., $B = 50°$ และ $C = 70°$ จงหาพื้นที่ของรูปสามเหลี่ยม ABC

วิธีทำ:

ขั้นที่ 1: หามุม $A$

$$A = 180° - B - C = 180° - 50° - 70° = 60°$$

ขั้นที่ 2: หาด้าน $c$ โดยใช้กฎของไซน์

$$\frac{a}{\sin A} = \frac{c}{\sin C}$$

$$\frac{12}{\sin 60°} = \frac{c}{\sin 70°}$$

$$c = \frac{12 \sin 70°}{\sin 60°} = \frac{12 \times 0.9397}{0.8660} \approx 13.02 \text{ ซม.}$$

ขั้นที่ 3: หาพื้นที่โดยใช้สูตร $\text{พื้นที่} = \frac{1}{2}ac\sin B$

$$\text{พื้นที่} = \frac{1}{2} \times 12 \times 13.02 \times \sin 50°$$

$$= \frac{1}{2} \times 12 \times 13.02 \times 0.7660$$

$$\approx 59.87 \text{ ตร.ซม.}$$

ตอบ: พื้นที่ $\approx 59.87$ ตร.ซม.

ตัวอย่างที่ 4: การประยุกต์ใช้กฎของไซน์ในชีวิตจริง

โจทย์: จากจุด A บนพื้นดิน สังเกตยอดตึกสูง B ได้มุมเงย $40°$ จากนั้นเดินเข้าไปใกล้ตึก $30$ เมตร ถึงจุด C สังเกตยอดตึกได้มุมเงย $55°$ จงหาความสูงของตึก

วิธีทำ:

ในรูปสามเหลี่ยม ABC:

- มุมที่ A = $40°$

- มุมที่ C = $180° - 55° = 125°$ (มุมภายนอก)

- ด้าน AC = $30$ ม.

ขั้นที่ 1: หามุมที่ B

$$\angle ABC = 180° - 40° - 125° = 15°$$

ขั้นที่ 2: ใช้กฎของไซน์หาด้าน BC

$$\frac{BC}{\sin 40°} = \frac{30}{\sin 15°}$$

$$BC = \frac{30 \sin 40°}{\sin 15°} = \frac{30 \times 0.6428}{0.2588} \approx 74.52 \text{ ม.}$$

ขั้นที่ 3: หาความสูงของตึก

$$h = BC \times \sin 55° = 74.52 \times 0.8192 \approx 61.05 \text{ ม.}$$

ตอบ: ความสูงของตึก $\approx 61.05$ เมตร

1.5 กฎของโคไซน์

ความหมาย

กฎของโคไซน์ (Law of Cosines หรือ Cosine Rule) เป็นการขยายความทฤษฎีพีทาโกรัสให้ใช้ได้กับรูปสามเหลี่ยมทุกชนิด กฎนี้เชื่อมโยงความยาวของด้านทั้งสามกับมุมหนึ่งของรูปสามเหลี่ยม มีประโยชน์ในการหาค่าด้านหรือมุมที่ไม่ทราบค่า

กฎของโคไซน์

สำหรับรูปสามเหลี่ยม ABC ที่มีด้าน $a$, $b$, $c$ และมุม $A$, $B$, $C$ ตามลำดับ

$$a^2 = b^2 + c^2 - 2bc \cos A$$

$$b^2 = a^2 + c^2 - 2ac \cos B$$

$$c^2 = a^2 + b^2 - 2ab \cos C$$

หรือเขียนในรูปของมุม:

$$\cos A = \frac{b^2 + c^2 - a^2}{2bc}$$

$$\cos B = \frac{a^2 + c^2 - b^2}{2ac}$$

$$\cos C = \frac{a^2 + b^2 - c^2}{2ab}$$

การใช้งาน:

  • ใช้เมื่อทราบด้าน 2 ด้าน และมุมระหว่างด้านทั้งสอง (SAS)
  • ใช้เมื่อทราบด้านทั้ง 3 ด้าน (SSS)

ตัวอย่างที่ 1: หาความยาวด้านโดยใช้กฎของโคไซน์ (กรณี SAS)

โจทย์: ในรูปสามเหลี่ยม ABC กำหนดให้ $b = 8$ ซม., $c = 10$ ซม. และ $A = 60°$ จงหาความยาวของด้าน $a$

วิธีทำ:

ใช้กฎของโคไซน์:

$$a^2 = b^2 + c^2 - 2bc \cos A$$

$$a^2 = 8^2 + 10^2 - 2(8)(10) \cos 60°$$

$$a^2 = 64 + 100 - 160 \times \frac{1}{2}$$

$$a^2 = 164 - 80$$

$$a^2 = 84$$

$$a = \sqrt{84} = 2\sqrt{21} \approx 9.17 \text{ ซม.}$$

ตอบ: $a = 2\sqrt{21} \approx 9.17$ ซม.

ตัวอย่างที่ 2: หามุมโดยใช้กฎของโคไซน์ (กรณี SSS)

โจทย์: ในรูปสามเหลี่ยม ABC กำหนดให้ $a = 7$ ซม., $b = 8$ ซม. และ $c = 5$ ซม. จงหามุม $C$

วิธีทำ:

ใช้กฎของโคไซน์:

$$\cos C = \frac{a^2 + b^2 - c^2}{2ab}$$

$$\cos C = \frac{7^2 + 8^2 - 5^2}{2(7)(8)}$$

$$\cos C = \frac{49 + 64 - 25}{112}$$

$$\cos C = \frac{88}{112} = \frac{11}{14}$$

$$C = \cos^{-1}\left(\frac{11}{14}\right) \approx 38.21°$$

ตอบ: $C \approx 38.21°$

ตัวอย่างที่ 3: หาพื้นที่สามเหลี่ยมโดยใช้กฎของโคไซน์

โจทย์: รูปสามเหลี่ยม ABC มีด้าน $a = 12$ ซม., $b = 15$ ซม. และมุม $C = 75°$ จงหาพื้นที่ของรูปสามเหลี่ยม ABC

วิธีทำ:

วิธีที่ 1: ใช้สูตร $\text{พื้นที่} = \frac{1}{2}ab\sin C$

$$\text{พื้นที่} = \frac{1}{2} \times 12 \times 15 \times \sin 75°$$

$$= 90 \times 0.9659$$

$$\approx 86.93 \text{ ตร.ซม.}$$

วิธีที่ 2: หาด้าน $c$ ก่อนแล้วใช้สูตรเฮรอน

$$c^2 = a^2 + b^2 - 2ab \cos C$$

$$c^2 = 12^2 + 15^2 - 2(12)(15) \cos 75°$$

$$c^2 = 144 + 225 - 360 \times 0.2588$$

$$c^2 = 369 - 93.17 = 275.83$$

$$c \approx 16.61 \text{ ซม.}$$

ตอบ: พื้นที่ $\approx 86.93$ ตร.ซม.

ตัวอย่างที่ 4: การประยุกต์ใช้กฎของโคไซน์

โจทย์: เรือลำหนึ่งออกจากท่าเรือแล่นไปทางทิศเหนือ $50$ กม. จากนั้นเปลี่ยนทิศไปทางตะวันออกเฉียงเหนือ ($45°$ จากทิศเหนือ) เป็นระยะทาง $40$ กม. จงหาระยะทางของเรือจากท่าเรือเป็นเส้นตรง

วิธีทำ:

ให้ A = ท่าเรือ, B = จุดแรกที่เปลี่ยนทิศ, C = ตำแหน่งปัจจุบันของเรือ

- $AB = 50$ กม.

- $BC = 40$ กม.

- มุมที่ B = $180° - 45° = 135°$ (มุมระหว่างเส้นทางสองทิศทาง)

ใช้กฎของโคไซน์หาด้าน $AC$:

$$AC^2 = AB^2 + BC^2 - 2(AB)(BC) \cos B$$

$$AC^2 = 50^2 + 40^2 - 2(50)(40) \cos 135°$$

$$AC^2 = 2500 + 1600 - 4000 \times (-\frac{\sqrt{2}}{2})$$

$$AC^2 = 4100 + 2828.43$$

$$AC^2 = 6928.43$$

$$AC \approx 83.24 \text{ กม.}$$

ตอบ: ระยะทางของเรือจากท่าเรือ $\approx 83.24$ กิโลเมตร

1.6 การแก้สามเหลี่ยม

ความหมาย

การแก้สามเหลี่ยม (Solving Triangles) หมายถึง การหาค่าของด้านและมุมที่ไม่ทราบค่าทั้งหมดในรูปสามเหลี่ยม เมื่อทราบข้อมูลบางส่วน การแก้สามเหลี่ยมใช้กฎของไซน์ กฎของโคไซน์ และทฤษฎีพีทาโกรัส

รูปแบบการแก้สามเหลี่ยม

1. กรณี ASA (Angle-Side-Angle)

ทราบมุม 2 มุม และด้านระหว่างมุมทั้งสอง

วิธีแก้: หามุมที่เหลือ แล้วใช้กฎของไซน์หาด้านที่เหลือ

2. กรณี AAS (Angle-Angle-Side)

ทราบมุม 2 มุม และด้านที่ไม่อยู่ระหว่างมุมทั้งสอง

วิธีแก้: หามุมที่เหลือ แล้วใช้กฎของไซน์หาด้านที่เหลือ

3. กรณี SAS (Side-Angle-Side)

ทราบด้าน 2 ด้าน และมุมระหว่างด้านทั้งสอง

วิธีแก้: ใช้กฎของโคไซน์หาด้านที่เหลือ แล้วใช้กฎของไซน์หรือโคไซน์หามุมที่เหลือ

4. กรณี SSS (Side-Side-Side)

ทราบด้านทั้ง 3 ด้าน

วิธีแก้: ใช้กฎของโคไซน์หามุมทั้งหมด

5. กรณี SSA (Side-Side-Angle)

ทราบด้าน 2 ด้าน และมุมที่ไม่อยู่ระหว่างด้านทั้งสอง

วิธีแก้: ใช้กฎของไซน์ (ระวัง! อาจมีคำตอบ 0, 1 หรือ 2 คำตอบ)

ตัวอย่างที่ 1: แก้สามเหลี่ยมกรณี ASA

โจทย์: ในรูปสามเหลี่ยม ABC กำหนดให้ $A = 50°$, $C = 70°$ และ $b = 12$ ซม. จงหาค่าที่เหลือทั้งหมด

วิธีทำ:

ขั้นที่ 1: หามุม $B$

$$B = 180° - A - C = 180° - 50° - 70° = 60°$$

ขั้นที่ 2: ใช้กฎของไซน์หาด้าน $a$

$$\frac{a}{\sin A} = \frac{b}{\sin B}$$

$$\frac{a}{\sin 50°} = \frac{12}{\sin 60°}$$

$$a = \frac{12 \sin 50°}{\sin 60°} = \frac{12 \times 0.7660}{0.8660} \approx 10.62 \text{ ซม.}$$

ขั้นที่ 3: ใช้กฎของไซน์หาด้าน $c$

$$\frac{c}{\sin C} = \frac{b}{\sin B}$$

$$\frac{c}{\sin 70°} = \frac{12}{\sin 60°}$$

$$c = \frac{12 \sin 70°}{\sin 60°} = \frac{12 \times 0.9397}{0.8660} \approx 13.02 \text{ ซม.}$$

ตอบ: $B = 60°$, $a \approx 10.62$ ซม., $c \approx 13.02$ ซม.

ตัวอย่างที่ 2: แก้สามเหลี่ยมกรณี SAS

โจทย์: ในรูปสามเหลี่ยม ABC กำหนดให้ $a = 9$ ซม., $c = 7$ ซม. และ $B = 55°$ จงหาค่าที่เหลือทั้งหมด

วิธีทำ:

ขั้นที่ 1: ใช้กฎของโคไซน์หาด้าน $b$

$$b^2 = a^2 + c^2 - 2ac \cos B$$

$$b^2 = 9^2 + 7^2 - 2(9)(7) \cos 55°$$

$$b^2 = 81 + 49 - 126 \times 0.5736$$

$$b^2 = 130 - 72.27 = 57.73$$

$$b \approx 7.60 \text{ ซม.}$$

ขั้นที่ 2: ใช้กฎของไซน์หามุม $A$

$$\frac{\sin A}{a} = \frac{\sin B}{b}$$

$$\sin A = \frac{a \sin B}{b} = \frac{9 \times 0.8192}{7.60} = 0.9702$$

$$A \approx 76.01°$$

ขั้นที่ 3: หามุม $C$

$$C = 180° - A - B = 180° - 76.01° - 55° = 48.99°$$

ตอบ: $b \approx 7.60$ ซม., $A \approx 76.01°$, $C \approx 48.99°$

ตัวอย่างที่ 3: แก้สามเหลี่ยมกรณี SSS

โจทย์: ในรูปสามเหลี่ยม ABC กำหนดให้ $a = 8$ ซม., $b = 10$ ซม. และ $c = 6$ ซม. จงหามุมทั้งสาม

วิธีทำ:

ขั้นที่ 1: ใช้กฎของโคไซน์หามุม $A$

$$\cos A = \frac{b^2 + c^2 - a^2}{2bc} = \frac{10^2 + 6^2 - 8^2}{2(10)(6)}$$

$$\cos A = \frac{100 + 36 - 64}{120} = \frac{72}{120} = 0.6$$

$$A = \cos^{-1}(0.6) \approx 53.13°$$

ขั้นที่ 2: ใช้กฎของโคไซน์หามุม $B$

$$\cos B = \frac{a^2 + c^2 - b^2}{2ac} = \frac{8^2 + 6^2 - 10^2}{2(8)(6)}$$

$$\cos B = \frac{64 + 36 - 100}{96} = \frac{0}{96} = 0$$

$$B = \cos^{-1}(0) = 90°$$

ขั้นที่ 3: หามุม $C$

$$C = 180° - A - B = 180° - 53.13° - 90° = 36.87°$$

ตอบ: $A \approx 53.13°$, $B = 90°$, $C \approx 36.87°$

ตัวอย่างที่ 4: แก้สามเหลี่ยมกรณี SSA (กรณีที่มีคำตอบสองค่า)

โจทย์: ในรูปสามเหลี่ยม ABC กำหนดให้ $a = 8$ ซม., $b = 10$ ซม. และ $A = 40°$ จงหาค่าที่เหลือทั้งหมด (ถ้ามี)

วิธีทำ:

ขั้นที่ 1: ใช้กฎของไซน์หามุม $B$

$$\frac{\sin B}{b} = \frac{\sin A}{a}$$

$$\sin B = \frac{b \sin A}{a} = \frac{10 \times \sin 40°}{8} = \frac{10 \times 0.6428}{8} = 0.8035$$

ขั้นที่ 2: หาค่ามุม $B$

$$B_1 = \sin^{-1}(0.8035) \approx 53.47°$$

$$B_2 = 180° - 53.47° = 126.53°$$

กรณีที่ 1: $B = 53.47°$

$$C = 180° - 40° - 53.47° = 86.53°$$

$$\frac{c}{\sin C} = \frac{a}{\sin A}$$

$$c = \frac{8 \times \sin 86.53°}{\sin 40°} = \frac{8 \times 0.9980}{0.6428} \approx 12.42 \text{ ซม.}$$

กรณีที่ 2: $B = 126.53°$

$$C = 180° - 40° - 126.53° = 13.47°$$

$$c = \frac{8 \times \sin 13.47°}{\sin 40°} = \frac{8 \times 0.2331}{0.6428} \approx 2.90 \text{ ซม.}$$

ตอบ: มีคำตอบสองชุด

ชุดที่ 1: $B \approx 53.47°$, $C \approx 86.53°$, $c \approx 12.42$ ซม.

ชุดที่ 2: $B \approx 126.53°$, $C \approx 13.47°$, $c \approx 2.90$ ซม.

แบบฝึกหัดบทที่ 1

ส่วนที่ 1: ฟังก์ชันตรีโกณมิติและเอกลักษณ์ (4 คะแนน)

  1. ถ้า $\tan \theta = \frac{5}{12}$ และ $\theta$ อยู่ในควอแดรนต์ที่ 1 จงหาค่า $\sin \theta$ และ $\cos \theta$
  2. จงหาค่าที่แน่นอนของ $\cos 15°$ โดยใช้เอกลักษณ์ผลต่างของมุม
  3. พิสูจน์ว่า $\frac{\tan \theta + \cot \theta}{\tan \theta} = \csc^2 \theta$
  4. ถ้า $\cos \theta = -\frac{3}{5}$ และ $90° < \theta < 180°$ จงหาค่า $\sin 2\theta$

เฉลย ส่วนที่ 1:

1. ให้สามเหลี่ยมมุมฉากมีด้านตรงข้าม = 5, ด้านประชิด = 12

หาด้านตรง: $c = \sqrt{5^2 + 12^2} = \sqrt{25 + 144} = \sqrt{169} = 13$

$$\sin \theta = \frac{5}{13}, \quad \cos \theta = \frac{12}{13}$$

2. $\cos 15° = \cos(45° - 30°)$

$$= \cos 45° \cos 30° + \sin 45° \sin 30°$$

$$= \frac{\sqrt{2}}{2} \cdot \frac{\sqrt{3}}{2} + \frac{\sqrt{2}}{2} \cdot \frac{1}{2}$$

$$= \frac{\sqrt{6}}{4} + \frac{\sqrt{2}}{4} = \frac{\sqrt{6} + \sqrt{2}}{4}$$

3. พิจารณาทางซ้าย:

$$\frac{\tan \theta + \cot \theta}{\tan \theta} = \frac{\tan \theta}{\tan \theta} + \frac{\cot \theta}{\tan \theta} = 1 + \frac{1}{\tan^2 \theta}$$

$$= 1 + \cot^2 \theta = \csc^2 \theta$$ (ใช้เอกลักษณ์พีทาโกรัส)

4. หา $\sin \theta$ จาก $\sin^2 \theta + \cos^2 \theta = 1$

$$\sin^2 \theta = 1 - \left(-\frac{3}{5}\right)^2 = 1 - \frac{9}{25} = \frac{16}{25}$$

$$\sin \theta = \frac{4}{5}$$ (บวกในควอแดรนต์ที่ 2)

$$\sin 2\theta = 2\sin \theta \cos \theta = 2 \times \frac{4}{5} \times \left(-\frac{3}{5}\right) = -\frac{24}{25}$$

ส่วนที่ 2: สมการตรีโกณมิติ (4 คะแนน)

  1. แก้สมการ $2\cos \theta + \sqrt{3} = 0$ สำหรับ $0° \leq \theta < 360°$
  2. แก้สมการ $\tan^2 \theta - 3 = 0$ สำหรับ $0° \leq \theta < 360°$
  3. แก้สมการ $\sin 2\theta = \sin \theta$ สำหรับ $0° \leq \theta < 360°$
  4. แก้สมการ $2\sin^2 \theta - 3\sin \theta + 1 = 0$ สำหรับ $0° \leq \theta < 360°$

เฉลย ส่วนที่ 2:

5. $2\cos \theta + \sqrt{3} = 0$

$$\cos \theta = -\frac{\sqrt{3}}{2}$$

ในช่วง $0° \leq \theta < 360°$:

$$\theta = 150° \quad \text{หรือ} \quad \theta = 210°$$

6. $\tan^2 \theta - 3 = 0$

$$\tan^2 \theta = 3$$

$$\tan \theta = \pm\sqrt{3}$$

เมื่อ $\tan \theta = \sqrt{3}$: $\theta = 60°, 240°$

เมื่อ $\tan \theta = -\sqrt{3}$: $\theta = 120°, 300°$

$$\theta = 60°, 120°, 240°, 300°$$

7. $\sin 2\theta = \sin \theta$

$$2\sin \theta \cos \theta = \sin \theta$$

$$2\sin \theta \cos \theta - \sin \theta = 0$$

$$\sin \theta(2\cos \theta - 1) = 0$$

เมื่อ $\sin \theta = 0$: $\theta = 0°, 180°$

เมื่อ $\cos \theta = \frac{1}{2}$: $\theta = 60°, 300°$

$$\theta = 0°, 60°, 180°, 300°$$

8. ให้ $x = \sin \theta$

$$2x^2 - 3x + 1 = 0$$

$$(2x - 1)(x - 1) = 0$$

$$x = \frac{1}{2} \quad \text{หรือ} \quad x = 1$$

เมื่อ $\sin \theta = \frac{1}{2}$: $\theta = 30°, 150°$

เมื่อ $\sin \theta = 1$: $\theta = 90°$

$$\theta = 30°, 90°, 150°$$

ส่วนที่ 3: กฎของไซน์ (3 คะแนน)

  1. ในรูปสามเหลี่ยม ABC กำหนดให้ $a = 10$ ซม., $A = 45°$ และ $B = 60°$ จงหาความยาวของด้าน $b$
  2. ในรูปสามเหลี่ยม ABC กำหนดให้ $a = 12$ ซม., $b = 8$ ซม. และ $A = 70°$ จงหามุม $B$
  3. ในรูปสามเหลี่ยม ABC มี $A = 50°$, $B = 70°$ และ $a = 15$ ซม. จงหาพื้นที่ของสามเหลี่ยม ABC

เฉลย ส่วนที่ 3:

9. ใช้กฎของไซน์:

$$\frac{a}{\sin A} = \frac{b}{\sin B}$$

$$\frac{10}{\sin 45°} = \frac{b}{\sin 60°}$$

$$b = \frac{10 \times \sin 60°}{\sin 45°} = \frac{10 \times \frac{\sqrt{3}}{2}}{\frac{\sqrt{2}}{2}}$$

$$b = \frac{10\sqrt{3}}{\sqrt{2}} = 5\sqrt{6} \approx 12.25 \text{ ซม.}$$

10. ใช้กฎของไซน์:

$$\frac{\sin A}{a} = \frac{\sin B}{b}$$

$$\sin B = \frac{b \sin A}{a} = \frac{8 \times \sin 70°}{12}$$

$$\sin B = \frac{8 \times 0.9397}{12} = 0.6265$$

$$B = \sin^{-1}(0.6265) \approx 38.79°$$ (หรือ $141.21°$ แต่ไม่เป็นไปได้เพราะ $A + B > 180°$)

11. หามุม $C = 180° - 50° - 70° = 60°$

หาด้าน $c$ จากกฎของไซน์:

$$\frac{c}{\sin C} = \frac{a}{\sin A}$$

$$c = \frac{15 \times \sin 60°}{\sin 50°} = \frac{15 \times 0.8660}{0.7660} \approx 16.95 \text{ ซม.}$$

พื้นที่ $= \frac{1}{2} \times a \times c \times \sin B$

$$= \frac{1}{2} \times 15 \times 16.95 \times \sin 70°$$

$$= \frac{1}{2} \times 15 \times 16.95 \times 0.9397 \approx 119.48 \text{ ตร.ซม.}$$

ส่วนที่ 4: กฎของโคไซน์ (3 คะแนน)

  1. ในรูปสามเหลี่ยม ABC กำหนดให้ $a = 7$ ซม., $b = 9$ ซม. และ $C = 120°$ จงหาความยาวของด้าน $c$
  2. ในรูปสามเหลี่ยม ABC กำหนดให้ $a = 5$ ซม., $b = 7$ ซม. และ $c = 8$ ซม. จงหามุม $A$
  3. รูปสามเหลี่ยมมีด้านยาว $6$ ซม., $8$ ซม. และ $10$ ซม. จงหามุมที่ใหญ่ที่สุด

เฉลย ส่วนที่ 4:

12. ใช้กฎของโคไซน์:

$$c^2 = a^2 + b^2 - 2ab \cos C$$

$$c^2 = 7^2 + 9^2 - 2(7)(9) \cos 120°$$

$$c^2 = 49 + 81 - 126 \times (-\frac{1}{2})$$

$$c^2 = 130 + 63 = 193$$

$$c = \sqrt{193} \approx 13.89 \text{ ซม.}$$

13. ใช้กฎของโคไซน์:

$$\cos A = \frac{b^2 + c^2 - a^2}{2bc}$$

$$\cos A = \frac{7^2 + 8^2 - 5^2}{2(7)(8)} = \frac{49 + 64 - 25}{112} = \frac{88}{112} = \frac{11}{14}$$

$$A = \cos^{-1}\left(\frac{11}{14}\right) \approx 38.21°$$

14. มุมที่ใหญ่ที่สุดตรงข้ามด้านที่ยาวที่สุด (10 ซม.)

$$\cos C = \frac{6^2 + 8^2 - 10^2}{2(6)(8)} = \frac{36 + 64 - 100}{96} = \frac{0}{96} = 0$$

$$C = \cos^{-1}(0) = 90°$$

ส่วนที่ 5: การแก้สามเหลี่ยมและการประยุกต์ (6 คะแนน)

  1. แก้สามเหลี่ยม ABC เมื่อกำหนดให้ $a = 12$ ซม., $b = 15$ ซม. และ $c = 18$ ซม.
  2. แก้สามเหลี่ยม ABC เมื่อกำหนดให้ $A = 35°$, $B = 65°$ และ $c = 20$ ซม.
  3. แก้สามเหลี่ยม ABC เมื่อกำหนดให้ $a = 8$ ซม., $b = 12$ ซม. และ $C = 75°$
  4. หอคอยสูง $h$ เมตร จากจุด A บนพื้นดินมองเห็นยอดหอคอยได้มุมเงย $30°$ จากจุด B ที่อยู่ห่างจากจุด A เป็นระยะ $50$ เมตร มองเห็นยอดหอคอยได้มุมเงย $45°$ และจุด A, B อยู่ด้านเดียวกันของหอคอย จงหาความสูงของหอคอย
  5. เรือลำหนึ่งแล่นจากท่าเรือไปทางทิศเหนือ $30$ กม. จากนั้นเปลี่ยนทิศไปทางตะวันออกเฉียงเหนือ $60°$ เป็นระยะทาง $25$ กม. จงหาระยะทางของเรือจากท่าเรือเป็นเส้นตรง
  6. รูปสามเหลี่ยม ABC มีด้าน $a = 13$ ซม., $b = 14$ ซม. และ $c = 15$ ซม. จงหาพื้นที่ของรูปสามเหลี่ยม ABC โดยใช้สูตรเฮรอน

เฉลย ส่วนที่ 5:

15. กรณี SSS - ใช้กฎของโคไซน์

$$\cos A = \frac{15^2 + 18^2 - 12^2}{2(15)(18)} = \frac{225 + 324 - 144}{540} = \frac{405}{540} = 0.75$$

$$A = \cos^{-1}(0.75) \approx 41.41°$$

$$\cos B = \frac{12^2 + 18^2 - 15^2}{2(12)(18)} = \frac{144 + 324 - 225}{432} = \frac{243}{432} = 0.5625$$

$$B = \cos^{-1}(0.5625) \approx 55.77°$$

$$C = 180° - 41.41° - 55.77° = 82.82°$$

16. กรณี AAS

$$C = 180° - 35° - 65° = 80°$$

$$\frac{a}{\sin A} = \frac{c}{\sin C}$$

$$a = \frac{20 \times \sin 35°}{\sin 80°} = \frac{20 \times 0.5736}{0.9848} \approx 11.64 \text{ ซม.}$$

$$b = \frac{20 \times \sin 65°}{\sin 80°} = \frac{20 \times 0.9063}{0.9848} \approx 18.40 \text{ ซม.}$$

17. กรณี SAS - ใช้กฎของโคไซน์

$$c^2 = a^2 + b^2 - 2ab \cos C$$

$$c^2 = 8^2 + 12^2 - 2(8)(12) \cos 75°$$

$$c^2 = 64 + 144 - 192 \times 0.2588 = 208 - 49.69 = 158.31$$

$$c \approx 12.58 \text{ ซม.}$$

ใช้กฎของไซน์หามุม A:

$$\sin A = \frac{8 \times \sin 75°}{12.58} = \frac{8 \times 0.9659}{12.58} = 0.6144$$

$$A \approx 37.93°, \quad B = 180° - 75° - 37.93° = 67.07°$$

18. ให้ C = ฐานหอคอย

ในสามเหลี่ยม ABC: $\angle CAB = 30°$, $\angle CBA = 180° - 45° = 135°$, $AB = 50$ ม.

$$\angle ACB = 180° - 30° - 135° = 15°$$

ใช้กฎของไซน์:

$$\frac{BC}{\sin 30°} = \frac{50}{\sin 15°}$$

$$BC = \frac{50 \times 0.5}{0.2588} \approx 96.65 \text{ ม.}$$

$$h = BC \times \sin 45° = 96.65 \times 0.7071 \approx 68.36 \text{ ม.}$$

19. มุมระหว่างเส้นทางสองทิศ = $180° - 60° = 120°$

ใช้กฎของโคไซน์:

$$d^2 = 30^2 + 25^2 - 2(30)(25) \cos 120°$$

$$d^2 = 900 + 625 - 1500 \times (-0.5) = 1525 + 750 = 2275$$

$$d = \sqrt{2275} \approx 47.70 \text{ กม.}$$

20. สูตรเฮรอน: $s = \frac{a + b + c}{2} = \frac{13 + 14 + 15}{2} = 21$

$$\text{พื้นที่} = \sqrt{s(s-a)(s-b)(s-c)}$$

$$= \sqrt{21 \times 8 \times 7 \times 6} = \sqrt{7056} = 84 \text{ ตร.ซม.}$$
