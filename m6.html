คณิตศาสตร์ มัธยมศึกษาปีที่ 6

คณิตศาสตร์ ม.6 เป็นบทสรุปของความรู้คณิตศาสตร์ระดับมัธยมศึกษา ประกอบด้วยเนื้อหาที่ท้าทายและลึกซึ้ง ได้แก่ ปริพันธ์ สมการเชิงอนุพันธ์ เวกเตอร์ในสามมิติ เรขาคณิตวิเคราะห์ขั้นสูง ความน่าจะเป็นขั้นสูง และการวิเคราะห์ข้อมูล ซึ่งเป็นรากฐานสำคัญสำหรับการศึกษาต่อในระดับอุดมศึกษา

บทที่ 1: ปริพันธ์ (Integrals)

1.1 ปริพันธ์ไม่จำกัดเขต

ปริพันธ์ คือ การหาฟังก์ชันที่เมื่อหาอนุพันธ์แล้วได้ฟังก์ชันเดิม (ตรงข้ามกับอนุพันธ์)

สูตรพื้นฐาน:

∫ xⁿ dx = xⁿ⁺¹/(n+1) + C (n ≠ -1)
∫ 1/x dx = ln|x| + C
∫ eˣ dx = eˣ + C
∫ sin x dx = -cos x + C
∫ cos x dx = sin x + C
∫ sec²x dx = tan x + C

โดยที่ C = ค่าคงที่

ตัวอย่างที่ 1:

จงหา ∫ 3x² dx

วิธีทำ: = 3 ∫ x² dx = 3 × x³/3 + C = x³ + C

ตอบ: x³ + C

1.2 เทคนิคการหาปริพันธ์

การแทนค่า (Substitution):

ใช้เมื่อพบฟังก์ชันผสมที่ซับซ้อน
ให้ u = g(x), du = g'(x)dx

ตัวอย่างที่ 2:

จงหา ∫ 2x(x²+1)⁵ dx

วิธีทำ: ให้ u = x²+1, du = 2x dx

= ∫ u⁵ du = u⁶/6 + C = (x²+1)⁶/6 + C

ตอบ: (x²+1)⁶/6 + C

1.3 ปริพันธ์จำกัดเขต

ทฤษฎีบทพื้นฐานของแคลคูลัส:

∫ₐᵇ f(x) dx = F(b) - F(a)

โดยที่ F'(x) = f(x)

ตัวอย่างที่ 3:

จงหา ∫₁³ x² dx

วิธีทำ: = [x³/3]₁³ = (3³/3) - (1³/3) = 9 - 1/3 = 26/3

ตอบ: 26/3

1.4 การประยุกต์ใช้ปริพันธ์

  • หาพื้นที่ใต้กราฟ
  • หาปริมาตรของทรงตัน
  • หาความยาวของเส้นโค้ง
  • หาระยะทางจากความเร็ว

พื้นที่ใต้กราฟ:

A = ∫ₐᵇ f(x) dx

บทที่ 2: สมการเชิงอนุพันธ์

2.1 ความหมายของสมการเชิงอนุพันธ์

สมการเชิงอนุพันธ์ คือ สมการที่มีอนุพันธ์ของฟังก์ชันเป็นสมาชิก

ตัวอย่าง:

dy/dx = 2x เป็นสมการเชิงอนุพันธ์อันดับที่ 1

d²y/dx² + 3dy/dx + 2y = 0 เป็นสมการเชิงอนุพันธ์อันดับที่ 2

2.2 การแก้สมการเชิงอนุพันธ์แบบแยกตัวแปรได้

ตัวอย่างที่ 4:

จงแก้สมการ dy/dx = 2xy

วิธีทำ:

dy/y = 2x dx

∫ dy/y = ∫ 2x dx

ln|y| = x² + C

y = e^(x²+C) = Ae^(x²)

ตอบ: y = Ae^(x²)

2.3 การประยุกต์ใช้สมการเชิงอนุพันธ์

  • แบบจำลองการเจริญเติบโตของประชากร
  • การสลายตัวของสารกัมมันตรังสี
  • กฎของนิวตันเกี่ยวกับการเย็นตัว
  • วงจรไฟฟ้า

บทที่ 3: เวกเตอร์ในสามมิติ

3.1 เวกเตอร์ในพิกัดสามมิติ

เวกเตอร์ในสามมิติมีรูปแบบ →v = (x, y, z) หรือ →v = xi + yj + zk

ขนาดของเวกเตอร์:

|→v| = √(x² + y² + z²)

ตัวอย่างที่ 5:

จงหาขนาดของเวกเตอร์ →v = (2, 3, 6)

วิธีทำ: |→v| = √(2² + 3² + 6²) = √(4 + 9 + 36) = √49 = 7

ตอบ: 7

3.2 ผลคูณดอต (Dot Product)

สูตร:

→a · →b = a₁b₁ + a₂b₂ + a₃b₃
→a · →b = |→a| |→b| cos θ

ตัวอย่างที่ 6:

จงหา →a · →b เมื่อ →a = (1, 2, 3) และ →b = (4, 5, 6)

วิธีทำ: →a · →b = (1×4) + (2×5) + (3×6) = 4 + 10 + 18 = 32

ตอบ: 32

3.3 ผลคูณไขว้ (Cross Product)

สูตร:

→a × →b = (a₂b₃ - a₃b₂, a₃b₁ - a₁b₃, a₁b₂ - a₂b₁)
|→a × →b| = |→a| |→b| sin θ

สมบัติผลคูณไขว้:

• →a × →b เป็นเวกเตอร์ที่ตั้งฉากกับทั้ง →a และ →b
• →a × →b = -→b × →a
• →a × →a = 0

3.4 การประยุกต์ใช้เวกเตอร์

  • หาสมการของเส้นตรงและระนาบในสามมิติ
  • หาระยะจากจุดถึงเส้นตรงหรือระนาบ
  • หามุมระหว่างเวกเตอร์
  • หาพื้นที่ของรูปสี่เหลี่ยมด้านขนาน

บทที่ 4: เรขาคณิตวิเคราะห์ขั้นสูง

4.1 เส้นตรงในระนาบ

สมการเส้นตรง:

รูปทั่วไป: Ax + By + C = 0
รูปความชัน-จุดตัด: y = mx + b
รูปจุด-ความชัน: y - y₁ = m(x - x₁)

4.2 วงกลม

สมการวงกลม:

(x - h)² + (y - k)² = r²
x² + y² + Dx + Ey + F = 0

โดยที่ (h, k) = ศูนย์กลาง, r = รัศมี

ตัวอย่างที่ 7:

จงหาสมการวงกลมที่มีศูนย์กลาง (3, 4) และรัศมี 5

วิธีทำ: (x - 3)² + (y - 4)² = 25

ตอบ: (x - 3)² + (y - 4)² = 25

4.3 พาราโบลา

สมการพาราโบลา:

แนวตั้ง: (x - h)² = 4p(y - k)
แนวนอน: (y - k)² = 4p(x - h)

โดยที่ (h, k) = จุดยอด, p = ระยะจากจุดยอดถึงโฟกัส

4.4 วงรี (Ellipse)

สมการวงรี:

(x - h)²/a² + (y - k)²/b² = 1

โดยที่ (h, k) = ศูนย์กลาง, a = กึ่งแกนเอก, b = กึ่งแกนโท

4.5 ไฮเพอร์โบลา (Hyperbola)

สมการไฮเพอร์โบลา:

แนวนอน: (x - h)²/a² - (y - k)²/b² = 1
แนวตั้ง: (y - k)²/a² - (x - h)²/b² = 1

บทที่ 5: ความน่าจะเป็นขั้นสูง

5.1 ทฤษฎีบทของเบย์

สูตร:

P(A|B) = P(B|A) × P(A) / P(B)

5.2 ตัวแปรสุ่มและการแจกแจง

ตัวแปรสุ่ม คือ ฟังก์ชันที่กำหนดค่าจำนวนให้กับผลลัพธ์แต่ละอย่างในปริภูมิตัวอย่าง

ประเภทของตัวแปรสุ่ม:

• ตัวแปรสุ่มแบบไม่ต่อเนื่อง (Discrete)
• ตัวแปรสุ่มแบบต่อเนื่อง (Continuous)

5.3 การแจกแจงแบบปกติ

สูตร:

f(x) = (1/σ√(2π)) × e^(-(x-μ)²/(2σ²))

โดยที่ μ = ค่าเฉลี่ย, σ = ส่วนเบี่ยงเบนมาตรฐาน

5.4 ช่วงความเชื่อมั่น

ช่วงความเชื่อมั่น คือ ช่วงของค่าที่คาดว่าจะมีพารามิเตอร์ของประชากร

ตัวอย่างที่ 8:

ช่วงความเชื่อมั่น 95% สำหรับค่าเฉลี่ย:

x̄ - 1.96(σ/√n) < μ < x̄ + 1.96(σ/√n)

บทที่ 6: การวิเคราะห์ข้อมูล

6.1 การถดถอยเชิงเส้น (Linear Regression)

การหาความสัมพันธ์ระหว่างตัวแปรสองตัวในรูปแบบเส้นตรง

สมการถดถอย:

ŷ = a + bx
b = Σ(xᵢ - x̄)(yᵢ - ȳ) / Σ(xᵢ - x̄)²
a = ȳ - bx̄

6.2 สัมประสิทธิ์สหสัมพันธ์

สูตร:

r = Σ(xᵢ - x̄)(yᵢ - ȳ) / √[Σ(xᵢ - x̄)² × Σ(yᵢ - ȳ)²]

-1 ≤ r ≤ 1

การแปลผล:

• r ใกล้ 1: มีความสัมพันธ์เชิงบวกสูง
• r ใกล้ -1: มีความสัมพันธ์เชิงลบสูง
• r ใกล้ 0: ไม่มีความสัมพันธ์เชิงเส้น

6.3 การทดสอบสมมติฐาน

กระบวนการตัดสินใจทางสถิติโดยใช้ข้อมูลจากตัวอย่าง

  • ตั้งสมมติฐานหลัก (H₀) และสมมติฐานรอง (H₁)
  • กำหนดระดับนัยสำคัญ (α)
  • คำนวณค่าสถิติทดสอบ
  • สรุปผล ยอมรับหรือปฏิเสธ H₀

แบบฝึกหัดท้ายบท

ข้อ 1: จงหา ∫ 4x³ dx

เฉลย: = 4 × x⁴/4 + C = x⁴ + C

ข้อ 2: จงหา ∫₀² 2x dx

เฉลย: = [x²]₀² = 4 - 0 = 4

ข้อ 3: จงหาขนาดของเวกเตอร์ →v = (1, 2, 2)

เฉลย: |→v| = √(1² + 2² + 2²) = √9 = 3

ข้อ 4: จงหาศูนย์กลางและรัศมีของวงกลม x² + y² - 6x + 8y = 0

เฉลย: จัดรูปใหม่: (x-3)² + (y+4)² = 25

ศูนย์กลาง (3, -4), รัศมี = 5

ข้อ 5: จงแก้สมการเชิงอนุพันธ์ dy/dx = 3x²

เฉลย:

dy = 3x² dx

∫ dy = ∫ 3x² dx

y = x³ + C

สรุปสำคัญสำหรับสอบเข้ามหาวิทยาลัย

หัวข้อสำคัญที่ควรทบทวน:

  • ปริพันธ์และการประยุกต์ใช้ (พื้นที่, ปริมาตร)
  • อนุพันธ์และการหาค่าสูงสุด-ต่ำสุด
  • ลิมิตและความต่อเนื่อง
  • เวกเตอร์ในระนาบและสามมิติ
  • เรขาคณิตวิเคราะห์ (วงกลม, พาราโบลา)
  • ความน่าจะเป็นและสถิติ
  • เซตและตรรกศาสตร์
  • ฟังก์ชันและกราฟ

เคล็ดลับในการสอบ:

• ทำความเข้าใจแนวคิดพื้นฐานให้แม่นยำ
• จำสูตรสำคัญและเข้าใจที่มา
• ฝึกทำโจทย์หลากหลายรูปแบบ
• จัดการเวลาในการทำข้อสอบอย่างมีประสิทธิภาพ
• ตรวจสอบคำตอบอีกครั้งก่อนส่ง
