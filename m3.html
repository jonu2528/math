คณิตศาสตร์ มัธยมศึกษาปีที่ 3

คณิตศาสตร์ ม.3 เป็นบทสรุปของความรู้ในระดับมัธยมต้น ประกอบด้วยเนื้อหาที่ท้าทาย เช่น สมการกำลังสอง ฟังก์ชัน ตรีโกณมิติเบื้องต้น เรขาคณิตระนาบ และสถิติขั้นสูง ซึ่งจะเป็นพื้นฐานสำคัญในการเรียนคณิตศาสตร์ระดับมัธยมปลาย

บทที่ 1: สมการกำลังสอง (Quadratic Equations)

1.1 ความหมายของสมการกำลังสอง

สมการกำลังสอง คือ สมการที่มีตัวแปรเพียงตัวเดียวและเลขชี้กำลังสูงสุดเป็น 2

รูปแบบทั่วไป:

ax² + bx + c = 0 (เมื่อ a ≠ 0)

1.2 การแก้สมการกำลังสองโดยการแยกตัวประกอบ

ตัวอย่างที่ 1:

จงแก้สมการ x² + 5x + 6 = 0

วิธีทำ:

(x + 2)(x + 3) = 0

x + 2 = 0 หรือ x + 3 = 0

x = -2 หรือ x = -3

ตอบ: x = -2 หรือ x = -3

1.3 การแก้สมการโดยใช้สูตร

สูตรสมการกำลังสอง:

x = (-b ± √(b² - 4ac)) / 2a

ตัวพิจารณา (Discriminant):

D = b² - 4ac

• ถ้า D > 0 มีคำตอบ 2 คำตอบที่แตกต่างกัน
• ถ้า D = 0 มีคำตอบ 1 คำตอบ (คำตอบซ้ำ)
• ถ้า D < 0 ไม่มีคำตอบจริง

ตัวอย่างที่ 2:

จงแก้สมการ 2x² - 7x + 3 = 0 โดยใช้สูตร

วิธีทำ: a = 2, b = -7, c = 3

D = (-7)² - 4(2)(3) = 49 - 24 = 25

x = (7 ± √25) / 4 = (7 ± 5) / 4

x = 12/4 = 3 หรือ x = 2/4 = 1/2

ตอบ: x = 3 หรือ x = 1/2

1.4 การประยุกต์ใช้สมการกำลังสอง

ตัวอย่างที่ 3:

สนามสี่เหลี่ยมผืนผ้ามีความยาวมากกว่าความกว้าง 4 เมตร และมีพื้นที่ 60 ตารางเมตร จงหาความกว้างและความยาวของสนาม

วิธีทำ: กำหนดให้ความกว้าง = x เมตร

ความยาว = x + 4 เมตร

x(x + 4) = 60

x² + 4x - 60 = 0

(x + 10)(x - 6) = 0

x = 6 (เอาเฉพาะค่าบวก)

ตอบ: ความกว้าง 6 เมตร ความยาว 10 เมตร

บทที่ 2: ฟังก์ชัน (Functions)

2.1 ความหมายของฟังก์ชัน

ฟังก์ชัน คือ ความสัมพันธ์ระหว่างสองเซต โดยที่สมาชิกแต่ละตัวในเซตแรกจะสัมพันธ์กับสมาชิกในเซตที่สองเพียงตัวเดียว

สัญลักษณ์:

f(x) อ่านว่า "เอฟของเอ็กซ์" หมายถึง ค่าของฟังก์ชัน f เมื่อ x มีค่าใดค่าหนึ่ง

ตัวอย่างที่ 4:

กำหนด f(x) = 2x + 3 จงหา f(5)

วิธีทำ:

f(5) = 2(5) + 3 = 10 + 3 = 13

ตอบ: 13

2.2 กราฟของฟังก์ชันเชิงเส้น

ฟังก์ชันเชิงเส้นมีรูปแบบ f(x) = mx + b โดยที่ m คือ ความชัน และ b คือ จุดตัดแกน y

ความชัน (Slope):

m = (y₂ - y₁) / (x₂ - x₁)

ตัวอย่างที่ 5:

จงหาความชันของเส้นตรงที่ผ่านจุด (2,3) และ (6,11)

วิธีทำ:

m = (11 - 3) / (6 - 2) = 8 / 4 = 2

ตอบ: ความชัน = 2

2.3 กราฟของฟังก์ชันกำลังสอง

ฟังก์ชันกำลังสองมีรูปแบบ f(x) = ax² + bx + c กราฟเป็นรูปพาราโบลา

จุดยอดของพาราโบลา:

x = -b / 2a

แทน x ในสมการเพื่อหาค่า y

บทที่ 3: ตรีโกณมิติเบื้องต้น (Basic Trigonometry)

3.1 อัตราส่วนตรีโกณมิติ

ในสามเหลี่ยมมุมฉาก มีอัตราส่วนตรีโกณมิติที่สำคัญ 3 อัตราส่วน คือ sin, cos, tan

อัตราส่วนตรีโกณมิติ:

sin θ = ด้านตรงข้าม / ด้านตรงข้ามมุมฉาก
cos θ = ด้านประชิด / ด้านตรงข้ามมุมฉาก
tan θ = ด้านตรงข้าม / ด้านประชิด

ช่วยจำ: โสคาโท่

โส = sin = ตรงข้าม/ตรงข้ามมุมฉาก
คา = cos = ประชิด/ตรงข้ามมุมฉาก
โท่ = tan = ตรงข้าม/ประชิด

3.2 ค่าตรีโกณมิติของมุมพิเศษ

มุมพิเศษที่ควรจำ: 30°, 45°, 60°

ค่าตรีโกณมิติมุมพิเศษ:

sin 30° = 1/2, cos 30° = √3/2, tan 30° = 1/√3

sin 45° = 1/√2, cos 45° = 1/√2, tan 45° = 1

sin 60° = √3/2, cos 60° = 1/2, tan 60° = √3

3.3 การประยุกต์ใช้ตรีโกณมิติ

ตัวอย่างที่ 6:

ในสามเหลี่ยมมุมฉากที่มีด้านตรงข้ามมุมฉาก 10 ซม. และมุมหนึ่งเป็น 30° จงหาด้านตรงข้ามมุม 30°

วิธีทำ:

sin 30° = ด้านตรงข้าม / 10

1/2 = ด้านตรงข้าม / 10

ด้านตรงข้าม = 5 ซม.

ตอบ: 5 เซนติเมตร

บทที่ 4: เรขาคณิตระนาบ (Plane Geometry)

4.1 ทฤษฎีบทพีทาโกรัส

ทฤษฎีบทพีทาโกรัส:

a² + b² = c²

โดยที่ c คือ ด้านตรงข้ามมุมฉาก, a และ b คือ ด้านประกอบมุมฉาก

ตัวอย่างที่ 7:

สามเหลี่ยมมุมฉากมีด้านประกอบมุมฉาก 3 ซม. และ 4 ซม. จงหาด้านตรงข้ามมุมฉาก

วิธีทำ:

c² = 3² + 4² = 9 + 16 = 25

c = √25 = 5 ซม.

ตอบ: 5 เซนติเมตร

4.2 ความสอดคล้องกันของรูปสามเหลี่ยม

เงื่อนไขที่ทำให้สามเหลี่ยมสอดคล้องกัน:

  • SSS: ด้านทั้งสามของสามเหลี่ยมหนึ่งเท่ากับด้านทั้งสามของอีกสามเหลี่ยมหนึ่งตามลำดับ
  • SAS: สองด้านและมุมคั่นของสามเหลี่ยมหนึ่งเท่ากับสองด้านและมุมคั่นของอีกสามเหลี่ยมหนึ่ง
  • ASA: สองมุมและด้านคั่นของสามเหลี่ยมหนึ่งเท่ากับสองมุมและด้านคั่นของอีกสามเหลี่ยมหนึ่ง

4.3 ความสอดคล้องกันของรูปสี่เหลี่ยม

สมบัติของรูปสี่เหลี่ยมพิเศษ:

  • สี่เหลี่ยมจัตุรัส: ด้านทุกด้านเท่ากัน มุมทุกมุมเป็นมุมฉาก
  • สี่เหลี่ยมผืนผ้า: ด้านตรงข้ามขนานและเท่ากัน มุมทุกมุมเป็นมุมฉาก
  • สี่เหลี่ยมด้านขนาน: ด้านตรงข้ามขนานและเท่ากัน มุมตรงข้ามเท่ากัน

บทที่ 5: สถิติและกราฟ

5.1 ค่ากลางของข้อมูล

ค่าเฉลี่ย (Mean):

x̄ = ผลรวมของข้อมูลทั้งหมด / จำนวนข้อมูล

ค่ามัธยฐาน (Median):

ค่ากลางของข้อมูลเมื่อเรียงลำดับจากน้อยไปมาก

ค่าฐานนิยม (Mode):

ค่าที่ปรากฏบ่อยที่สุดในชุดข้อมูล

ตัวอย่างที่ 8:

จงหาค่าเฉลี่ยของข้อมูล: 5, 7, 9, 12, 15, 18

วิธีทำ:

x̄ = (5 + 7 + 9 + 12 + 15 + 18) / 6 = 66 / 6 = 11

ตอบ: 11

5.2 ความน่าจะเป็นเบื้องต้น

สูตรความน่าจะเป็น:

P(A) = จำนวนผลลัพธ์ที่ต้องการ / จำนวนผลลัพธ์ทั้งหมด

ตัวอย่างที่ 9:

ในกล่องมีลูกบอล 5 สี (แดง 2 ลูก, เขียว 3 ลูก) จงหาความน่าจะเป็นที่จะหยิบได้ลูกสีแดง

วิธีทำ:

P(แดง) = 2/5

ตอบ: 2/5 หรือ 0.4

แบบฝึกหัดท้ายบท

ข้อ 1: จงแก้สมการ x² - 9 = 0

เฉลย:

x² = 9

x = ±3

ตอบ: x = 3 หรือ x = -3

ข้อ 2: กำหนด f(x) = 3x - 5 จงหา f(4)

เฉลย:

f(4) = 3(4) - 5 = 12 - 5 = 7

ข้อ 3: จงหาค่า sin 60°

เฉลย: sin 60° = √3/2

ข้อ 4: สามเหลี่ยมมุมฉากมีด้านประกอบมุมฉาก 5 ซม. และ 12 ซม. จงหาด้านตรงข้ามมุมฉาก

เฉลย:

c² = 5² + 12² = 25 + 144 = 169

c = 13 ซม.

ข้อ 5: จงหาค่าเฉลี่ยของข้อมูล: 10, 15, 20, 25, 30

เฉลย:

x̄ = (10 + 15 + 20 + 25 + 30) / 5 = 100 / 5 = 20
