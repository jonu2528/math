คณิตศาสตร์ มัธยมศึกษาปีที่ 5

คณิตศาสตร์ ม.5 เป็นเนื้อหาที่ลึกซึ้งและท้าทาย ครอบคลุมเมทริกซ์ ความน่าจะเป็น สถิติเชิงวิเคราะห์ และแคลคูลัสเบื้องต้น รวมถึงลิมิต ความต่อเนื่อง และอนุพันธ์ ซึ่งเป็นพื้นฐานสำคัญสำหรับการศึกษาในระดับอุดมศึกษา

บทที่ 1: เมทริกซ์ (Matrices)

1.1 ความหมายของเมทริกซ์

เมทริกซ์ คือ ตารางสี่เหลี่ยมผืนผ้าที่เรียงลำดับของจำนวนหรือสัญลักษณ์

ตัวอย่าง:

A = [2 3]
    [1 4]
เป็นเมทริกซ์ขนาด 2×2

1.2 การบวกและลบเมทริกซ์

บวกหรือลบสมาชิกที่อยู่ในตำแหน่งเดียวกัน (ต้องมีขนาดเท่ากัน)

สูตร:

[a b] + [e f] = [a+e b+f]
[c d]   [g h]   [c+g d+h]

1.3 การคูณเมทริกซ์

การคูณเมทริกซ์ A (m×n) กับ B (n×p) ได้เมทริกซ์ผลลัพธ์ขนาด (m×p)

ตัวอย่างที่ 1:

[1 2] × [5 6] = [1×5+2×7 1×6+2×8] = [19 22]
[3 4]   [7 8]   [3×5+4×7 3×6+4×8]   [43 50]

1.4 ดีเทอร์มิแนนต์

สูตร (เมทริกซ์ 2×2):

det [a b] = ad - bc
      [c d]

ตัวอย่างที่ 2:

จงหา det [2 3]
              [1 4]

วิธีทำ: det = (2×4) - (3×1) = 8 - 3 = 5

ตอบ: 5

1.5 เมทริกซ์ผกผัน

เมทริกซ์ผกผัน A⁻¹ คือ เมทริกซ์ที่ทำให้ A × A⁻¹ = I (เมทริกซ์เอกลักษณ์)

สูตร (เมทริกซ์ 2×2):

A⁻¹ = 1/det(A) × [d -b]
                     [-c a]

บทที่ 2: ความน่าจะเป็น (Probability)

2.1 ความน่าจะเป็นเบื้องต้น

สูตร:

P(A) = n(A) / n(S)
0 ≤ P(A) ≤ 1

2.2 กฎการบวก

สูตร:

P(A ∪ B) = P(A) + P(B) - P(A ∩ B)
ถ้า A และ B เป็นเหตุการณ์แยกกัน: P(A ∪ B) = P(A) + P(B)

2.3 กฎการคูณ

สูตร:

P(A ∩ B) = P(A) × P(B|A)
ถ้า A และ B เป็นอิสระต่อกัน: P(A ∩ B) = P(A) × P(B)

ตัวอย่างที่ 3:

โยนเหรียญ 2 ครั้ง จงหาความน่าจะเป็นที่จะได้หัว 2 ครั้ง

วิธีทำ: P(หัว) = 1/2

P(หัว 2 ครั้ง) = 1/2 × 1/2 = 1/4

ตอบ: 1/4

2.4 ความน่าจะเป็นแบบมีเงื่อนไข

สูตร:

P(A|B) = P(A ∩ B) / P(B)

2.5 การจัดหมู่และการเรียงสับเปลี่ยน

สูตร:

การเรียงสับเปลี่ยน: P(n,r) = n!/(n-r)!
การจัดหมู่: C(n,r) = n!/[r!(n-r)!]

บทที่ 3: สถิติเชิงวิเคราะห์

3.1 ส่วนเบี่ยงเบนมาตรฐาน

สูตร:

ความแปรปรวน: σ² = Σ(xᵢ - x̄)² / n
ส่วนเบี่ยงเบนมาตรฐาน: σ = √(σ²)

3.2 การแจกแจงความน่าจะเป็น

การแจกแจงแบบปกติ (Normal Distribution) มีรูปร่างเป็นรูประฆังคว่ำ

สมบัติของการแจกแจงปกติ:

• สมมาตรรอบค่าเฉลี่ย
• ค่าเฉลี่ย = มัธยฐาน = ฐานนิยม
• พื้นที่ใต้กราฟ = 1

บทที่ 4: ลิมิตและความต่อเนื่อง

4.1 ลิมิตของฟังก์ชัน

สัญลักษณ์:

lim f(x) = L
x→a

หมายความว่า เมื่อ x เข้าใกล้ a ค่าของ f(x) จะเข้าใกล้ L

ตัวอย่างที่ 4:

จงหาค่า lim (2x + 3)
          x→2

วิธีทำ: แทน x = 2

= 2(2) + 3 = 7

ตอบ: 7

4.2 ทฤษฎีบทลิมิต

สูตร:

lim [f(x) + g(x)] = lim f(x) + lim g(x)
lim [f(x) × g(x)] = lim f(x) × lim g(x)
lim [f(x)/g(x)] = lim f(x) / lim g(x) [เมื่อ lim g(x) ≠ 0]

4.3 ความต่อเนื่อง

ฟังก์ชัน f ต่อเนื่องที่ x = a ถ้า:

  • 1. f(a) มีค่า
  • 2. lim f(x) มีค่า
        x→a
  • 3. lim f(x) = f(a)
        x→a

บทที่ 5: อนุพันธ์ (Derivatives)

5.1 ความหมายของอนุพันธ์

อนุพันธ์ของฟังก์ชัน f ที่ x คือ อัตราการเปลี่ยนแปลงของ f ที่ x

นิยาม:

f'(x) = lim [f(x+h) - f(x)] / h
       h→0

5.2 สูตรอนุพันธ์พื้นฐาน

สูตร:

d/dx(c) = 0
d/dx(xⁿ) = nxⁿ⁻¹
d/dx(sin x) = cos x
d/dx(cos x) = -sin x
d/dx(eˣ) = eˣ
d/dx(ln x) = 1/x

ตัวอย่างที่ 5:

จงหาอนุพันธ์ของ f(x) = 3x⁴

วิธีทำ: f'(x) = 3 × 4x³ = 12x³

ตอบ: 12x³

5.3 กฎลูกโซ่

สูตร:

d/dx[f(g(x))] = f'(g(x)) × g'(x)

ตัวอย่างที่ 6:

จงหาอนุพันธ์ของ f(x) = (2x + 1)³

วิธีทำ: f'(x) = 3(2x + 1)² × 2 = 6(2x + 1)²

ตอบ: 6(2x + 1)²

5.4 การประยุกต์ใช้อนุพันธ์

  • หาค่าสูงสุดและต่ำสุด
  • หาจุดเปลี่ยนทิศทาง
  • หาความชันของเส้นสัมผัส
  • หาอัตราการเปลี่ยนแปลง

หมายเหตุ:

• f'(x) = 0 ที่จุดสูงสุดหรือต่ำสุดในพื้นที่
• f''(x) > 0 แสดงว่ากราฟเว้าขึ้น
• f''(x) < 0 แสดงว่ากราฟเว้าลง

แบบฝึกหัดท้ายบท

ข้อ 1: จงหา det [3 2]
                       [1 4]

เฉลย: det = (3×4) - (2×1) = 12 - 2 = 10

ข้อ 2: โยนลูกเต๋า 1 ลูก จงหาความน่าจะเป็นที่จะได้เลขคู่

เฉลย: เลขคู่ = {2, 4, 6}

P(คู่) = 3/6 = 1/2

ข้อ 3: จงหาค่า lim (x² + 2x)
               x→3

เฉลย: = 3² + 2(3) = 9 + 6 = 15

ข้อ 4: จงหาอนุพันธ์ของ f(x) = 5x³ - 2x + 1

เฉลย: f'(x) = 15x² - 2

ข้อ 5: จงหาค่าของ C(5,2)

เฉลย: C(5,2) = 5!/(2!×3!) = 120/(2×6) = 10
