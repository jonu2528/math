# PWA Icons

SVG icons have been generated for all required sizes.

To convert to PNG (required for PWA):
1. Use online tool: https://svgtopng.com/
2. Or use ImageMagick: `convert icon.svg icon.png`
3. Or open in browser and save as PNG

## Sizes Required:
- 72x72, 96x96, 128x128, 144x144
- 152x152, 192x192, 384x384, 512x512

## Alternative:
Use favicon generators like:
- https://realfavicongenerator.net/
- https://www.favicon-generator.org/
