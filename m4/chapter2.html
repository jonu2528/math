บทที่ 2: ฟังก์ชันและกราฟ

2.1 ฟังก์ชันและความสัมพันธ์

ความหมาย

ความสัมพันธ์ (Relation)

ถ้า $A$ และ $B$ เป็นเซตใดๆ ความสัมพันธ์ $R$ จาก $A$ ไป $B$ คือเซตของคู่อันดับ $(x, y)$ โดยที่ $x \in A$ และ $y \in B$

  • $A$ เรียกว่า โดเมน (Domain)
  • $B$ เรียกว่า โคโดเมน (Codomain)
  • เซตของค่า $y$ ทั้งหมดที่มีคู่กับ $x$ เรียกว่า เรนจ์ (Range)

ฟังก์ชัน (Function)

ความสัมพันธ์ $f$ จาก $A$ ไป $B$ เป็นฟังก์ชัน ก็ต่อเมื่อสมาชิกแต่ละตัวใน $A$ มีคู่กับสมาชิกใน $B$ ได้เพียงตัวเดียวเท่านั้น

เขียนแทนด้วย $f: A \rightarrow B$ อ่านว่า "$f$ เป็นฟังก์ชันจาก $A$ ไป $B$"

  • ถ้า $(x, y) \in f$ เขียนแทนด้วย $f(x) = y$ หรือ $y = f(x)$
  • $x$ เรียกว่า ตัวแปรอิสระ (Independent Variable)
  • $y$ เรียกว่า ตัวแปรตาม (Dependent Variable)

การตรวจสอบว่าเป็นฟังก์ชันหรือไม่:

  • ทุก $x$ ใน $A$ ต้องมีคู่กับ $y$ ใน $B$
  • แต่ละ $x$ มีคู่กับ $y$ ได้เพียงค่าเดียว
  • ในกราฟ: ใช้ Vertical Line Test (เส้นตรงแนวตั้งตัดกราฟได้ไม่เกิน 1 จุด)

การหาโดเมนและเรนจ์:

  • โดเมน = เซตของค่า $x$ ทั้งหมดที่ทำให้ฟังก์ชันมีค่าได้
  • เรนจ์ = เซตของค่า $y$ ทั้งหมดที่ได้จากการแทนค่า $x$ ในโดเมน

ตัวอย่างที่ 1: การตรวจสอบฟังก์ชัน

โจทย์: จงพิจารณาว่าความสัมพันธ์ใดต่อไปนี้เป็นฟังก์ชัน

  1. $R_1 = \{(1, 2), (2, 3), (3, 4), (4, 5)\}$
  2. $R_2 = \{(1, 2), (1, 3), (2, 4), (3, 5)\}$
  3. $R_3 = \{(1, 2), (2, 2), (3, 2), (4, 2)\}$

วิธีทำ:

1. $R_1 = \{(1, 2), (2, 3), (3, 4), (4, 5)\}$
แต่ละค่า $x$ มีคู่กับ $y$ เพียงค่าเดียว
เป็นฟังก์ชัน

2. $R_2 = \{(1, 2), (1, 3), (2, 4), (3, 5)\}$
$x = 1$ มีคู่กับ $y = 2$ และ $y = 3$ (มากกว่า 1 ค่า)
ไม่เป็นฟังก์ชัน

3. $R_3 = \{(1, 2), (2, 2), (3, 2), (4, 2)\}$
แต่ละค่า $x$ มีคู่กับ $y$ เพียงค่าเดียว (ถึงแม้ $y$ จะเป็นค่าเดียวกันทั้งหมด)
เป็นฟังก์ชัน

ตัวอย่างที่ 2: การหาโดเมนและเรนจ์

โจทย์: กำหนดให้ $f = \{(1, 3), (2, 5), (3, 7), (4, 9)\}$ จงหาโดเมนและเรนจ์ของ $f$

วิธีทำ:

โดเมน = เซตของค่า $x$ ทั้งหมด

$$\text{Domain} = \{1, 2, 3, 4\}$$

เรนจ์ = เซตของค่า $y$ ทั้งหมด

$$\text{Range} = \{3, 5, 7, 9\}$$

ตัวอย่างที่ 3: การหาค่าของฟังก์ชัน

โจทย์: กำหนดให้ $f(x) = 3x - 5$ จงหา

  1. $f(2)$
  2. $f(-1)$
  3. $f(a + 1)$
  4. ค่าของ $x$ เมื่อ $f(x) = 10$

วิธีทำ:

1. $f(2) = 3(2) - 5 = 6 - 5 = 1$

2. $f(-1) = 3(-1) - 5 = -3 - 5 = -8$

3. $f(a + 1) = 3(a + 1) - 5 = 3a + 3 - 5 = 3a - 2$

4. เมื่อ $f(x) = 10$
$3x - 5 = 10$
$3x = 15$
$x = 5$

ตัวอย่างที่ 4: การหาโดเมนของฟังก์ชัน

โจทย์: จงหาโดเมนของฟังก์ชันต่อไปนี้

  1. $f(x) = \dfrac{1}{x - 2}$
  2. $g(x) = \sqrt{x + 3}$
  3. $h(x) = \dfrac{1}{\sqrt{4 - x}}$

วิธีทำ:

1. $f(x) = \dfrac{1}{x - 2}$
ตัวหารต้องไม่เป็นศูนย์ $\Rightarrow x - 2 \neq 0 \Rightarrow x \neq 2$
โดเมน: $\{x | x \in \mathbb{R}, x \neq 2\}$ หรือ $(-\infty, 2) \cup (2, \infty)$

2. $g(x) = \sqrt{x + 3}$
ในรากที่สองต้องไม่ติดลบ $\Rightarrow x + 3 \geq 0 \Rightarrow x \geq -3$
โดเมน: $\{x | x \geq -3\}$ หรือ $[-3, \infty)$

3. $h(x) = \dfrac{1}{\sqrt{4 - x}}$
เงื่อนไข: ในรากต้องไม่ติดลบ และตัวหารต้องไม่เป็นศูนย์
$4 - x > 0 \Rightarrow x < 4$
โดเมน: $\{x | x < 4\}$ หรือ $(-\infty, 4)$

2.2 ประเภทของฟังก์ชัน

ประเภทของฟังก์ชัน

1. ฟังก์ชันคงตัว (Constant Function)

$$f(x) = c$$ โดยที่ $c$ เป็นค่าคงที่
เรนจ์: $\{c\}$, กราฟเป็นเส้นตรงขนานกับแกน $x$

2. ฟังก์ชันเอกลักษณ์ (Identity Function)

$$f(x) = x$$
เรนจ์ = โดเมน, กราฟเป็นเส้นตรงผ่านจุดกำเนิดทำมุม $45°$ กับแกน $x$

3. ฟังก์ชันเชิงเส้น (Linear Function)

$$f(x) = ax + b$$ โดยที่ $a \neq 0$
กราฟเป็นเส้นตรงที่มีความชัน $a$ และจุดตัดแกน $y$ ที่ $(0, b)$

4. ฟังก์ชันกำลังสอง (Quadratic Function)

$$f(x) = ax^2 + bx + c$$ โดยที่ $a \neq 0$
กราฟเป็นพาราโบลา

5. ฟังก์ชันหนึ่งต่อหนึ่ง (One-to-One Function)

ถ้า $f(x_1) = f(x_2)$ แล้ว $x_1 = x_2$
ตรวจสอบด้วย Horizontal Line Test (เส้นตรงแนวนอนตัดกราฟได้ไม่เกิน 1 จุด)

6. ฟังก์ชันทั่วถึง (Onto Function)

เรนจ์ = โคโดเมน (ทุกค่าในโคโดเมนมีคู่กับค่าในโดเมน)

ตัวอย่างที่ 1: การระบุประเภทของฟังก์ชัน

โจทย์: จงระบุประเภทของฟังก์ชันต่อไปนี้

  1. $f(x) = 5$
  2. $g(x) = 2x - 3$
  3. $h(x) = x^2 + 4x + 3$

วิธีทำ:

1. $f(x) = 5$ เป็น ฟังก์ชันคงตัว (มีค่าเป็นค่าคงที่ 5 เสมอ)

2. $g(x) = 2x - 3$ เป็น ฟังก์ชันเชิงเส้น ($a = 2, b = -3$)

3. $h(x) = x^2 + 4x + 3$ เป็น ฟังก์ชันกำลังสอง ($a = 1, b = 4, c = 3$)

ตัวอย่างที่ 2: การตรวจสอบฟังก์ชันหนึ่งต่อหนึ่ง

โจทย์: จงตรวจสอบว่า $f(x) = 2x + 1$ เป็นฟังก์ชันหนึ่งต่อหนึ่งหรือไม่

วิธีทำ:

สมมติว่า $f(x_1) = f(x_2)$

$$2x_1 + 1 = 2x_2 + 1$$

$$2x_1 = 2x_2$$

$$x_1 = x_2$$

ดังนั้น $f(x) = 2x + 1$ เป็น ฟังก์ชันหนึ่งต่อหนึ่ง

ตัวอย่างที่ 3: การหาฟังก์ชันผกผัน

โจทย์: กำหนดให้ $f(x) = 3x - 2$ จงหาฟังก์ชันผกผัน $f^{-1}(x)$

วิธีทำ:

ให้ $y = 3x - 2$

สลับตำแหน่ง $x$ กับ $y$: $x = 3y - 2$

แก้หา $y$:
$x + 2 = 3y$
$y = \dfrac{x + 2}{3}$

ดังนั้น $$f^{-1}(x) = \dfrac{x + 2}{3}$$
