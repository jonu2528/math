บทที่ 6: ตรีโกณมิติ

ตรีโกณมิติ (Trigonometry) เป็นศาสตร์ที่ศึกษาความสัมพันธ์ระหว่างมุมและด้านของสามเหลี่ยม โดยเฉพาะสามเหลี่ยมมุมฉาก บทนี้จะเรียนรู้เกี่ยวกับอัตราส่วนตรีโกณมิติพื้นฐาน การแก้สามเหลี่ยม กราฟของฟังก์ชันตรีโกณมิติ และเอกลักษณ์ตรีโกณมิติ ซึ่งมีประโยชน์ในหลายสาขาวิชา

6.1 อัตราส่วนตรีโกณมิติ

อัตราส่วนตรีโกณมิติในสามเหลี่ยมมุมฉาก

ในสามเหลี่ยมมุมฉากที่มีมุม $\theta$ ประกอบด้วย:

  • ด้านตรงข้ามมุมฉาก (hypotenuse) - ด้านที่ยาวที่สุด
  • ด้านตรงข้ามมุม $\theta$ (opposite)
  • ด้านประชิดมุม $\theta$ (adjacent)

อัตราส่วนตรีโกณมิติ 6 ประการ

1. ไซน์ (sine): $\sin \theta = \frac{\text{ตรงข้าม}}{\text{ตรงข้ามมุมฉาก}} = \frac{opposite}{hypotenuse}$

2. โคไซน์ (cosine): $\cos \theta = \frac{\text{ประชิด}}{\text{ตรงข้ามมุมฉาก}} = \frac{adjacent}{hypotenuse}$

3. แทนเจนต์ (tangent): $\tan \theta = \frac{\text{ตรงข้าม}}{\text{ประชิด}} = \frac{opposite}{adjacent}$

4. โคแทนเจนต์ (cotangent): $\cot \theta = \frac{1}{\tan \theta} = \frac{\text{ประชิด}}{\text{ตรงข้าม}}$

5. ซีแคนต์ (secant): $\sec \theta = \frac{1}{\cos \theta} = \frac{\text{ตรงข้ามมุมฉาก}}{\text{ประชิด}}$

6. โคซีแคนต์ (cosecant): $\csc \theta = \frac{1}{\sin \theta} = \frac{\text{ตรงข้ามมุมฉาก}}{\text{ตรงข้าม}}$

ตัวอย่างที่ 1: หาอัตราส่วนตรีโกณมิติ

โจทย์: ในสามเหลี่ยมมุมฉาก $ABC$ มุม $C = 90°$ ถ้า $AB = 13$ cm, $BC = 5$ cm จงหา $\sin A$, $\cos A$ และ $\tan A$

วิธีทำ:

หา $AC$ จากทฤษฎีบทพีทาโกรัส:

$$AC^2 = AB^2 - BC^2 = 13^2 - 5^2 = 169 - 25 = 144$$

$$AC = 12 \text{ cm}$$

สำหรับมุม $A$: ด้านตรงข้าม = $BC = 5$, ด้านประชิด = $AC = 12$, ด้านตรงข้ามมุมฉาก = $AB = 13$

$$\sin A = \frac{BC}{AB} = \frac{5}{13}$$

$$\cos A = \frac{AC}{AB} = \frac{12}{13}$$

$$\tan A = \frac{BC}{AC} = \frac{5}{12}$$

ตัวอย่างที่ 2: หาค่าที่ไม่ทราบ

โจทย์: ถ้า $\sin \theta = \frac{3}{5}$ และ $\theta$ เป็นมุมแหลม จงหา $\cos \theta$ และ $\tan \theta$

วิธีทำ:

ให้ ด้านตรงข้าม = $3k$, ด้านตรงข้ามมุมฉาก = $5k$

หาด้านประชิดจากทฤษฎีบทพีทาโกรัส:

$$\text{ประชิด}^2 = (5k)^2 - (3k)^2 = 25k^2 - 9k^2 = 16k^2$$

$$\text{ประชิด} = 4k$$

$$\cos \theta = \frac{\text{ประชิด}}{\text{ตรงข้ามมุมฉาก}} = \frac{4k}{5k} = \frac{4}{5}$$

$$\tan \theta = \frac{\text{ตรงข้าม}}{\text{ประชิด}} = \frac{3k}{4k} = \frac{3}{4}$$

ตัวอย่างที่ 3: ค่าตรีโกณมิติของมุมพิเศษ

โจทย์: จงหาค่า $\sin 45°$, $\cos 45°$ และ $\tan 45°$

วิธีทำ:

ในสามเหลี่ยมมุมฉากหน้าจั่วที่มีมุม $45°-45°-90°$

ถ้าด้านประชิด = ด้านตรงข้าม = $1$

ด้านตรงข้ามมุมฉาก = $\sqrt{1^2 + 1^2} = \sqrt{2}$

$$\sin 45° = \frac{1}{\sqrt{2}} = \frac{\sqrt{2}}{2}$$

$$\cos 45° = \frac{1}{\sqrt{2}} = \frac{\sqrt{2}}{2}$$

$$\tan 45° = \frac{1}{1} = 1$$

ตัวอย่างที่ 4: ตารางค่าตรีโกณมิติของมุมพิเศษ

โจทย์: จงหาค่า $\sin 30° + \cos 60° + \tan 30°$

วิธีทำ:

จากตารางค่ามุมพิเศษ:

$$\sin 30° = \frac{1}{2}$$

$$\cos 60° = \frac{1}{2}$$

$$\tan 30° = \frac{1}{\sqrt{3}} = \frac{\sqrt{3}}{3}$$

$$\sin 30° + \cos 60° + \tan 30° = \frac{1}{2} + \frac{1}{2} + \frac{\sqrt{3}}{3}$$

$$= 1 + \frac{\sqrt{3}}{3} = \frac{3 + \sqrt{3}}{3}$$

6.2 การหาค่าอัตราส่วน

ตารางค่าตรีโกณมิติของมุมพิเศษ

มุมพิเศษที่ควรจำคือ $0°, 30°, 45°, 60°, 90°$

ค่าตรีโกณมิติของมุมพิเศษ

มุม $\sin$ $\cos$ $\tan$
$0°$ $0$ $1$ $0$
$30°$ $\frac{1}{2}$ $\frac{\sqrt{3}}{2}$ $\frac{\sqrt{3}}{3}$
$45°$ $\frac{\sqrt{2}}{2}$ $\frac{\sqrt{2}}{2}$ $1$
$60°$ $\frac{\sqrt{3}}{2}$ $\frac{1}{2}$ $\sqrt{3}$
$90°$ $1$ $0$ ไม่นิยาม

วิธีจำ: สังเกตว่า $\sin 30° = \cos 60°$ และ $\sin 60° = \cos 30°$ (มุมเสริม)

ตัวอย่างที่ 1: การใช้ตาราง

โจทย์: จงหาค่า $2\sin 30° + 3\cos 60° - \tan 45°$

วิธีทำ:

$$2\sin 30° + 3\cos 60° - \tan 45°$$

$$= 2 \times \frac{1}{2} + 3 \times \frac{1}{2} - 1$$

$$= 1 + \frac{3}{2} - 1$$

$$= \frac{3}{2}$$

ตัวอย่างที่ 2: หาค่าจากเครื่องคิดเลข

โจทย์: ใช้เครื่องคิดเลขหาค่า $\sin 37°$ (ปัดเป็น 4 ตำแหน่ง)

วิธีทำ:

ตรวจสอบว่าเครื่องคิดเลขอยู่ในโหมด DEG (องศา)

กด: sin 37 =

$$\sin 37° \approx 0.6018$$

ตัวอย่างที่ 3: หามุมจากค่าตรีโกณมิติ

โจทย์: ถ้า $\sin \theta = 0.5$ และ $0° < \theta < 90°$ จงหา $\theta$

วิธีทำ:

จากตาราง $\sin 30° = \frac{1}{2} = 0.5$

ดังนั้น $\theta = 30°$

(หรือใช้ $\sin^{-1}(0.5)$ บนเครื่องคิดเลข)

ตัวอย่างที่ 4: การประยุกต์

โจทย์: ถ้า $\cos A = \frac{\sqrt{3}}{2}$ และ $A$ เป็นมุมแหลม จงหา $\sin A$ และ $\tan A$

วิธีทำ:

จากตาราง $\cos 30° = \frac{\sqrt{3}}{2}$ ดังนั้น $A = 30°$

$$\sin A = \sin 30° = \frac{1}{2}$$

$$\tan A = \tan 30° = \frac{\sqrt{3}}{3}$$

หรือใช้ $\tan A = \frac{\sin A}{\cos A} = \frac{\frac{1}{2}}{\frac{\sqrt{3}}{2}} = \frac{1}{\sqrt{3}} = \frac{\sqrt{3}}{3}$

6.3 การแก้สามเหลี่ยมมุมฉาก

การแก้สามเหลี่ยมมุมฉาก

การแก้สามเหลี่ยม หมายถึง การหาความยาวด้านและขนาดมุมที่ไม่ทราบค่าของสามเหลี่ยมมุมฉาก โดยใช้:

  • อัตราส่วนตรีโกณมิติ ($\sin, \cos, \tan$)
  • ทฤษฎีบทพีทาโกรัส
  • ผลรวมมุมภายในสามเหลี่ยม = $180°$

ขั้นตอนการแก้สามเหลี่ยม

1. กรณีรู้ 1 ด้าน 1 มุม: ใช้อัตราส่วนตรีโกณมิติหาด้านอื่น

2. กรณีรู้ 2 ด้าน: ใช้ทฤษฎีบทพีทาโกรัสหาด้านที่สาม แล้วใช้อัตราส่วนหามุม

3. หามุมที่เหลือ: ใช้ผลรวมมุม = $180°$

ตัวอย่างที่ 1: รู้ 1 ด้าน 1 มุม

โจทย์: ในสามเหลี่ยม $ABC$ มุม $C = 90°$, มุม $A = 35°$ และ $AC = 10$ cm จงหา $AB$ และ $BC$

วิธีทำ:

หา $AB$ (ด้านตรงข้ามมุมฉาก):

$$\cos 35° = \frac{AC}{AB} = \frac{10}{AB}$$

$$AB = \frac{10}{\cos 35°} \approx \frac{10}{0.8192} \approx 12.21 \text{ cm}$$

หา $BC$:

$$\tan 35° = \frac{BC}{AC} = \frac{BC}{10}$$

$$BC = 10 \times \tan 35° \approx 10 \times 0.7002 \approx 7.00 \text{ cm}$$

หามุม $B$: $B = 180° - 90° - 35° = 55°$

ตัวอย่างที่ 2: รู้ 2 ด้าน

โจทย์: สามเหลี่ยมมุมฉาก $PQR$ มีมุมฉากที่ $R$, $PQ = 25$ cm และ $PR = 15$ cm จงหา $QR$ และมุม $P$

วิธีทำ:

หา $QR$ โดยทฤษฎีบทพีทาโกรัส:

$$QR^2 = PQ^2 - PR^2 = 25^2 - 15^2 = 625 - 225 = 400$$

$$QR = 20 \text{ cm}$$

หามุม $P$:

$$\sin P = \frac{QR}{PQ} = \frac{20}{25} = 0.8$$

$$P = \sin^{-1}(0.8) \approx 53.13°$$

มุม $Q = 180° - 90° - 53.13° = 36.87°$

ตัวอย่างที่ 3: การประยุกต์ - ความสูง

โจทย์: ต้นไม้สูง 20 เมตร หล่นเอียงไปกระทบพื้นจุดหนึ่งห่างจากโคนต้นไม้ 12 เมตร จงหามุมระหว่างต้นไม้กับพื้น

วิธีทำ:

ให้มุมที่หา = $\theta$

$$\sin \theta = \frac{\text{ความสูง}}{\text{ความยาวต้นไม้}} = \frac{20}{20} = 1$$

แต่ต้องหาความยาวต้นไม้จริงจากพีทาโกรัส:

$$L^2 = 20^2 + 12^2 = 400 + 144 = 544$$

$$L = \sqrt{544} \approx 23.32 \text{ เมตร}$$

$$\sin \theta = \frac{20}{23.32} \approx 0.858$$

$$\theta \approx 59°$$

ตัวอย่างที่ 4: การประยุกต์ - ระยะทาง

โจทย์: จากตึกสูง 50 เมตร มองเห็นรถยนต์คันหนึ่งทำมุมยอดต่ำ $30°$ กับแนวระดับ จงหาระยะทางจากฐานตึกถึงรถยนต์

วิธีทำ:

ให้ระยะทางที่หา = $d$

$$\tan 30° = \frac{50}{d}$$

$$d = \frac{50}{\tan 30°} = \frac{50}{\frac{\sqrt{3}}{3}} = \frac{150}{\sqrt{3}} = 50\sqrt{3} \approx 86.60 \text{ เมตร}$$

6.4 มุมในตำแหน่งมาตรฐาน

มุมในตำแหน่งมาตรฐาน

มุมในตำแหน่งมาตรฐาน คือมุมที่มีจุดยอดอยู่ที่จุดกำเนิด ด้านเริ่มต้นทับกับแกน $x$ บวก และหมุนทวนเข็มนาฬิกา (บวก) หรือตามเข็มนาฬิกา (ลบ)

นิยามตรีโกณมิติบนวงกลมหนึ่งหน่วย

ถ้าจุด $P(x, y)$ อยู่บนวงกลมรัศมี $r$ และ $\theta$ คือมุมในตำแหน่งมาตรฐาน

$$\sin \theta = \frac{y}{r}, \quad \cos \theta = \frac{x}{r}, \quad \tan \theta = \frac{y}{x}$$

บนวงกลมหนึ่งหน่วย ($r = 1$):

$$\sin \theta = y, \quad \cos \theta = x$$

เครื่องหมายในแต่ละควอดรันต์:

  • ควอดรันต์ที่ 1 ($0° < \theta < 90°$): $\sin, \cos, \tan$ ทั้งหมดเป็นบวก
  • ควอดรันต์ที่ 2 ($90° < \theta < 180°$): เฉพาะ $\sin$ เป็นบวก
  • ควอดรันต์ที่ 3 ($180° < \theta < 270°$): เฉพาะ $\tan$ เป็นบวก
  • ควอดรันต์ที่ 4 ($270° < \theta < 360°$): เฉพาะ $\cos$ เป็นบวก

ตัวอย่างที่ 1: หาค่าในควอดรันต์ต่างๆ

โจทย์: จงหา $\sin 120°$, $\cos 120°$ และ $\tan 120°$

วิธีทำ:

$120°$ อยู่ในควอดรันต์ที่ 2 มุมอ้างอิง = $180° - 120° = 60°$

$$\sin 120° = \sin 60° = \frac{\sqrt{3}}{2}$$ (บวก)

$$\cos 120° = -\cos 60° = -\frac{1}{2}$$ (ลบ)

$$\tan 120° = -\tan 60° = -\sqrt{3}$$ (ลบ)

ตัวอย่างที่ 2: มุมมากกว่า 360°

โจทย์: จงหา $\sin 420°$

วิธีทำ:

$420° = 360° + 60°$

$$\sin 420° = \sin 60° = \frac{\sqrt{3}}{2}$$

ตัวอย่างที่ 3: มุมลบ

โจทย์: จงหา $\cos(-45°)$

วิธีทำ:

$-45°$ หมุนตามเข็มนาฬิกา = $360° - 45° = 315°$ (ควอดรันต์ที่ 4)

$$\cos(-45°) = \cos 45° = \frac{\sqrt{2}}{2}$$ (โคไซน์เป็นฟังก์ชันคู่)

ตัวอย่างที่ 4: หาพิกัดบนวงกลม

โจทย์: จุด $P$ อยู่บนวงกลมหนึ่งหน่วย มุมในตำแหน่งมาตรฐาน = $150°$ จงหาพิกัดของจุด $P$

วิธีทำ:

$x = \cos 150° = -\cos 30° = -\frac{\sqrt{3}}{2}$

$y = \sin 150° = \sin 30° = \frac{1}{2}$

$$P\left(-\frac{\sqrt{3}}{2}, \frac{1}{2}\right)$$

6.5 กราฟฟังก์ชันตรีโกณมิติ

กราฟฟังก์ชันตรีโกณมิติพื้นฐาน

ฟังก์ชันตรีโกณมิติเป็นฟังก์ชันคาบ (periodic) คือมีรูปแบบที่ซ้ำกันเป็นช่วงๆ

คุณสมบัติของกราฟตรีโกณมิติ

1. ฟังก์ชันไซน์ $y = \sin x$

  • โดเมน: $(-\infty, \infty)$
  • เรนจ์: $[-1, 1]$
  • คาบ (Period): $360°$ หรือ $2\pi$ เรเดียน
  • แอมพลิจูด (Amplitude): $1$
  • ผ่าน $(0, 0)$, $(90°, 1)$, $(180°, 0)$, $(270°, -1)$, $(360°, 0)$

2. ฟังก์ชันโคไซน์ $y = \cos x$

  • โดเมน: $(-\infty, \infty)$
  • เรนจ์: $[-1, 1]$
  • คาบ: $360°$ หรือ $2\pi$ เรเดียน
  • แอมพลิจูด: $1$
  • ผ่าน $(0, 1)$, $(90°, 0)$, $(180°, -1)$, $(270°, 0)$, $(360°, 1)$

3. ฟังก์ชันแทนเจนต์ $y = \tan x$

  • โดเมน: $x \neq 90°, 270°, ...$
  • เรนจ์: $(-\infty, \infty)$
  • คาบ: $180°$ หรือ $\pi$ เรเดียน
  • มีเส้นกำกับดิ่งที่ $x = 90° + 180°k$ ($k$ เป็นจำนวนเต็ม)

ตัวอย่างที่ 1: กราฟ $y = 2\sin x$

โจทย์: จงหาแอมพลิจูด คาบ และเรนจ์ของ $y = 2\sin x$

วิธีทำ:

เปรียบเทียบกับ $y = A\sin x$

แอมพลิจูด $A = 2$

คาบ = $360°$ (ไม่เปลี่ยน)

เรนจ์: $[-2, 2]$ (เพราะ $-2 \leq 2\sin x \leq 2$)

ตัวอย่างที่ 2: กราฟ $y = \cos(x - 30°)$

โจทย์: กราฟ $y = \cos(x - 30°)$ เลื่อนไปทางใด

วิธีทำ:

เปรียบเทียบกับ $y = \cos(x - c)$

กราฟเลื่อนไปทางขวา $30°$

ค่าสูงสุด $= 1$ เกิดที่ $x = 30°, 390°, ...$

ตัวอย่างที่ 3: หาค่าจากกราฟ

โจทย์: ถ้า $y = \sin x$ และ $y = 0.5$ จงหาค่า $x$ ที่ $0° \leq x \leq 360°$

วิธีทำ:

$\sin x = 0.5 = \sin 30°$

จากกราฟไซน์ใน 1 คาบ:

$x = 30°$ (ควอดรันต์ที่ 1)

$x = 180° - 30° = 150°$ (ควอดรันต์ที่ 2)

ตอบ: $x = 30°$ หรือ $x = 150°$

ตัวอย่างที่ 4: แก้สมการ

โจทย์: จงหาคำตอบของสมการ $2\cos x = 1$ เมื่อ $0° \leq x < 360°$

วิธีทำ:

$$\cos x = \frac{1}{2}$$

$\cos 60° = \frac{1}{2}$

จากกราฟโคไซน์:

$x = 60°$ (ควอดรันต์ที่ 1)

$x = 360° - 60° = 300°$ (ควอดรันต์ที่ 4)

ตอบ: $x = 60°$ หรือ $x = 300°$

6.6 เอกลักษณ์ตรีโกณมิติ

เอกลักษณ์ตรีโกณมิติ (Trigonometric Identities)

เอกลักษณ์ตรีโกณมิติ คือสมการที่เป็นจริงสำหรับทุกค่าของตัวแปร ใช้ในการพิสูจน์และลดรูปนิพจน์ตรีโกณมิติ

เอกลักษณ์พื้นฐาน

1. เอกลักษณ์พีทาโกรัส:

$$\sin^2 \theta + \cos^2 \theta = 1$$

$$1 + \tan^2 \theta = \sec^2 \theta$$

$$1 + \cot^2 \theta = \csc^2 \theta$$

2. เอกลักษณ์ส่วนกลับ:

$$\tan \theta = \frac{\sin \theta}{\cos \theta}, \quad \cot \theta = \frac{\cos \theta}{\sin \theta}$$

$$\sec \theta = \frac{1}{\cos \theta}, \quad \csc \theta = \frac{1}{\sin \theta}$$

3. เอกลักษณ์มุมเสริม:

$$\sin(90° - \theta) = \cos \theta$$

$$\cos(90° - \theta) = \sin \theta$$

$$\tan(90° - \theta) = \cot \theta$$

ตัวอย่างที่ 1: ใช้เอกลักษณ์พีทาโกรัส

โจทย์: ถ้า $\sin \theta = \frac{5}{13}$ จงหา $\cos \theta$ (เมื่อ $\theta$ เป็นมุมแหลม)

วิธีทำ:

ใช้ $\sin^2 \theta + \cos^2 \theta = 1$

$$\left(\frac{5}{13}\right)^2 + \cos^2 \theta = 1$$

$$\frac{25}{169} + \cos^2 \theta = 1$$

$$\cos^2 \theta = 1 - \frac{25}{169} = \frac{144}{169}$$

$$\cos \theta = \frac{12}{13}$$ (เป็นบวกเพราะเป็นมุมแหลม)

ตัวอย่างที่ 2: พิสูจน์เอกลักษณ์

โจทย์: จงพิสูจน์ว่า $\frac{\sin \theta}{\cos \theta} + \frac{\cos \theta}{\sin \theta} = \frac{1}{\sin \theta \cos \theta}$

วิธีทำ:

พิจารณาด้านซ้าย:

$$\frac{\sin \theta}{\cos \theta} + \frac{\cos \theta}{\sin \theta}$$

$$= \frac{\sin^2 \theta + \cos^2 \theta}{\sin \theta \cos \theta}$$

$$= \frac{1}{\sin \theta \cos \theta}$$ (เพราะ $\sin^2 \theta + \cos^2 \theta = 1$)

ซึ่งเท่ากับด้านขวา ดังนั้นพิสูจน์แล้ว

ตัวอย่างที่ 3: ลดรูปนิพจน์

โจทย์: จงลดรูป $\frac{1 - \sin^2 x}{\cos x}$

วิธีทำ:

$$\frac{1 - \sin^2 x}{\cos x}$$

$$= \frac{\cos^2 x}{\cos x}$$ (เพราะ $1 - \sin^2 x = \cos^2 x$)

$$= \cos x$$

ตัวอย่างที่ 4: ใช้เอกลักษณ์หลายสูตร

โจทย์: จงลดรูป $(\sec^2 \theta - 1) \cos^2 \theta$

วิธีทำ:

ใช้ $\sec^2 \theta - 1 = \tan^2 \theta$

$$(\sec^2 \theta - 1) \cos^2 \theta = \tan^2 \theta \cdot \cos^2 \theta$$

$$= \frac{\sin^2 \theta}{\cos^2 \theta} \cdot \cos^2 \theta$$

$$= \sin^2 \theta$$

↑ กลับไปด้านบน

แบบฝึกหัดบทที่ 6

ส่วนที่ 1: อัตราส่วนตรีโกณมิติพื้นฐาน (4 ข้อ)

  1. ในสามเหลี่ยมมุมฉาก $ABC$ มุม $C = 90°$, $AC = 8$ cm, $BC = 6$ cm จงหา $\sin A$, $\cos A$ และ $\tan B$
  2. ถ้า $\cos \theta = \frac{12}{13}$ และ $\theta$ เป็นมุมแหลม จงหา $\sin \theta$ และ $\tan \theta$
  3. ในสามเหลี่ยมมุมฉาก ถ้า $\tan A = \frac{3}{4}$ จงหา $\sin A$ และ $\cos A$
  4. จงหาค่า $\sin 30° \times \cos 60° + \tan 45°$

เฉลย ส่วนที่ 1:

1. $AB = \sqrt{8^2+6^2} = 10$ cm
$\sin A = \frac{6}{10} = \frac{3}{5}$, $\cos A = \frac{8}{10} = \frac{4}{5}$, $\tan B = \frac{8}{6} = \frac{4}{3}$

2. ให้ประชิด $= 12k$, ตรงข้ามมุมฉาก $= 13k$
ตรงข้าม $= \sqrt{(13k)^2-(12k)^2} = 5k$
$\sin \theta = \frac{5}{13}$, $\tan \theta = \frac{5}{12}$

3. ตรงข้าม $= 3k$, ประชิด $= 4k$, ตรงข้ามมุมฉาก $= 5k$
$\sin A = \frac{3}{5}$, $\cos A = \frac{4}{5}$

4. $\frac{1}{2} \times \frac{1}{2} + 1 = \frac{1}{4} + 1 = \frac{5}{4}$

ส่วนที่ 2: การหาค่าอัตราส่วน (4 ข้อ)

  1. จงหาค่า $\sin 60° + \cos 30° - 2\tan 60°$
  2. ถ้า $\sin A = \cos 60°$ และ $A$ เป็นมุมแหลม จงหา $A$
  3. จงหาค่า $\frac{\sin 30° + \cos 45°}{\tan 45°}$
  4. ถ้า $\tan \theta = \sqrt{3}$ และ $0° < \theta < 90°$ จงหา $\theta$

เฉลย ส่วนที่ 2:

5. $\frac{\sqrt{3}}{2} + \frac{\sqrt{3}}{2} - 2\sqrt{3} = \sqrt{3} - 2\sqrt{3} = -\sqrt{3}$

6. $\sin A = \frac{1}{2} = \sin 30°$ ดังนั้น $A = 30°$

7. $\frac{\frac{1}{2} + \frac{\sqrt{2}}{2}}{1} = \frac{1 + \sqrt{2}}{2}$

8. $\theta = 60°$ (เพราะ $\tan 60° = \sqrt{3}$)

ส่วนที่ 3: การแก้สามเหลี่ยมมุมฉาก (4 ข้อ)

  1. สามเหลี่ยมมุมฉาก $ABC$ มีมุมฉากที่ $C$, $AB = 20$ cm, มุม $A = 40°$ จงหา $AC$ (ปัดทศนิยม 2 ตำแหน่ง)
  2. สามเหลี่ยมมุมฉาก มี $a = 7$ cm, $b = 24$ cm จงหามุมแหลมทั้งสอง
  3. บันไดยาว 5 เมตร พิงกำแพง ทำมุม $60°$ กับพื้น จงหาความสูงที่บันไดถึง
  4. จากยอดตึกสูง 40 เมตร มองเห็นวัตถุทำมุมยอดต่ำ $45°$ จงหาระยะทางจากฐานตึกถึงวัตถุ

เฉลย ส่วนที่ 3:

9. $\cos 40° = \frac{AC}{20}$
$AC = 20 \cos 40° \approx 20 \times 0.766 \approx 15.32$ cm

10. $c = \sqrt{7^2+24^2} = 25$ cm
$\sin A = \frac{7}{25} \Rightarrow A \approx 16.26°$
$B = 90° - 16.26° = 73.74°$

11. $h = 5 \sin 60° = 5 \times \frac{\sqrt{3}}{2} = \frac{5\sqrt{3}}{2} \approx 4.33$ เมตร

12. $\tan 45° = \frac{40}{d}$
$d = \frac{40}{1} = 40$ เมตร

ส่วนที่ 4: มุมในตำแหน่งมาตรฐานและกราฟ (4 ข้อ)

  1. จงหาค่า $\sin 150°$
  2. จงหาค่า $\cos 240°$
  3. แก้สมการ $\sin x = \frac{\sqrt{3}}{2}$ เมื่อ $0° \leq x < 360°$
  4. จุด $P$ บนวงกลมหนึ่งหน่วยทำมุม $120°$ กับแกน $x$ บวก จงหาพิกัด $P$

เฉลย ส่วนที่ 4:

13. $150°$ อยู่ในควอดรันต์ที่ 2, มุมอ้างอิง $= 30°$
$\sin 150° = \sin 30° = \frac{1}{2}$

14. $240°$ อยู่ในควอดรันต์ที่ 3, มุมอ้างอิง $= 60°$
$\cos 240° = -\cos 60° = -\frac{1}{2}$

15. $\sin 60° = \frac{\sqrt{3}}{2}$
$x = 60°$ (ควอดรันต์ที่ 1) หรือ $x = 120°$ (ควอดรันต์ที่ 2)

16. $x = \cos 120° = -\frac{1}{2}$, $y = \sin 120° = \frac{\sqrt{3}}{2}$
$P\left(-\frac{1}{2}, \frac{\sqrt{3}}{2}\right)$

ส่วนที่ 5: เอกลักษณ์ตรีโกณมิติ (4 ข้อ)

  1. ถ้า $\sin \theta = \frac{8}{17}$ จงหา $\cos \theta$ (เมื่อ $\theta$ เป็นมุมแหลม)
  2. จงลดรูป $\frac{\sin^2 x + \cos^2 x}{\cos x}$
  3. จงพิสูจน์ว่า $\tan^2 \theta + 1 = \sec^2 \theta$
  4. จงลดรูป $\sin x \cdot \tan x + \cos x$

เฉลย ส่วนที่ 5:

17. $\sin^2 \theta + \cos^2 \theta = 1$
$\left(\frac{8}{17}\right)^2 + \cos^2 \theta = 1$
$\cos^2 \theta = 1 - \frac{64}{289} = \frac{225}{289}$
$\cos \theta = \frac{15}{17}$

18. $\frac{1}{\cos x} = \sec x$

19. แบ่งทั้งสองข้างของ $\sin^2 \theta + \cos^2 \theta = 1$ ด้วย $\cos^2 \theta$:
$\frac{\sin^2 \theta}{\cos^2 \theta} + 1 = \frac{1}{\cos^2 \theta}$
$\tan^2 \theta + 1 = \sec^2 \theta$

20. $\sin x \cdot \frac{\sin x}{\cos x} + \cos x = \frac{\sin^2 x}{\cos x} + \cos x$
$= \frac{\sin^2 x + \cos^2 x}{\cos x} = \frac{1}{\cos x} = \sec x$
